# IRG Working Set 2024

## 概要

IRG Working Set 2024 は、IRG が review している CJK Unified Ideographs の現行 working set である。IRG Meeting \#67 は Version 5.0 を review し、[Version 6.0 の作成・review schedule](../events/irg-67-ws2024-version6-review-schedule.md)に合意した。

[IRG N2932](../documents/irg-n2932.md) は Version 5.0 の chart / list で、各候補の source、attributes、discussion record を含む。[IRG N2933](../documents/irg-n2933.md) は Version 5.0 consolidated comments で、過去版から unresolved の指摘を含む source 別の review 意見を束ねる。Meeting \#67 前の入力文書であり、個別の採否は記録しない。

## 主な論点

### Version 5.0 review schedule

`IRG N2909` の M66.07 は、2026-05-01 に data fixing、2026-05-29 に Version 5.0 release、2026-07-17 に ORT comments、2026-08-14 に consolidated comments、2026-10-09 に submitter responses という schedule を置いた。Meeting \#67 は、この cycle の会合 review にあたる。

[IRG N2933](../documents/irg-n2933.md) は candidate ごとの Attributes、Unification、Glyph Design & Normalization などの comments を整理し、Version 1.0～4.0 から持ち越された unresolved comments も含む。registry date は 2026-07-18 であり、M66.07 の 2026-08-14 予定日とは記録の種類が異なる。掲載日から審査完了を推定せず、Meeting \#67 での disposition を確認する。

その前段として、[IRG N2702](../documents/irg-n2702.md) の M63.06 は Version 2.0、[IRG N2765](../documents/irg-n2765.md) の M64.04 は Version 3.0 の production / ORT review schedule を置いている。WS2024 は各 meeting の recommendation により、data fixing、ORT release、editor comments、consolidated comments、submitter responses を繰り返しながら進んでいる。

### agenda が明示する要注意項目

[IRG N2935](../documents/irg-n2935.md) は、Version 5.0 の中で特に注意が必要なものとして、ROK の確認が必要な `GCCPP-00019`、new evidence により unification / withdrawal を戻せる可能性がある `UTC-03362`、disposition が不明な `SAT-09585` を挙げている。

### representative glyph updates

Version 5.0 では、ORT の discussion record に基づき、G-source、K-source、SAT-source、T-source、U-source、UK-source、V-source の representative glyph 更新が agenda に列挙されている。これは [IRG Source Data and Representative Glyphs](irg-source-data-and-representative-glyphs.md) と重なる。

### CJKV Components との重複

Meeting \#67 agenda は、`CJK Unified Ideographs Components-B` に入る 11 ideographs が WS2024 にも含まれており、WS2024 から withdraw すべきだとしている。この点は [CJKV Components](cjkv-components.md) と直接接続する。

### 次期 Working Set の member body 予定

[IRG N2938](../documents/irg-n2938.md) は Macao SAR が次期 Working Set に提出しない方針、[IRG N2939R](../documents/irg-n2939r.md) は TCA が約 1,500～2,000 文字を提出する計画を維持する。[IRG N2941](../documents/irg-n2941.md) は ROK が承政院日記から集めた300字をさらに review し、最大200字を次期 Working Set に提案すると報告する。[IRG N2945](../documents/irg-n2945.md) の Vietnam 約 5,000 文字は将来の符号化候補の見積もりであり、次期提出数ではない。いずれも Meeting \#67 前の member body report で、採択・登録件数ではない。

[IRG N2943](../documents/irg-n2943.md) の UK は561字を暫定的に受け入れ、216字を shortlist とし、最終約1,000字を見込む。これは UK 内の準備状況であり、IRG の受理や符号化件数ではない。

### 次版文書の登録と本文公開

[M67.05](../events/irg-67-ws2024-version6-review-schedule.md)は N2979（Version 6.0）を2026-12-25、N2980（consolidated comments）を2027-02-26に release する予定を定めた。作成への合意と、文書本文の公開・review 完了を区別する。

### 初期 IRG との接続

[N131](../documents/irg-n131.md) V5–V6 は候補ごとの根拠、MRF data、draft、複数回の review、WG2 送付を工程化した。[初期 IRG 議論](early-irg-history.md)では現在の ORT / responses cycle と比較し、同一の手続が1994年から存在したとは扱わない。

### 初期の優先順位・証拠と配置判断

[N250](../documents/irg-n250.md) / [N315](../documents/irg-n315.md)は候補の優先順位と、国の規格・公的資料・辞書・使用頻度などの根拠を扱った。[1996年の Extension A 処理](../events/wg2-31-extension-a-repertoire-and-bmp-consultation.md)は repertoire の受理と BMP 配置照会を分ける。現在の production / review 日程を当時へ投影せず、選択・送付・配置・発行を区別する比較に使う。
