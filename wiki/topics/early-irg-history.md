# Early IRG History (1993–1996)

## 概要

本調査で本文を確認した最古の IRG 文書は、1993-05-25 の [設立提案 N002](../documents/irg-n002.md) である。番号順では N001 が先だが、それは同年7月の会合招集通知であり、番号順と日付順は一致しない。会合としては1993年10月の第1回から、1996年の第7回と WG2 第31回までを扱う。

最初期の議論は、漢字を増やす作業だけでなく、source と glyph の誤り修正、統合・分離規則の説明、既存表への source column 追加、新規 code positions、components、編集・review 手続を既に含む。現在の論点との接続は下表の問題設定の比較であり、同じ制度や repertoire がそのまま継続したと推定しない。

IRG 以前の CJK-JRG の作業は N034 が参照するが、本ページはその成立史や最古の漢字統合議論を確定するものではない。未公開の入力資料・minutes の内容は補わない。

### 1995～1996年に具体化した接続

| 比較する問題 | 初期の一次記録 | 最近の議論への接続 |
| --- | --- | --- |
| source column と保守責任 | [1996年の S-column 統合](../events/irg-7-s-column-merge-into-g.md) | [2026年の SG-source 独立化](../events/irg-m66-16-kirg-sgsource-establishment.md)と比較できる。GS prefix 導入や全 mapping の変遷は別途確認が必要。 |
| 部件集合と構成記法の区別 | [N310](../documents/irg-n310.md) → [IRG の4案送付](../events/irg-7-ideographic-description-proposals-forwarding.md) → [WG2 の改訂要請](../events/wg2-31-ideographic-description-refinement.md) | 現在の [Components](cjkv-components.md)でも部件自体の同定・統合と、IDS による記述を分ける。N392 は当時の疑問であり現行仕様ではない。 |
| 編集時の類似警告と登録済み字形指定 | [N366](../documents/irg-n366.md)の Variation Mark | 現在の [IVD](ideographic-variation-database.md)は base character と variation selector の組合せを登録して glyphic subset を定める。古い1記号案との同一性・直接の継承関係は確認していない。 |
| repertoire と配置・発行の段階 | [WG2 第31回の Extension A 処理](../events/wg2-31-extension-a-repertoire-and-bmp-consultation.md) | 現在の Working Set review、WG2 送付、版への取り込みを分ける読み方につながる。1996年の6,585字を後年の最終 block 件数に使わない。 |

[第4回の三役兼任禁止の撤回](../events/irg-4-officer-role-restriction-withdrawal.md)により、N034 項目3c の当該一文を後年にも有効な規則として扱えないことも確認できる。過去ページの記述は当時のまま残し、後続変更へリンクする。

N259 の13記号案、N313 の13機能表、N365 の12構造記号、N366 の1記号案は、単なる改称ではなく提案の分割・意味の整理として読む。現在の code positions や文字特性を当時の proposal から推定しない。

### 早期の決着と保留を分ける

設立、提案送付、拡張用語、Annex 送付は上記の canonical events に集約する。これらの IRG 内の結論を、そのまま規格の publication や Unicode encoding 完了とはしない。N131 V1 の人名文字 Category H も WG2 への要求であり、WG2 が同じ分類を採択した証拠ではない。

Users Guide の完成・出版と、N013 の各訂正がいつ反映されたかは、今回の確認資料では確定しない。N131 Y1 の Y-variants を、後年の `kZVariant` や IVD と同一の仕組みとも扱わない。

### 日付と公開範囲

N001～N033 の多くは catalog で unposted / unknown であり、文書番号の小ささだけで議論の内容を復元できない。N034 が旧 CJK-JRG 資料を IRG 番号で再配布したと記すため、番号付与と元資料の作成年も分ける。

N080 は会合日と registry date が異なり、N100 は表紙と添付草案の日付が異なる。N007 の「20,209」という印刷値は N008 / N100 の20,902と食い違う。日付・数値の差を黙って同一化しない。
