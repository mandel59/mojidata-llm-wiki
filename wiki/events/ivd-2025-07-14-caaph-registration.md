# IVD 2025-07-14 CAAPH registration

## 概要

IVD Registrar は、2025-07-11 に review を終了した [PRI \#521](../documents/pri-521.md) の申請を 2025-07-14 版 Ideographic Variation Database に登録した。新しい `CAAPH` collection に、95 base characters に対する 198 IVS を登録し、IVD の collection 数は 6 になった。

## 背景

Culture and Art Publishing House Co., Ltd. (文化艺术出版社) が、中国の文化・芸術と非物質文化遺産資料のデジタル化に必要な字形を登録申請した。representative は Eiso Chan。提案の目的と identifier scheme は [PRI \#521](../documents/pri-521.md) で読む。

## 結果

公式 PRI archive は、collection と 198 IVS を 2025-07-14 版へ登録したと明記する。正式な base / VS pair と identifiers は同日版の `IVD_Sequences.txt`、collection の定義は `IVD_Collections.txt` で確認する。

## 影響範囲

[IVD topic](../topics/ideographic-variation-database.md) では、既存 collection の追加登録と、新しい利用目的を持つ collection の新設を分ける節目である。新しい code point を符号化する決定を表すものではない。
