# IRG \#3 unification Annex forwarding

## 概要

IRG 第3回会合は N128 の Annex を最終編集修正付きで受理し、ISO/IEC 10646-1:1993 の速やかな改訂に向けて WG2 へ送るよう Rapporteur に求めた。同時に、その Annex の適用対象を既存の1993年版に限定した。[N131](../documents/irg-n131.md) A1–A2 が一次記録。

## 背景

第1回で [Annex 作成案を送付](irg-1-users-guide-and-annex-forwarding.md)し、第2回で統合規則・source と variant matters を分ける方針を置いた。[N100](../documents/irg-n100.md) は会合前の統合・配列草案である。

## 結果

将来 internal / horizontal supplementation や vertical extension を取り込む版では、V-column と対応辞書を反映して Annex を変更する必要があるとした。後続文書は catalog の `irg-n128r` / WG2 N1059.1 から辿れる。N131 は WG2 送付を指示する会合結論であり、規格発行の記録ではない。

## 影響範囲

現在の [UCV / NUCV](../topics/ucv-nucv-lists.md)や [indexing rules](../topics/irg-indexing-rules.md)との比較では、統合規則の記述と適用 repertoire を一緒に確認する必要がある。1994年の草案を現行の全漢字に機械適用しない。
