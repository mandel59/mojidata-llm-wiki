# IRG \#2 extension terminology and V-column

## 概要

IRG 第2回会合（Ha Noi、1994-02-28/03-04）は、補充 repertoire 作成のため Internal Supplementation、Horizontal Supplementation、Vertical Extension を区別し、Vietnam の N066 に応じて新しい V-column を設けると結論した。[N080](../documents/irg-n080.md) 項目4–5 が一次記録。event date は会期末、文書の registry date は1994-03-16である。

## 背景

既存 ISO/IEC 10646-1 の表へどのように repertoire を追加するか、各 body の資料と Vietnam の参加を合わせて処理する必要があった。

## 結果

| 当時の用語 | N080 が示す操作 |
| --- | --- |
| Internal Supplementation | 既存表の空き位置へ ideographs を追加する。 |
| Horizontal Supplementation | 既存表へ新しい ideograph sets を表す column を追加する。 |
| Vertical Extension | 新しい code positions を割り当てる additional sets を追加する。 |

N080 項目9は BMP allocation の責任が WG2 にあることを認識し、IRG は要求と優先順位を示すとした。V-column の設定はこの会合の結論であり、規格の出版日とは区別する。

## 影響範囲

現在の [horizontal extension](../topics/cjk-horizontal-extensions.md)を読む際の歴史的な比較点となる。ただし現在は既にある source column の reference / glyph 追加も含む。当時の定義をそのまま現行手続として適用しない。
