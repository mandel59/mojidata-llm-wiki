# IRG \#67 WS2024 Version 6.0 review schedule

## 概要

IRG 第67回会合は WS2024 Version 5.0 の feedback / responses を review し、N2947 の結論に基づき Version 6.0 を作成することで合意した。[N2946](../documents/irg-n2946.md) M67.05 が、その production / review cycle を定める。

## 背景

既存 working set を固定してから ORT 上で comments・回答を集め、次の会合で review する工程である。Version 6.0 の公開済みを示す記録ではない。

## 結果

| 期限 | Action item |
| --- | --- |
| 2026-11-27 | Chief Editor / ORT Manager が data を固定。必要な glyph 更新 font を submitters が提出。 |
| 2026-12-25 | ORT と N2979 で Version 6.0 を release。Excel attributes file を添付。 |
| 2027-02-05 | ORT Editors が comments を提出。 |
| 2027-02-26 | ORT / N2980 で consolidated comments を release。 |
| 2027-03-12 | Submitters が responses を提出。 |

M67.06 は次期 working set の準備を China (4000)、TCA (2000)、ROK (200)、SAT (300)、UK (1000)、UTC (200)、Vietnam (2500) に勧告する。括弧内は提出見積もりであり、受理数や encoding quota ではない。call は第68回後を見込む。

## 影響範囲

[第3回会合](../meetings/irg/irg-meeting-3.md)の MRF→draft→review→WG2 送付と工程を比較できる。ORT、font・attributes files、会合別の継続 record は後年の運用であり、1994年にあった仕組みとして書かない。
