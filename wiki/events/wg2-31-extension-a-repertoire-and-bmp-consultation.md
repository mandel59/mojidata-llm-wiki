# WG2 \#31 Extension A repertoire and BMP consultation

## 概要

WG2 第31回 M31.10 は Extension A Version 1.1 の6,585文字と字形を規格収録に向け全会一致で受理した。一方、M31.11 は BMP 配置について SC 2 から national bodies / liaisons へ照会するよう求めた。

## 背景

IRG 第7回 N360 項目3は repertoire 収録を全会一致で求めたが、BMP 配置には Unicode が反対し Vietnam が棄権した。項目1は当時の3 levels を Extensions A/B/C と改称していた。

## 結果

M31.11 は「今後 IRG が BMP への unified ideographs 追加を求めない」ことを条件とする質問を送り、1996-11-15までの回答を求めた。Canada は照会決議に棄権した。repertoire 受理、配置照会、規格発行・Unicode 収録を分けて記録する。

## 影響範囲

現在の Working Set でも、候補の review、WG2 への送付、符号位置と規格の progression を同一の完了状態にまとめない。6,585はこの1996年提案の件数であり、後年の最終 block の件数として使わない。
