# IRG \#7 ideographic-description proposals forwarding

## 概要

IRG 第7回会合は N360 項目10で、Structure Characters、Variation Mark、Radical Supplement、Component Supplement の4案を BMP 収録に向けて WG2 に送ると決議した。Japan は Structure Characters と Variation Mark について棄権した。

## 背景

[N259](../documents/irg-n259.md)、[N310](../documents/irg-n310.md)、[N313](../documents/irg-n313.md)は、未符号化漢字の表現と構造機能を議論してきた。N315 は structure symbols を control characters として扱う方針を記した。

## 結果

N361 項目10–11・14 は glyph / attachments、rationale、N310R 改訂を整えて WG2 第31回へ送る作業を求める。7月31日の N365 / N366 は Proposal Summary Form と添付を含み、12構造記号と1つの Variation Mark を別に提出する。

## 影響範囲

IRG の送付承認と WG2 の採用を分ける必要がある。[WG2 第31回の要請](wg2-31-ideographic-description-refinement.md)は4案を改訂・明確化する段階に留めた。現在の components や IVD の仕様をこの提出案から直接導かない。
