# UTC \#188 Unicode 18.0 release authorization

## 概要

UTC Meeting \#188 の consensus 188-C47 は、同会合で記録された decisions / actions を取り込んだ Unicode 18.0 と同期 UTS \#10、\#39、\#46、\#51、\#58 の release を、2026-09-16 target で authorize した。

## 背景

UTC \#187 は Unicode 18.0 beta review を authorize し、PRI \#548 を含む public review は 2026-07-07 に close した。UTC \#188 は beta feedback、WG2 \#73 decisions、RMG / PAG / CJK / SEW / Editorial / Charts reports を受け、final content を確定した。

## 結果

Release authorization には Chisoi の延期、Small Seal algorithmic name の変更、property / algorithm / data corrections、CJK / Unihan updates が含まれる。[L2/26-215 / IRG N2944](../documents/utc-l2-26-215.md) は Unicode 18.0 が 2026-09-16 に実際に release されたことを報告する。

## 影響範囲

この event は UTC の release decision を表す。ISO/IEC 10646 7th edition の ballot progression や、Unicode 19.0 target の provisional assignments は別 body / version の状態として分けて追う。
