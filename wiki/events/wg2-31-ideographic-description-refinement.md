# WG2 \#31 ideographic-description refinement

## 概要

WG2 第31回 M31.12b は、構造・variation・component・radical の4案を、会合で受けた comments に基づいて改訂するよう IRG に全会一致で促した。

## 背景

[IRG 第7回の送付](irg-7-ideographic-description-proposals-forwarding.md)により、WG2 N1430 / WG2 N1431 / WG2 N1432 / WG2 N1433 が提出された。採用・符号位置の確定とは異なる段階である。

## 結果

[N392](../documents/irg-n392.md)が質問を記録する。structure operator の scope・入れ子・等価性、Variation Mark の類似の軸と sorting、radical / component の独立集合・統合原則が明確化対象となった。これは質問であり、その答えや最終仕様ではない。

## 影響範囲

現在の [CJKV Components](../topics/cjkv-components.md)にある「既存 ideographs と components の境界」や、[IVD](../topics/ideographic-variation-database.md)の glyph 指定との比較に役立つ。[N394R](../documents/irg-n394r.md)は N392 への回答と N310 改訂を準備する action plan 案であり、確定回答の証拠にはしない。
