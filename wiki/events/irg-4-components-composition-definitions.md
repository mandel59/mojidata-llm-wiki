# IRG \#4 components and composition definitions

## 概要

IRG 第4回会合は N189 C1 で ideographic components と ideographic composition の定義を採用し、C2 で Zhang Zhoucai 主導の討議継続と IRG 外の experts の参加を認めた。

## 背景

[N080](../documents/irg-n080.md)項目13と [N131](../documents/irg-n131.md) C1 で components の定義・組合せ方式を継続討議していた。

## 結果

components は ideographs を表す basic units とし、ideographs proper と dependent ideographs を含める。composition は規則で順序付けた component の列による単一 ideograph の表現とした。N177 の英訳、feedback、summary の期限も設定した。これは定義と討議方針の採用であり、具体的な文字集合の符号化決定ではない。

## 影響範囲

[N200](../documents/irg-n200.md)がこの定義と方針を引用し、[N310](../documents/irg-n310.md)が再帰的構成方式を具体化した。2026年の [Components](../topics/cjkv-components.md)との比較では、定義・構成記法・符号化 repertoire の段階を分ける。
