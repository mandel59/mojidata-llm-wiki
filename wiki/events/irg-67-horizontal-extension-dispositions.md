# IRG \#67 horizontal extension dispositions

## 概要

[IRG N2946](../documents/irg-n2946.md) M67.08–12 は、China 9,178字、TCA 700字、UK 2字、UTC 74字の horizontal extension に受入勧告を行い、Vietnam 9,263字には継続 review と改訂を求めた。各勧告は Unanimous と記録される。IRG の勧告段階であり、Unicode / ISO 正式データへの反映完了を示さない。

## 背景

会合には G / T / UK / U / V source の追加案が出ていた。TCA の提出案改訂は [U+2403D source replacement](irg-67-tca-u2403d-source-replacement.md) に分ける。

## 結果

M67.11 は U+21148 の H-source glyph 変更を Hong Kong SAR に検討するよう勧告し、UTC font 提出を2026-10-30、Hong Kong SAR の回答を2027-02-19とする。

M67.12 は Vietnam 案の glyph と code chart 抜粋を並べる ORT review 方法を2026-12-25までに用意するよう求める。feedback は2027-01-15、N2970R は02-19、改訂案受理の見込みは第68回であり、この会合での受入勧告ではない。

## 影響範囲

[1994年の horizontal supplementation 定義](irg-2-extension-terminology-and-v-column.md)と比較できる。2026年の課題は、新たな column の設置だけでなく、既存文字と大量 source references / glyphs の対応をどう review するかにも及ぶ。
