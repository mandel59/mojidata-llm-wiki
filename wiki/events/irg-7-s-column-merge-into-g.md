# IRG \#7 S-column merge into G-column

## 概要

IRG 第7回会合は N360 項目5で、CJK Unified Ideograph Extension A に提案された S-column を G-column へ統合すると全会一致で決議した。

## 背景

第5回の [N250](../documents/irg-n250.md) P1 は Singapore の S と Korea の K の一部を優先順位別に分ける作業を記し、[N321](../documents/irg-n321.md)の Draft 4.1 表にも S-column が独立していた。

## 結果

決議の対象は Extension A に提案された S-column である。これを Singapore の全資料、全時期の source data の統合と拡張しない。GS prefix の導入時期や全 mapping がこの決議だけで確定するとも扱わない。

## 影響範囲

2026年には [N2926](../documents/irg-n2926.md)が China では GS-source の問題に対応できないとして独立 property を求め、[M66.16](irg-m66-16-kirg-sgsource-establishment.md)へ進む。1996年の chart column 統合と2026年の source property 分離は、source の表現と保守責任を比較する具体的な接続点となる。
