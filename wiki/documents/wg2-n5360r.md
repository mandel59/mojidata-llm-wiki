# WG2 N5360R

## 要約

`WG2 N5360R` は、ISO/IEC 10646 7th edition CD.4 consultation に対する China、India、Japan、USA comments の revised draft disposition である。17 CJK Strokes standardized variation sequences、6 glyph changes、4 name changes、Small Seal の radical / modern CJK property corrections を proposed disposition としてまとめる。

draft 時点では repertoire の追加・削除はないとし、複数の India comments を WG2 Meeting \#73 discussion 待ちにした。Small Seal character names を `SEAL CHARACTER-` から `SMALL SEAL CHARACTER-` へ変える comment には nonacceptance を提案しており、3日後の最終 [WG2 N5369](wg2-n5369.md) とは重要な差がある。

## 報告内容

### draft summary

| 区分 | Revised draft の proposed disposition |
| --- | --- |
| Repertoire | addition / removal なし。Chisoi removal request は WG2 discussion 待ち。 |
| CJK Strokes | [L2/26-073R](utc-l2-26-073r.md) / [L2/26-099](utc-l2-26-099.md) の17 standardized variation sequences を propose acceptance。 |
| Glyph changes | U+06C4、U+13228 と4 CJK source glyphs（U+2976E、U+2B876、U+2B8A0、U+2DB7C）を修正。 |
| Name changes | U+11DF1 Bengali name と U+1DF90、U+1DF91、U+1DF93 の Latin names を修正。 |
| Small Seal | 6 `kSEAL_Rad` values と20 `kSEAL_MCJK` values を修正。character-name prefix change は proposed nonacceptance。 |

U+06C4 ARABIC LETTER WAW WITH RING WITHIN の glyph correction は [L2/26-119](utc-l2-26-119.md) / [L2/26-120](utc-l2-26-120.md) の evidence に基づく。CJK source glyph changes は IRG / UTC recommendations を CD.4 chart に反映する disposition である。

### WG2 discussion 待ちの項目

India comments のうち、Odia signs U+0B53 / U+0B54 を generic combining diacritics で代替できるか、Chisoi proposal に wider community consultation が必要か、Kannada / Telugu archaic Shrii glyph を変えるかは WG2 discussion に送られた。

Chisoi comment は government backing と community consensus の不足を理由に removal を求める。secretariat observation は、script proposal に government backing は必須ではないと明記しつつ、最終判断を WG2 に残した。

### Small Seal comments

China comments は、Small Seal の naming clause、`kSEAL_Rad` 6件、`kSEAL_MCJK` 20件を扱う。draft は property corrections を proposed acceptance としたが、block name と character-name convention が一致するとの理由から `SMALL SEAL CHARACTER-` への変更を proposed nonacceptance とした。

## 後続決定

[WG2 N5369](wg2-n5369.md) は WG2 Meeting \#73 discussion 後の final disposition である。draft から final への主要な変更は次のとおり。

| 項目 | WG2 N5360R draft | WG2 N5369 final |
| --- | --- | --- |
| Chisoi | WG2 discussion 待ち、repertoire removal なし | 40 characters を CD.4 から removal |
| Small Seal names | `SMALL SEAL CHARACTER-` change を proposed nonacceptance | 11,328 names を `SMALL SEAL CHARACTER-XXXXX` へ変更 |
| disposition status | proposed acceptance / discussion pending | comments を accepted または accepted in principle として確定 |

[WG2 N5354](wg2-n5354.md) の M73.01 は final disposition を SC2 が受け入れるよう勧告し、M73.04 はその変更を含む 7th edition DIS text を ballot へ進めるよう勧告した。したがって implementation / current ballot status の根拠には N5360R ではなく N5369 と N5354 を使う。

## 論点

### draft と final の区別

本書は WG2 discussion の入力であり、final disposition ではない。特に repertoire removal と Small Seal naming は結論が反転しているため、draft summary を最終決定として引用してはならない。

### 複数 subsystem の一括 disposition

CD.4 ballot は script repertoire、character names、standardized variation sequences、regional source glyphs、Small Seal properties を一つの disposition で処理する。各変更の technical evidence は UTC / IRG proposal にあり、本書と N5369 はそれらを ISO/IEC 10646 edition text に取り込む層として読む。
