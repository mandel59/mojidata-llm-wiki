# IRG N313

## 要約

China が N310 を踏まえて提示した13構造記号の改訂表。
RSM、左右・上下・三分割、7種類の囲み、EMB を coded / gaiji examples とともに示す。
OTI を細分した具体形を比較する1ページの提出案である。
後の N365 の12記号表と比べ、Resemble の別扱いを確認できる。

## 提案内容

No.1 は RSM（Similar but not Equal to）。No.2–5 は LTR / ATB / LMR / AMB、No.6–C は OVA / DTE / UTE / RTE / RDE / LDE / RUE、No.D は Embedded Structure（EMB）である。これらは提出表の機能名・略号であり、現在の Unicode character names と同一視しない。

## 後続決定

[N365](irg-n365.md)は12構造記号、[N366](irg-n366.md)は1つの Variation Mark を別提案とした。[第7回の送付 event](../events/irg-7-ideographic-description-proposals-forwarding.md)と [WG2 の質問](irg-n392.md)へ続く。
