# IRG N2929R

## 要約

IRG N2929R は、China が既符号化文字へ GCW-Source references を追加する提案の改訂版である。
対象は初版 IRG N2929 の9,156文字から9,178文字へ増え、URO と Extensions A–J にまたがる。
文書は Sichuan International Studies University の地名研究プロジェクトに基づく second draft と説明する。
新しい code point の割当ではなく、既存 CJK Unified Ideographs の source data を拡張する提案である。

## 提案内容

改訂版が示す対象数は次のとおり。

| 範囲 | 文字数 |
| --- | ---: |
| URO | 21 |
| Extension A | 168 |
| Extension B | 3,061 |
| Extension C | 421 |
| Extension D | 27 |
| Extension E | 377 |
| Extension F | 2,795 |
| Extension G | 1,537 |
| Extension H | 366 |
| Extension J | 405 |
| 合計 | 9,178 |

source は GCW-Source 一種類で、official geographical names、personal names、philological works、dictionaries、periodicals、local gazetteers などに現れる文字を根拠とする。
文書の冒頭は初版からの主な変更を付録に列挙すると記す。

## 後続決定

IRG Meeting \#67 の公開 agenda IRG N2935 は Section 8.1 に初版 IRG N2929 の9,156文字を掲載しており、改訂版の件数は反映していない。会合での審議・採否は recommendation と action items が公開された後に確認する。

## 論点

改訂版は初版から合計22文字増え、各拡張の件数も一部増減している。議事録では初版と改訂版のどちらが審議対象になったかを区別する必要がある。
