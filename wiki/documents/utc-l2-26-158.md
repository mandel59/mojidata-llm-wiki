# L2/26-158

## 要約

`L2/26-158` は Script Encoding Working Group が UTC Meeting \#188 に提出した recommendations report である。新規 scripts、既存 script への characters、symbols、character changes、feedback を item ごとに整理する。
SEW consensus は KORE SEBELI、Ndiko Jonam、N’ti を含む provisional assignments を勧告したが、UTC 本会合は各 item を再検討し、一部を採択・修正・保留した。
したがって script の status はこの report 単独ではなく、[UTC \#188 minutes](utc-l2-26-151.md) の numbered decisions を優先する。

## 決定・Action Item

- KORE SEBELI 93 code points、Ndiko Jonam 69 code points、N’ti 47 code points の provisional assignment を SEW として勧告した。
- Combining marks、Arabic astronomical characters、Leibniz symbols、Chinese folk music symbol などの provisional assignment candidates をまとめた。
- Samavedic svara markers、COMPOSE、consecutive anusvaras などは action 不要または追加確認が必要とした。
- Maya proposals は reference list に含まれるが、この report の recommendation item には含まれない。

## 後続決定

[L2/26-151](utc-l2-26-151.md) は KORE SEBELI の character names を修正するため provisional assignment を次回へ延期し、Ndiko Jonam / N’ti も IP clarification 前には action を取らなかった。一方、U+20F1..U+20F2、Leibnizian Ambiguous Signs、U+1D282 などは numbered consensus として採択した。

## 論点

Working group recommendation と UTC decision を混同しないことが重要である。特に report の `SEW-188-Cn` は UTC minutes の `188-Cn` と同一ではなく、最終 status は後者で確認する。
