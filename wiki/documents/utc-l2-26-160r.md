# L2/26-160R

## 要約

`L2/26-160R` は UTC Meeting \#188 に対する Release Management Group report で、Unicode 18.0 beta completion、content finalization、2026-09-16 release target をまとめる。
Unicode 18.0 と同期 UTS \#10、\#39、\#46、\#51、\#58 の release authorization、final data / charts / specification tasks を提案した。
また、Chisoi を Unicode 18.0 から外すこと、Small Seal 11,328 characters の algorithmic names を変更することを勧告した。

## 決定・Action Item

- Unicode 18.0 と同期 UTS の release authorization、および final data、NamesList、charts、Core Specification、PRI closure の作業を UTC に勧告した。
- 今後の release publication day を Tuesday から Wednesday へ移す運用方針を説明した。
- Chisoi の Unicode 18.0 approval revert と Small Seal algorithmic names の変更を勧告した。

## 後続決定

[UTC \#188 minutes](utc-l2-26-151.md) は release authorization を 188-C47、Chisoi postponement を 188-C2、Small Seal naming changes を 188-C3 として記録した。[L2/26-215 / IRG N2944](utc-l2-26-215.md) は Unicode 18.0 が 2026-09-16 に実際に release されたことを報告する。

## 論点

この文書は RMG recommendation であり、最終決定は minutes、実際の publication は後続 activity report / release artifacts と区別する。
