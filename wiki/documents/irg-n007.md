# IRG N007

## 要約

Japan が IRG 第1回会合へ提出した Users Guide の新規 work item 提案。
統合漢字の coded representation だけでは利用・実装の説明が不足するとして、利用者向け Technical Report Type 3 を構想する。
source sets、統合規則、配列、Glyph vs Character、variants、subsetting / substitution を対象とする。
承認の記録は第1回会合の結論に分ける。

## 提案内容

実際の CJK systems における利用指針を目標にし、SC18/WG8 と AFII を liaison 候補として挙げる。予定成果物は Technical Report Type 3、PDTR 目標は JTC 1 承認後6か月以内。これらは提出案の計画である。

p.3 の文字数は「20,209」と印刷されている。同時期の [N008](irg-n008.md) と [N100](irg-n100.md) の20,902とは異なるため、この値を repertoire 件数の根拠にしない。

## 後続決定

[第1回会合の修正承認・上位 body への送付](../events/irg-1-users-guide-and-annex-forwarding.md)を参照。Technical Report の完成・出版までをこの会合結論から推定しない。
