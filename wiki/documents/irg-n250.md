# IRG N250

## 要約

1995-08-22 の Seoul 第5回会合決議。
Vertical Extension の category A 候補を3つの priority levels に分ける原則を合意する。
IRG の任務と作業計画を明文化し、components は Vertical Extension と別の集合として BMP へ提案する方針を置く。
component 集合は既存符号化文字との重複を避け、小さくするよう求める。

## 決定・Action Item

- P1–P3: Core、G7 / G3 / TE / J と K / S の一部を Level I、残る K / S を Level II、G5 / T4 を Level III とする。当時の候補の優先順位であり、完成した Unicode block の分類ではない。source set 内の code values は分割時も変更しない。
- M1: IRG は ideograph 関連規格案を作って WG2 へ提出する。IS/HS、Vertical Extension、components、Annex、高解像度 chart を work program に挙げる。
- C1–C2: N211R を component 討議の draft base とし、各 body に1995年9月末までの提出を求める。BMP 採用そのものを上位 body が決めた記録ではない。

## 後続決定

[N315](irg-n315.md)は component 選択条件と composition 記号を具体化し、[N360](irg-n360.md)は優先段階の名称を Extensions A/B/C に改めた。
