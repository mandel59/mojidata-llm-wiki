# IRG N100

## 要約

Takeo Koike による CJK 統合・分離と配列の informative Annex 草案。
Source code separation を他の統合規則より優先し、abstract shape と actual typeface shape の2段階で差異を説明する。
対象は既存の CJK Unified Ideographs repertoire であり、将来の拡張では規則を変更しうると明記する。
source separation list と source sets の詳細には未完成部分がある。

## 提案内容

- §1: 列挙した source standards 内で区別される文字を統合しない。
- §2: 非同源文字は原則として統合しない。component 数、配置、構造、source 内の扱い、radicals を使って abstract shape を比較し、字形設計上の違いと区別する。
- §3: source separation による例外を例示する。草案表を現行の完全な例外一覧として扱わない。
- §4: Kangxi Dictionary、Daikanwa Jiten、Hanyu Dazidian、Daejaweon の順に配列の根拠を参照する。
