# IRG N361

## 要約

1996-06-27 の IRG 第7回会合 action items。
Extension A / IS/HS の review、署名付き formal comments、Annex 改訂、WG2 提出を役割別・期限付きで定める。
構造記号など4案の rationale と fonts / attachments も提出対象にする。
font 利用の制限を記録し、単に公開データが揃ったという意味にはしない。

## 決定・Action Item

- 項目2–6: 7月8日 feedback、12日 Annex text、14日 final draft、15日署名付き formal comments を経て WG2 第31回へ送付する。
- 項目8–9: 7月31日までの96×96 bitmap / TrueType font 提供と、font data を配布せず IS/HS 印刷以外に使わない旨の正式同意を求める。
- 項目10–11・14: N365–N368 の glyphs / attachments、選択基準・rationale、N310R 改訂を準備する。
- 項目15–16: Extension A の使用頻度 evidence と、Singapore の BMP 配置への意向を確認する。

## 後続決定

提出・会合での扱いは [第7回送付 event](../events/irg-7-ideographic-description-proposals-forwarding.md)と [WG2 第31回](../meetings/wg2/wg2-meeting-31.md)を参照する。
