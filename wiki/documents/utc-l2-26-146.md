# L2/26-146

## 要約

`L2/26-146` は Maya Hieroglyphs Extended-A を符号化する in-progress draft proposal である。Classic Maya corpus に現れる signs のうち、Codical set と parallel representation を持たない signs を first tranche として追加する。

文書は Codical Maya proposal [L2/26-145](utc-l2-26-145.md) に依存し、Codical and Classic Maya Hieroglyphs を unified encoding として扱う。Classic / Codical の差は font level で扱い、Codical set にない signs を Extended-A で追加する方針である。

2026-06-19 の `WG2 N5367` Version 0.61 も同一提案であり、表紙に `IN PROGRESS DRAFT — Not for citation` と明記される。現版は Classic Maya 全体の完成 repertoire ではなく、今後複数回に分けて追加する first tranche である。

## 提案内容

| 区分 | 内容 |
| --- | --- |
| scope | Classic Maya corpus の first extension tranche。 |
| dependency | Codical set と format controls は [L2/26-145](utc-l2-26-145.md) に依存する。 |
| block | Maya Hieroglyphs Extended-A chart を U+15720..U+1578F に置き、現版では U+15720..U+1577B に glyphs を示す。 |
| unification model | Codical and Classic Maya を unified encoding とし、parallel representations は font level で扱う。 |
| future work | Classic Maya signs は今後の regular updates / tranches で拡張される見込み。 |
| evidence | ML catalog 順の charts、Codical / Classic concordance、Yaxchilan Lintel 25 と Stela 11 の prototype typesetting を示す。 |

## 後続決定

[WG2 N5354](wg2-n5354.md) の M73.14 は、`WG2 N5366` と `WG2 N5367` を National Bodies と liaison organizations が WG2 \#74 までに review するよう求めた。これは repertoire の採択ではなく、Codical base set と unified encoding を前提にした first tranche の review request である。

[UTC \#188 minutes](utc-l2-26-151.md) と `L2/26-158` は Maya proposals を reference list に含むが、採択 consensus / action item は置いていない。このため UTC \#188 で採択されたとは扱わない。

## 論点

### unified Maya encoding

この proposal の中心は、Codical Maya と Classic Maya を別 script / 別 encoding とせず、unified Maya Hieroglyphs として扱う点である。CJK 的な extension model と同様に、base set、extension set、font-level glyph style の分担が review point になる。

### 未完成の仕様領域

現版の `Properties` section は placeholder の一文だけである。Codical set との concordance も作業途中で、proposal は最終 repertoire、property assignment、future tranches の block allocation を確定した文書としては読めない。約 80% の Codical set を将来 Classic equivalents に map できるという見通しも、現時点の完了率ではなく目標である。
