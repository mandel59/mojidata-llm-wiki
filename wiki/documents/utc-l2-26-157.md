# L2/26-157

## 要約

`L2/26-157` は 2026-07-10 の CJK & Unihan Working Group meeting から UTC Meeting \#188 へ送られた recommendations である。
PRI \#534 feedback に基づく `kStrange`、`kRSUnicode`、`kMandarin`、`kJinmeiyoKanji`、`kZVariant`、IRG source data の修正と、個別 CJK / Unihan proposals の disposition をまとめる。
Unicode 18.0 向けの data corrections と Unicode 19.0 pipeline items が混在するため、採択結果は [UTC \#188 minutes](utc-l2-26-151.md) の numbered consensus / action item で確認する。

## 決定・Action Item

- PRI \#534 feedback から Unihan property の追加・修正を勧告し、`kMandarin` の 164 discrepancies は CLDR-TC に再確認を求めた。
- U+32CDD の normative `kIRG_GSource`、U+2BB89 / U+2C07B の informative `kRSUnicode` など、Unicode 18.0 向け correction candidates を整理した。
- DOUBLE IDEOGRAPHIC FULL STOP と WHITE IDEOGRAPHIC COMMA の provisional assignment、glyph、UAX \#50、Core Specification、pipeline 更新案を UTC に送った。

## 後続決定

[L2/26-151](utc-l2-26-151.md) は working group recommendations を選択的に採択し、たとえば U+16FE6 を 188-C41、U+16FE5 を 188-C42、458 件の `kTotalStrokes` changes を 188-C40 で処理した。recommendation 文書だけを UTC の最終決定として扱わない。

## 論点

同一の report 内でも normative source property、informative reading / radical data、future-version repertoire item は重みが異なる。Unicode version と numbered decision を保ったまま追跡する必要がある。
