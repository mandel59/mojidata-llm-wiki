# PRI 534

## 要約

`PRI #534` は、Unicode 18.0.0 向け Proposed Update UAX \#38 Revision 40 と関連する Unihan data corrections の public review record である。draft は 2026-04-23 に更新され、PRI は 2026-07-07 に closed となった。

review 対象には、`kJapaneseNewVariant` / `kJapaneseOldVariant` の追加、`kIRGDaeJaweon` / `kIRGKangXi` の削除、23 properties の delimiter 変更、`kGB5` / `kIRG_GSource` の syntax・description 更新などが含まれる。仕様変更の詳細は [L2/26-105](utc-l2-26-105.md)、UTC action への変換は [L2/26-099](utc-l2-26-099.md) が一次ソースである。

accumulated feedback は、Unihan property definitions だけでなく、個別 ideograph の source reference、radical / stroke count、readings、variant mappings、U-source status / horizontal extension まで広く扱う。PRI の closed status は、すべての feedback が採択されたことを意味しない。

## フィードバック内容

### UAX \#38 Revision 40

| 区分 | review 対象 |
| --- | --- |
| property lifecycle | provisional `kJapaneseNewVariant` / `kJapaneseOldVariant` の追加、`kIRGDaeJaweon` / `kIRGKangXi` の削除 |
| syntax / delimiter | 23 properties の delimiter、`kGB5`、`kIRG_GSource` の syntax 更新 |
| descriptions | `kIRG_GSource` / `kIRG_KSource` / `kIRG_UKSource`、`kOtherNumeric`、`kTang` の説明更新 |
| repertoire table | Section 4.4 の covered ideographs table に U+2B81E を追加 |

### accumulated feedback の主な系統

- `kIRG_GSource` / `kGB5` / G-source representative glyph と source reference の対応修正。
- `kRSUnicode` / `kTotalStrokes` / `kFourCornerCode` など radical・stroke・index data の修正。
- `kMandarin` / `kTang` / `kJinmeiyoKanji` など readings・dictionary / mapping data の修正。
- `kSemanticVariant` / `kSpecializedSemanticVariant` / `kSpoofingVariant` / `kZVariant` の追加、対称性、self-variant の修正。
- UAX \#45 `USourceData.txt` の status、IDS、related code point、U-source horizontal extension 候補。

feedback page は、2025-10 から 2026-03 までの一部を UTC Meeting \#186 / \#187 で review 済みと明示する。一方、2026-05 以降の `kStrange`、`kRSUnicode`、`kJinmeiyoKanji`、variant、Extension J の G-source reference などの report には、同 page 上で final disposition が示されていない。

## 後続決定

[L2/26-099](utc-l2-26-099.md) は、UTC Meeting \#187 までに処理した PRI \#534 feedback を Unihan additions / changes / removals、UAX \#45 record corrections、UAX \#38 updates の action items に変換した。

PRI は 2026-07-07 に closed したが、feedback page は individual report の採否を一括して示さない。UTC \#187 後に掲載された feedback の disposition と Unicode 18.0 への最終反映は、UTC Meeting \#188 minutes / working group report、final UAX \#38、`Unihan.zip`、UAX \#45 data で確認する必要がある。

## 論点

### draft review と data correction の分離

PRI title は UAX \#38 proposed update だが、accumulated feedback の多くは annex text ではなく Unihan / UAX \#45 の individual data correction である。仕様文面への feedback と code point 単位の data change を同じ disposition とみなさず、更新先の file / property を区別して追う必要がある。

### closed status と採択

`Closed` は comment period の終了を表す。UTC \#186 / \#187 で review 済みとされた report も、実際の処置は [L2/26-099](utc-l2-26-099.md) の action items や final data で確認する。marker より後の report は、UTC \#188 の記録が公開されるまで pending follow-up として扱う。
