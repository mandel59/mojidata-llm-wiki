# L2/26-216

## 要約

`L2/26-216` は taboo variants（避讳字）を standard forms に対応付ける provisional Unihan property `kTabooVariant` を提案する。主対象は、重要な歴史的人物の名を直接書くことを避けるため、末画省略などで作られた Han ideographs である。

property data と UAX \#38 の記述に加え、背景・範囲を詳述する Unicode Technical Note \#63 の作成も提案する。文書は19 mappings と、追加調査中の2 mappings を示す。

## 提案内容

| field | proposal |
| --- | --- |
| Property | `kTabooVariant` |
| Status | Provisional |
| Category | Variants |
| Delimiter | space |
| Syntax | `U\+[23]?[0-9A-F]{4}` |
| Direction | standard form の record から one or more taboo variants を列挙 |

例として U+7384 玄 → U+248E5 𤣥、U+4E16 世 → U+2000D 𠀍 / U+200D2 𠃒 などを挙げる。省画だけでなく homophone / synonym substitution、component substitution で新しい ideograph になった場合も scope に含め得る。

## 後続決定

2026-09-18 時点では proposal であり、UTC acceptance は未確認である。[L2/26-215 / IRG N2944](utc-l2-26-215.md) は IRG experts に Unicode 19.0 向け proposal として注意を促すが、採択を記録する文書ではない。

## 論点

IRG は通常 taboo variants を standard forms と unify するが、既に disunified encoding された早期例や特殊例が存在する。新 property は新たな disunification rule ではなく、既存 encoded characters 間の historical variant relation を明示する提案として読む必要がある。
