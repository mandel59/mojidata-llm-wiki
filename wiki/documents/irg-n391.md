# IRG N391

## 要約

1996-08-12/16、Quebec City の WG2 第31回会合決議。
本ページは IRG 関連の M31.9–12 と supplementary planes に関する M31.14 を中心に扱う。
IS/HS の pDAM 準備、Extension A の repertoire 受理、BMP 配置の照会を別の手続として記録する。
components / structure / variation / radicals の4提案には改訂を促す。

## 決定・Action Item

- M31.9: IS/HS の WG2 N1427 / WG2 N1428 / WG2 N1429 / WG2 N1434 を受理し、pDAM text と SC 2 ballot を準備する。
- M31.10–11: [Extension A repertoire と BMP 照会](../events/wg2-31-extension-a-repertoire-and-bmp-consultation.md)へ。
- M31.12b: [4案への仕様明確化要求](../events/wg2-31-ideographic-description-refinement.md)へ。M31.12c–d は Zhang Zhoucai の Rapporteur 継続と IRG 第8回の予定を受理する。
- M31.14: supplementary planes を埋める Part 2 の project subdivision を SC 2 に求める。
- 他の script 等の決議も含む2ページの文書であり、本 digest は全16決議の詳細一覧ではない。

## 後続決定

[N394R](irg-n394r.md)は Rapporteur の follow-up action plan 案。[N392](irg-n392.md)の質問への回答候補は catalog の `irg-n436` から次に追う。
