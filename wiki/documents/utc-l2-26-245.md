# L2/26-245

## 要約

Yoram Meroz と Karl Pentzlin が Yahgan / Ona の記録に使う Ellis’s Phonotypic Alphabet 拡張8文字を提案する。
Latin small letters 7文字と COMBINING LEFT-JOINED ACUTE-MACRON 1文字が対象。
Thomas / Lucas Bridges の手書き・印刷資料から orthography の改訂段階と用例を分けて説明する。
本文は SEW comments を反映した 2026-09-20版、registry date は 2026-10-12。

## 提案内容

- U+1DFA7..U+1DFAB に L / N / R / W / Y WITH MIDDLE LOOP、U+1DFAC に PHONOTYPIC SYLLABIC R、U+1DFAD に ESH-K を提案する。
- U+1AF4 COMBINING LEFT-JOINED ACUTE-MACRON は Mn / ccc=230 の案。
- 手書き Ona の ESH-K に未確認の uppercase を追加せず、既存文字で表現可能なものは追加から除く。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

異なる orthography 段階の letter identity、diacritic の音価、字形 variation を区別する。
