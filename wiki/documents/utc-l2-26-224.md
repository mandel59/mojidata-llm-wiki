# L2/26-224

## 要約

L2/26-224 は、Buryat Mongolian 用 Wagindara script の39字を提案する改訂文書である。
L2/24-242 の Mongolian extension 案から、独立 script の graphemic encoding model へ整理を進める。
29 letters、4 combining marks、6 punctuation marks を提案し、縦書き・左から右への行進行を保つ。
本文の日付は 2026-05-18、registry date は 2026-10-09。

## 提案内容

- Mongolian の phonemic model と orthography-dependent shaping を持ち込まず、written units と cursive joining に基づく model を採る。
- letters は dual joining、combining marks は transparent、punctuation は non-joining とする提案表を示す。
- repertoire の位置は `XX00` 等の placeholders であり、具体的な割当済み code point ではない。
- Mongolian 由来の字形、二種類の vowel notation、借用語の diacritics、1905–1910年の11資料を比較する。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

字形の歴史的起源と character behavior を区別し、Mongolian block を共用して shaping を複雑にする問題を避ける案である。joining variants がほぼ同形でも cursive と扱う判断と combining-mark model が検討点となる。
