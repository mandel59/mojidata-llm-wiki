# L2/26-249

## 要約

Biswajit Mandal が DEVANAGARI DOUBLE SEPARATOR 1文字を提案する。
Devanagari Extended-A の U+11B15 を候補とし、Po / Bidi_Class=L / Line_Break=AL を求める。
Jain Nagari の Sanskrit / Prakrit 写本から文・段落末や verse number の強調に用いる例を示す。
文書日付は 2026-08-22、registry date は 2026-10-13。

## 提案内容

- single SEPARATOR との対比、danda 上の用例を提示し、QUOTATION MARK との confusability を挙げる。
- 名称や representative glyph は SEW review で変更可能とする。
