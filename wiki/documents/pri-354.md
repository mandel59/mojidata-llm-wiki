# PRI 354

## 要約

`PRI #354` は、Moji_Joho collection への 674 IVS 追加登録の public review である。
提出者は ITSCJ / IPSJ、representative は Tetsuji ORITA。review closing date は 2017-11-17。
Unicode 10.0 の CJK Unified Ideographs Extension F に取り込まれた MJ characters の字形区別を扱う。
archive は 2017-12-12 版 IVD への追加登録を記録する。

## 提案内容

Extension F には文字情報基盤の 1,645 characters が含まれ、一部の行政用字形は同じ code point に統合された。提案は、その code point を共有しながら必要な字形区別を IVS で残す。

674 sequences のうち 181 は Hanyo-Denshi と共有し、493 は新しい base / VS pair として提案された。文書は、同じ base character に対して同一またはほぼ同一の glyphs を持つ 16 pairs についても、行政システムで区別が必要なため別 identifiers を与えたと説明する。

## 後続決定

公式 archive は、2017-12-12 版 IVD に 674 IVS を追加登録したと明記する。Moji_Joho の初回登録は [PRI \#259](pri-259.md)、2026 年の更新は [PRI \#546](pri-546.md) を参照。

## 論点

字形が近いことと、利用者が区別を必要とすることは別の条件である。文書の説明は collection の行政用途に基づき、すべての collection に同じ区別を要求するものではない。登録履歴は [IVD topic](../topics/ideographic-variation-database.md) にまとめる。
