# WG2 N5353

## 要約

`WG2 N5353` は、IRG Meeting \#65 と \#66 の recommendations を WG2 / SC2 向けに17項目へ再編した summary report である。原 recommendation は [IRG N2826](irg-n2826.md) / `WG2 N5345` と [IRG N2909](irg-n2909.md) / `WG2 N5352` にあり、本書は複数会合をまたぐ進捗、訂正、WG2 action を一つの入口にまとめる。

WS2024、disunification、horizontal extensions、source / glyph changes、IRG P&P、UCV/NUCV に加え、`kIRG_SGSource`、CJKV Components、CJK Hybrid Characters、UTS \#37 update を WG2 の検討事項として提示する。会合決定そのものではなく、どの recommendation が information、approval、action を要するかを body 間で引き渡す report である。

### disunification と horizontal extensions

Meeting \#65 は、U+980B / U+FACB / U+2F9FF から既存 U+2EA07 への disunification と、U+6B25 から新規 U+2B81E への disunification を勧告した。前者の根拠は [IRG N2834](irg-n2834.md) / [IRG N2865](irg-n2865.md)、後者は `IRG N2889R2` である。いずれも ISO/IEC 10646 7th edition CD.4 と IRG Disunified Ideographs page に反映されたと報告する。

[IRG N2892](irg-n2892.md) まで文書で管理していた disunification list は、Meeting \#66 が web page で IWDS Series 4 を supersede することに同意した。

horizontal extension は China 597、TCA 163、Hong Kong SAR の U+35E9、ROK の U+2B058 を accept し、CD.4 に反映したとする。

### representative glyph と source reference

Meetings \#65 / \#66 は G / T / K source representative glyphs、`kIRG_GSource` / `kIRG_TSource` / `kIRG_KSource`、`kRSUnicode` の変更を多数勧告した。本書は recommendation text の集計漏れを2点訂正する。

- [IRG N2861](irg-n2861.md) Table 2 の6 T-source glyph changes が M65.14 から漏れていたため、T-source glyph count を12から18へ修正する。
- [IRG N2874R](irg-n2874r.md) の U+204F2 `kRSUnicode` change が M65.11 から漏れていたことを追記する。

Meeting \#66 の新しい T / K glyph、G-source、`kRSUnicode` changes は Unicode 18.0 Beta と後続 ISO/IEC 10646 CD に入る一方、それ以前の変更は CD.4 に反映済みと区別する。

## 後続決定

[WG2 N5354](wg2-n5354.md) の M73.06 は CJK Unified Ideographs Components-A / B を Amendment 1 の first additions に含め、M73.15 は `kIRG_SGSource` を Amendment 1 target に追加するよう勧告した。M73.17 は IRG \#67-\#69 を含む future meeting schedule を確認した。

一方、CJK Hybrid Characters の separate-block recommendation と UTS \#37 reference update は、`WG2 N5354` に独立した採択項目としては記録されていない。これらは N5353 が WG2 discussion / action を求めた状態と、後続 meeting records を分けて追う必要がある。

## 論点

### recommendation と summary report

`WG2 N5353` は M65 / M66 を新たに採択する文書ではない。IRG 内の一次決定は [IRG N2826](irg-n2826.md) / [IRG N2909](irg-n2909.md)、WG2 の後続決定は [WG2 N5354](wg2-n5354.md) に置き、本書は二つの body を接続する status / action summary として使う。

### 数値訂正の扱い

T-source glyph count と U+204F2 `kRSUnicode` は recommendation の意味を覆す変更ではなく、対象件数の omission correction である。ただし CD / Unicode data への実装範囲を照合するときは、元 recommendation の数値ではなく、本書の訂正を含めて読む必要がある。

### dated status

Singapore feedback 未受領、WS2024 Version 5.0 の開始予定、next working set の翌年提出可能性などは 2026-04-30 時点の status である。現在状態は Meeting \#67 documents と WG2 \#73 recommendations で更新する。
