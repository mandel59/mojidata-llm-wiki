# IRG N2946

## 要約

2026-10-15 公開の IRG Meeting \#67 Recommendations and Action Items。
WS2024 Version 6.0 の作成・review schedule と、次期 Working Set 提出準備を勧告する。
China・TCA・UK・UTC の horizontal extensions に受入勧告、Vietnam 案には継続 review を置く。
UCV / NUCV・radical rules、source / glyph の個別 disposition、会合言語の扱いも記録する。
IRG の受入勧告を Unicode / ISO データへの反映完了と同一視しない。

## 決定・Action Item

| 勧告 | 内容 |
| --- | --- |
| M67.01 | \#68～\#70 の予定と、春 virtual・秋 hybrid の運用。 |
| M67.02–04 | 既存 UCV / NUCV 例を確認し、新規例を受理。N2952 を今後の提出の radical assignment rules として受理。 |
| M67.05–06 | [WS2024 Version 6.0 作成 event](../events/irg-67-ws2024-version6-review-schedule.md)と次期提出準備。 |
| M67.07 | China UNC 1字を受入勧告。推奨 code point は Extension D 末尾 U+2B81F。 |
| M67.08–12 | [Horizontal extension disposition event](../events/irg-67-horizontal-extension-dispositions.md)を参照。 |
| M67.13–14 | U+2B0AF / U+2B26F / U+2B720 の G-source references と、U+2AE99 / U+2B622 / U+2CCA3 の G-source glyphs へ受入勧告。U+2AE99 の kRSUnicode / kTotalStrokes は87.11 / 15、U+2CCA3 は167′.18 / 23。342 references と194 glyph changes は China の検討・回答を次会合へ求める。 |
| M67.15–18 | SAT の17 glyphs と Vietnam の references / glyphs は検討を求める。U+3097C の T-source glyph 変更には受入勧告。 |
| M67.19 | 非英語の限定使用には英語の要約と英語の決定記録を条件とする。ROK の異議（recommendation に含めることへの反対）と今後の feedback 募集を記録する。 |

M67.19 以外の19項中18項には Unanimous と表示される。M67.19 も全会一致だったとは書かない。

## 後続決定

[IRG \#67](../meetings/irg/irg-meeting-67.md)から追跡する。Version 6.0 release と Vietnam 改訂案の review は将来の action item であり、公開・完了済みとは扱わない。
