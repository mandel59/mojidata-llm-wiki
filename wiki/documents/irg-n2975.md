# IRG N2975

## 要約

IRG N2975 は IRG N2974 の U+3097C（T13-2F35）T-source glyph issue に対する TCA feedback である。
TCA は《龍龕手鑑》の複数版を照合し、上部の米に hook がない形と hook がある形の双方が資料に見られると報告した。
NAER は unhooked form を standard glyph として採用し、Dictionary of Chinese Character Variants の掲載を更新した。
TCA は IRG N2974 の変更案に同意し、更新 glyph を反映した font を IRG と WG2 に提出した。

## フィードバック内容

- TCA は original evidence の由来を Dictionary of Chinese Character Variants とし、複数版の《龍龕手鑑》を比較資料として NAER に提供した。
- NAER が unhooked form を standard glyph として採用した後、TCA は U+3097C の T-source glyph を更新することに同意した。
- 更新した font file は IRG と WG2 に提出された。

## 後続決定

N2975 は source owner TCA の同意と提出を記録する。IRG、UTC、WG2 による後続の正式採択・Unicode data 更新はこの文書では確認できない。

## 論点

N2974 の提案に対し、TCA は source owner として変更に同意した。両文書の役割を、提案と feedback に分けて追い、会合後の disposition で標準 data の更新を確認する。
