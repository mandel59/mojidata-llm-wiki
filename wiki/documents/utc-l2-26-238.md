# L2/26-238

## 要約

2026-10-09 の CJK & Unihan WG review に基づく UTC \#189 向け勧告。
IRG \#67 の UNC・horizontal extensions・glyph / source corrections を Unicode 19.0 の変更案へつなぐ。
kSEAL_AdditionalSrc の追加、kJURC_Src syntax の修正、Unihan feedback の処理も扱う。
IRG recommendation、WG の勧告、UTC の採択を別の段階として読む。

## 決定・Action Item

| Section | 勧告・報告 |
| --- | --- |
| 01–06 | UAX \#60 syntax / 誤記、U+2BAD5 の U-source・画数・glyph、semantic / spoofing variants、U+80E7 の radical / KangXi reference を更新する案。 |
| 07 | kTabooVariant は mapping 反転・kTabooVariantOf という名前、対象選定、region / period registry を再検討するよう author に返す。 |
| 08–09 | SC 2/AG 1 の任命状況を報告。provisional kSEAL_AdditionalSrc を19.0向けに追加する案。 |
| 12 | IRG M67.07 に基づき UNC U+2B81F と GHS source prefix を追加する案。 |
| 13–16 | G-source 9,178、T-source 700、UK-source 2、U-source 74文字の horizontal extension を受け入れる案。 |
| 17–19 | G-source reference / glyph / radical corrections、T-source U+3097C の glyph change を受け入れる案。 |

PDF には Copy&Paste-ready recommendations と Unihan / U-source / SealSources の変更案を添付する。

## 後続決定

[UTC Meeting \#189](../meetings/utc/utc-meeting-189.md) の審議資料。2026-10-25 時点では会合前であり、採択・承認の結果は後続 minutes で確認する。
