# L2/26-227

## 要約

Tatar・Bashkir の yaña imlâ、Arabic-script Nogai、中国の Tatar 出版物で使う1文字を再提案する。
U+0892 ARABIC LETTER ALEF MAKSURA WITH COMMA ABOVE を候補とし、dual-joining / Joining_Group=YEH を提案する。
2011年に ALEF MAKSURA + DAMMA で表現可能とされた文字について、letter identity と追加用例を再検討する。
文書日付は 2026-10-01、registry date は 2026-10-12。

## 提案内容

- General_Category=Lo、Bidi_Class=AL、ccc=0。結合時にも FARSI YEH の下の二点を持たず、ALEF MAKSURA に基づく文字とする。
- 上の comma は独立した vowel sign ではなく字母の一部とし、U+0649 + U+064F による表現へ反論する。
- Karakalpak は alphabet chart 以外の本文使用を確認できなかったため、今回の使用言語には含めない。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

新しい用例を根拠とした再提案であり、2011年の判断が既に変更されたことは示さない。
