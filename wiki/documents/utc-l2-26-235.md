# L2/26-235

## 要約

PAG が UTC \#189 に提出する properties / algorithms の勧告集。
Georgian titlecase、segmentation、bidi、normalization、security、emoji の既定 property を扱う。
finite automata の UAX \#14 / \#29・UCD への導入、UTS \#61 の初版公開、UTR \#25 の改訂公開を勧告する。
Recommended UTC actions は採択前の案であり、番号付き UTC consensus ではない。

## 決定・Action Item

| 項目 | PAG の勧告 |
| --- | --- |
| §2 | Mtavruli の titlecase を Mkhedruli に変更。U+1F201 の Vertical_Orientation を Tu → U。Script_Extensions 制約と Age=Unassigned の説明を修正。 |
| §4–6 | bidi fast path / reference implementation、NFC buffering 条件、Tulu-Tigalari independent vowels の Line_Break=AS → AK を修正。 |
| §7 | finite automata と CSS の language-independent tailorings を導入。Word_Break の ALetter / Other 再分類と U+21AE の Extended_Pictographic=Yes を勧告。 |
| §8–10 | collation weights、folding の非正規化、UTS \#39 の fast path・email local-part（NFKC → NFC）・confusables scope を修正。 |
| §11 | future emoji 領域の East_Asian_Width=Wide / Vertical_Orientation=U、既存の5記号の vo=R → U、emoji 表示の縦組み説明を勧告。 |
| §12–13 | UTR \#25 Revision 17 と UTS \#61 の公開、PRI \#523 / \#555 の終了を勧告。 |
