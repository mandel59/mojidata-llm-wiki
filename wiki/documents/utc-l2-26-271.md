# L2/26-271

## 要約

Orchid Flower を flower emoji の追加として提案する。
ESR の [L2/26-237](utc-l2-26-237.md) が Unicode 19.0 向けの5候補に含めている。
Registry の source は空欄であり、著者を推定しない。
後続の改訂勧告は [canonical event](../events/esr-189-four-characters-directional-zwj-recommendations.md) へ。

## 提案内容

orchid の文化的意味、利用・検索データ、既存 flower emoji との識別を説明する。
Phalaenopsis をモデルとする color / monochrome の図案を提示する。
