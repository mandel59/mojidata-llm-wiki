# L2/26-226

## 要約

L2/26-226 は、Vithkuqi block の annotation を変更する提案であり、新文字の追加は求めない。
HHA / IJE の大文字・小文字にある19世紀の orthography という注釈を冗長として削除する。
U+10596 と U+105BD に reserved の表示を追加し、既存の将来拡張用 gaps との整合を求める。
本文の日付は 2026-07-31、registry date は 2026-10-09。

## 提案内容

- U+1057D、U+1057F、U+105A4、U+105A6 の annotation を削除する。
- U+10596 / U+105BD を chart の annotation table で `<reserved>` と明示する。
- 原資料である1844 / 1845年の primers と revivalist uses を区別する。
- representative glyph redraw は必要との意見を示すが、この提案の範囲には含めない。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

文字の追加、予約位置の注釈、glyph の描き直しは別の変更である。添付 chart の Latin letters は予約用途の説明用であり、chart にそれらを表示する要求でもない。
