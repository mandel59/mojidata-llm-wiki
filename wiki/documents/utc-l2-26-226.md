# L2/26-226

## 要約

UTS \#61 Unicode Set Notation の Revision 2、Version 1 draft 4 の snapshot。
Registry の表題は Proposed Draft だが、実体の header は Draft Unicode Technical Standard とする。
code points / strings の集合と property queries を機械可読な共通構文で記述する。
draft 4 は Testing、Bidirectional display、Segmentation Dialect の節を含む。
snapshot の登録日は2026-10-25、仕様 header の日付は2026-10-01。

## 提案内容

- escaped / named / bracketed elements、property queries、union / intersection / difference とその semantics を定義する。
- Revision 2 の改訂履歴は、集合演算の union / intersection / difference の優先順位を同じにした修正を説明する。古い文法との差は、well-formedness だけでなく評価結果に関わる。
- 4.1節は conformance test data の形式・公開先を案内する。ただし draft 内の Review Note は test files を準備中と記すため、公開済みとはみなさない。
- 7.2節は bidi display、7.3節は UTC が維持する specifications 向けの style guide を扱う。
- 8節は UAX \#14 / UAX \#29 用に、implicit property queries と variables を導入する segmentation dialect を示す。
