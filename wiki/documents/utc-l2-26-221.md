# L2/26-221

## 要約

L2/26-221 は DEVANAGARI CORRECTION MARK FOR VOWEL SIGNS を Devanagari Extended-A へ追加する提案である。
Jain manuscripts で省略された AA を上付きの double repha-like mark で補う用例と、E / AI に加えて O / AU を表す用例を示す。
提案位置は U+11B0F。名称は initial proposal の VOWEL SIGN ALTERNATE AA から変更したと説明する。
本文の日付は 2026-10-08、registry date は 2026-10-09。

## 提案内容

- NamesList の alias として `Kaanaa Darshaka` を提案する。
- 提案 property は `General_Category=Mn`、`Canonical_Combining_Class=0`、`Bidi_Class=L`、`Line_Break=CM`。
- `Indic_Syllabic_Category=Syllable_Modifier`、`Indic_Positional_Category=Top` とし、通常の repha sequence で代用できないとする。
- PHONETIC CORRECTION MARK が割り当てられた場合、その後に sort する案を示す。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

訂正記号としての役割、vowel signs との組合せ、repha が先行する場合の表示を確認する。本文は name に SEW の助言を反映したと述べるが、UTC の最終 assignment とは区別する。
