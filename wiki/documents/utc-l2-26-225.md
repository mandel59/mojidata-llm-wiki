# L2/26-225

## 要約

L2/26-225 は、Romance dialectological atlases 用の LATIN SMALL LETTER TURNED DOTLESS I 1字を提案する。
L2/26-079 の追加文書として、U+1D09 / U+1D4E に Soft_Dotted を追加する案の安定性問題を説明する。
新文字の提案位置は U+1DFA6 で、下付き diacritics により dot が消える RFE alphabet の用例を示す。
本文の日付は 2026-08-07、registry date は 2026-10-09。

## 提案内容

- 提案 UnicodeData は `LATIN SMALL LETTER TURNED DOTLESS I`、`General_Category=Ll`、`Bidi_Class=L`。
- 新文字 + U+0323 と U+1D09 は canonical equivalent にできないと説明し、`DoNotEmit` の `Precomposed_Form` record を提案する。
- modifier turned dotless i は今回の要求に含めず、RFE modifier letters 全般の扱いに依存するとする。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

既存文字の property 変更による casing / dot suppression の影響と、新文字で非正規の同形 sequence が増える tradeoff を分ける。UTC \#188 に関する経緯は提案者の説明なので、最終 decision は会合の一次記録で確認する。
