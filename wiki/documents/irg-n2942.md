# IRG N2942

## 要約

IRG N2942 は SAT Committee の IRG Meeting \#66 から \#67 までの activity report である。
SAT は ISO/IEC 10646 の Kanbun repertoire 拡張と WS2024 の作業を継続している。
Meeting \#67 と併催後イベントの準備、次期 IRG Working Set への約300字の提出計画も記録する。
この報告は活動・計画を述べるもので、提出受理や符号化決定ではない。

## 報告内容

- SAT Committee は ISO/IEC 10646 における Kanbun repertoire の拡張を進め、IRG Working Set 2024 に取り組んでいる。
- IRG Meeting \#67 と post-event の BiangBiangCon – East Asia Encoding Meetup を準備している。
- 次の IRG Working Set に約300字を提出する計画を示した。

## 後続決定

IRG N2935 は Meeting \#67 の agenda を示すが、IRG N2942 の次期 working set 提出計画の採否を記録していない。

## 論点

報告は Kanbun repertoire 拡張、WS2024 の継続作業、次期 submission preparation を並記する。約300字は計画値であり、受理済み文字数として扱わない。
