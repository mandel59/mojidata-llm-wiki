# PRI \#557

## 要約

`PRI #557` は Proposed Update UAX \#11, East Asian Width の open review である。closing date は 2026-10-05。

## 提案内容

Revision 47 draft は Section 4.1 に DBCS / SBCS の定義を追加し、Section 6.3 から古い `EastAsianWidth.txt` format description を除き、`DerivedEastAsianWidth.txt` への参照を追加する。

## 後続決定

2026-09-18 時点で open。UTC \#189 の disposition を確認する。

## 論点

中心は property value の大規模変更ではなく、用語と normative / derived data の参照関係を現在の UCD structure に合わせる documentation update である。
