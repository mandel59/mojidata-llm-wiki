# L2/26-262

## 要約

ISO/IEC 10646 第7版の Amendment 1、CDAM 1（SC 2 N5072）の公開 draft。
Sirmauri、Proto-Cuneiform、Chisoi、CJK components、既存 block への追加と glyph changes を含む。
kIRG_SGSource と外部 delta charts への参照も更新する。
本文日付は2026-10-05、registry date は2026-10-15。最終 Amendment ではない。

## 提案内容

- 既存blockへの追加と、新block Sirmauri / Proto-Cuneiform / Chisoi / Leibnizian Ambiguous Signs / CJK Unified Ideographs Components-A/B を列挙する。
- SG-source を source enumeration と chart presentation に追加する。
- Amendment 用の外部 delta charts と Unicode 19.0 の full charts に参照を置く。
- editor note は Unicode 19.0 の参照先がまだ有効でないことを明記する。
