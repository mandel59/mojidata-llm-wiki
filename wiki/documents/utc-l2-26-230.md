# L2/26-230

## 要約

Karl Pentzlin が Benjamin Franklin の reformed alphabet の未符号化 Latin letters 4文字を再提案する。
Latin Extended-G の U+1DFB2..U+1DFB5 に FRANKLIN OH / SH / TH / DH を置く案。
2008 / 2022年提案の審議指摘に対し、running text、現代の学術利用、字形・名称・交換上の問題を追加する。
文書日付は 2026-08-30、registry date は 2026-10-12。

## 提案内容

- Franklin が導入した6字のうち TURNED H と ENG は既存文字で表現し、今回の追加には含めない。
- 字形の細部を名称に固定するより、Franklin の system と音価を示す functional names を採る。
- 用途を spelling reform の復興に限定せず、史料編集・言語学・archive での plain-text interchange とする。
