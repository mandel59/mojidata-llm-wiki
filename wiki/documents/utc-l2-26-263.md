# L2/26-263

## 要約

SC 2 N5062 の ISO/IEC 10646 Maintenance Agency ToR draft に対する consultation 結果（SC 2 N5073）。
公開 ZIP の index.pdf は2026-07-15〜10-07の照会と、20 member bodies の回答を記録する。
質問は draft にコメントがあるかであり、賛否投票や MA 設置決定ではない。
6 bodies が Yes、14 bodies が No と回答し、2 bodies は回答しなかった。

## 報告内容

- コメントあり: Canada、China、India、Japan、Norway、United States。
- Canada は tools / charts の escrow、Unicode との相互 commitment、encoding criteria を論点にする。
- Japan は MA の範囲、NBVG / IAVG / JVG の decision process、IRG の AG 化を評価し、編集修正も求める。
- Norway は secretariat 名の固定、representatives / observers、投票閾値の明確化を求める。
- index.pdf に直接掲載されたコメントと添付ファイルへの参照を確認した。collated .doc の全コメントを精読したものではない。

## 論点

Yes / No はコメントの有無を表す。ToR の承認数、MA の設置承認数、Unicode と ISO の合意成立として数えない。JISC 等の proper names は draft 内の暫定 placeholders と説明されている。
