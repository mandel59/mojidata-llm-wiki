# IRG N360

## 要約

1996-06-27、Hong Kong の IRG 第7回会合決議。
Vertical Extension の3 levels を Extensions A/B/C と改称し、Extension A の採用と BMP 配置を WG2 へ求める。
Singapore の S-column を G-column に統合し、構造・variation・radical・component の4提案を送付する。
全会一致の項目と、Unicode の反対・Vietnam / Japan の棄権を分けて記録する。

## 決定・Action Item

- 項目1–4: 3 levels を Extensions A/B/C に改称。Extension A の規格収録要求は全会一致だが、BMP 配置要求には Unicode が反対し Vietnam が棄権した。詳細は [後続 WG2 event](../events/wg2-31-extension-a-repertoire-and-bmp-consultation.md)へ。
- 項目5: [S-column と G-column の統合](../events/irg-7-s-column-merge-into-g.md)を決議する。
- 項目6–9: 高品質 fonts、印刷、次期 Rapporteur、Clause 26・Annex S・IS/HS・Extension A の記述を WG2 へ提出する。
- 項目10: [4提案の送付 event](../events/irg-7-ideographic-description-proposals-forwarding.md)へ。
- 項目11–13: email を FAX / mail と併用し、次回会合と WG2 への参加を求める。

## 後続決定

[N361](irg-n361.md)が実務の action items、[N391](irg-n391.md)が WG2 第31回の正式 disposition を記録する。
