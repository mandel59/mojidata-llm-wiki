# L2/26-231

## 要約

UTC \#189 の preliminary draft agenda。会合は2026-10-26〜28、Nancy, France / online の hybrid 形式を予定する。
Unicode 19.0 の scope、script・CJK・property・emoji 各勧告、ISO/IEC 10646 の保守体制が主要議題。
registry date は2026-10-23、取得した本文の更新表示は2026-10-25。
議題への掲載は採択を意味しない。

## 報告内容

- 毎日13:30 CET（UTC+1）から開始する予定。
- 10月26日: CJK / Unihan、properties / algorithms、関連 liaison。
- 10月27日: SC 2 liaison、script proposals、新しく作られた script の支援。
- 10月28日: Editorial、Charts、Emoji、SEQ、Release Management、PRI と事務事項。
