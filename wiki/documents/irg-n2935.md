# IRG N2935

## 要約

IRG N2935 は、2026-10-12/16 に Tokyo, Japan で開催すると告知された IRG Meeting \#67 の schedule and agenda である。
registry date と HTML の Last Update はともに 2026-10-12。
WS2024 Version 5.0 review と \#66 follow-up に加え、Section 7 に N2983 の U+2EA07 調査、Section 8.1 に N2984 / N2987 の G-source horizontal extension feedback を載せる。
Section 9.1 には N2976 / N2977 の glyph 提案と China の N2985 / N2986、Section 9.4 には kSEAL_AdditionalSrc 提案を追加した。
IRG の議事は 2026-10-12/15 に置かれ、金曜日 2026-10-16 は BiangBiangCon — East Asia Encoding Meetup を予定する。

## 論点

2026-10-12版は、開催初日の追加資料を agenda に束ねる。赤字の title は提出期限後の資料を意味し、採択や討議完了を示さない。[IRG N2973](irg-n2973.md) の中国語使用案と現行 P&P Version 18 の Participation も継続掲載する。agenda への掲載は提案の承認ではない。

Section 8 の [IRG N2929R](irg-n2929r.md) と [IRG N2972](irg-n2972.md)、Section 9.1 の [IRG N2975](irg-n2975.md) は submission deadline 後の提出を示す赤字で掲載される。改訂 repertoire と source-owner feedback を入力文書として追い、採否は会合後の記録で確認する。

### \#66 recommendation の current status

`IRG N2935` は、`kIRG_SGSource` と CJKV Components について、IRG Convenor が WG2 \#73 へ提出し、WG2 recommendation と SC2 acceptance を経て Unicode Version 19.0 target になった current status を記録している。これは `IRG N2909` の決定そのものではなく、\#67 agenda 時点の後続 status である。

### Unicode 18.0 / ISO/IEC 10646 7th edition との接続

Agenda Section 4 では、T-source U+2976E、K-source U+2DB7C、一部 G-source reference changes などが UTC / WG2 の decisions を経て、2026-09-16 に release された Unicode 18.0 に反映されたと整理している。`WG2 N5354` の Recommendation M73.02 は、これらの一部を ISO/IEC 10646 CD の CJK additions and changes に接続する。

### 未決事項

Meeting \#67 では、G-source / UK-source / V-source / SAT-source / T-source glyph issues、China horizontal extension revised document、WS2024 Version 5.0 comments、[IRG N2952](irg-n2952.md) の radical assignment rules などが継続確認対象である。V-source では `IRG N2928` の U+268A1 / U+268A2 glyph enquiry が "Redux" として再掲され、follow-up の `IRG N2953` が入力文書になっている。agenda は決定事項ではないため、会合後は `IRG N2946` recommendations and action items で状態を更新する。2026-10-12の追加資料は [IRG N2983](irg-n2983.md)、[IRG N2984](irg-n2984.md) / [IRG N2987](irg-n2987.md)、[IRG N2985](irg-n2985.md) / [IRG N2986](irg-n2986.md)、[IRG N2976](irg-n2976.md) / [IRG N2977](irg-n2977.md) から読む。
