# L2/26-256

## 要約

Roozbeh Pournader が UTC 164-A63 の Devanagari / Vedic shaping properties 調査を報告する。
U+1CE2..U+1CE8 と U+1CED を Indic_Syllabic_Category=Cantillation_Mark へ変更する案。
U+1CF8 / U+1CF9 の Indic_Positional_Category を NA→Top とし、OM / HEADSTROKE などは Other を維持する。
文書日付は 2026-09-12、registry date は 2026-10-13。

## 報告内容

- visarga の accents は Vedic tone marks として扱い、visarga 本体とは別に分類する。
- TIRYAK の独立した音声機能は不明瞭だが、既存 data model の範囲では Cantillation_Mark を推奨する。
- U+A8F4..U+A8F7 の Bindu 案と U+0971 の維持は companion report に委ねる。

## 論点

既存実装の override は比較材料であり、Unicode の normative property が既に変更されたことを示さない。
