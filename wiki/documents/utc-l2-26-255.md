# L2/26-255

## 要約

Roozbeh Pournader が UTC 158-A106 の Unicode 12.0 beta feedback 調査を報告する。
Lao cancellation mark を Consonant_Killer、複数の Vedic / Indic nasal signs を Bindu へ変更する案。
既に Unicode 12 / 13 / 17 で修正された項目を分け、残る変更と保留する値を整理する。
文書日付は 2026-09-09、registry date は 2026-10-13。

## 報告内容

- U+0ECC: Other→Consonant_Killer。unpronounced base consonant を示す annotation と cross-references を提案する。
- U+1CFA: Consonant_Placeholder→Bindu。U+1CE9..U+1CEC、U+1CEE..U+1CF0、U+A8F4..U+A8F7、U+11448、U+114C5: Other→Bindu。
- Bindu の定義に spacing nasal signs と、その上へさらに combining marks が付く用法を明記する。U+0971 は Other の維持を推奨する。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

古い feedback の全要望を新規変更として数えず、既実装項目と今回の提案を区別する。action item の調査終了は property 変更の採択とは別。
