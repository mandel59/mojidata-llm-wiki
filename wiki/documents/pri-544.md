# PRI 544

## 要約

`PRI #544` は、個別 PRI、特定文書、Unicode 18.0 Beta review などに属さない UTC Meeting \#188 向け formal public feedback の集成である。2026-07-07 に closed となり、17 件の report を CJK & Unihan、Script Encoding、Properties & Algorithms、Editorial、Charts の各 working group に振り分けている。Emoji Standard & Research と Other Reports には掲載時点で report がない。

内容は UAX \#45 の IDS corrections、Georgian titlecase mapping、UAX \#9 の RTL digits の説明、U+11A7 normalization test、Small Seal code chart / data corrections、Core Specification と NamesList の編集提案など広範囲に及ぶ。この page は受領された feedback の記録であり、個々の提案が UTC に採択されたことを示す decision record ではない。

## フィードバック内容

### CJK & Unihan Working Group

Ken Lunde は、UAX \#45 の 4 records (`UTC-00970`, `UTC-01044`, `UK-01462`, `UK-01653`) について、欠落または placeholder を含む IDS を具体的な ideograph components に置き換えるよう求めた。

### Script Encoding Working Group

- Georgian Extended の assigned characters について、Mtavruli 全体を titlecase したときに不自然な mixed case にならないよう、`Titlecase_Mapping` を `Lowercase_Mapping` と同じにする提案。
- sarcasm / irony を示す reverse oblique property または variation mechanism の提案。
- MENDE KIKAKUI SYLLABLE M193 HON と Dalby の M193 NGGEE の注記・repertoire 関係の確認要求。
- SMP roadmap の Musical Symbols Supplement を Roadmapped ではなく Accepted for publication とする訂正要求。

### Properties & Algorithms Working Group

- UAX \#9 が RTL scripts の digits を一般化しすぎているとして、N'Ko、Mende Kikakui、Adlam など strong RTL digits を持つ scripts も正確に扱う説明への訂正要求。
- Unicode 6.1 より前から存在する characters の `Emoji_Presentation` default を見直す提案。
- U+11A7 HANGUL JUNGSEONG O-YAE を誤って trailing consonant と扱う実装 bug を検出するため、`NormalizationTest.txt` に specific test case を加える提案。
- Samaritan の `Joining_Type=Transparent` が `ArabicShaping.txt` に現れない derivation についての照会。

### Editorial Working Group

- Core Specification の abugida encoding models の説明を、`Pure_Killer`、`Invisible_Stacker`、encoded repha / medial などを使う newer models まで広げる提案。
- [L2/26-128](utc-l2-26-128.md) の East Asian quotation marks に関する用法・幅の説明と英文の copy edits。
- WORD SEPARATOR MIDDLE DOT と MIDDLE DOT の推奨記述、deprecated tag characters の歴史的説明、BOM section の `U+FFEF` typo を `U+FEFF` に直す提案。

### Charts Working Group

Huang Junliang は draft Seal data の空 glyph 16 件と radical order 3 件を報告した。Eiso Chan が伝えた TCA feedback は、`kSEAL_Rad` 2 groups と `kSEAL_MCJK` 19 mappings の corrections を列挙し、Unicode 18.0 Beta でも未反映とした。Harriet Riddle は mathematical symbols を中心に、NamesList annotations の cross-reference と alias の追加を提案した。

## 後続決定

`PRI #544` は 2026-07-07 に closed だが、PRI page と accumulated feedback page は working groups への routing と提出内容を記録するだけで、17 件それぞれの disposition を示していない。採否、修正文、Unicode 18.0 data への反映は、UTC Meeting \#188 の minutes / working group reports、最終 data files、code charts で確認する必要がある。

## 論点

### 一つの PRI に異種の feedback が集まる

この PRI は fallback intake であり、character encoding、property semantics、algorithm test data、core specification text、code charts が同居する。したがって PRI 全体を一つの technical proposal として扱わず、routing 先と report ごとの論点を維持して読む必要がある。

### Small Seal feedback の位置づけ

Small Seal 関連 report は repertoire proposal そのものではなく、draft data / chart の空 glyph、radical order、`kSEAL_Rad`、`kSEAL_MCJK` correspondence の correction である。[Small Seal Script](../topics/small-seal-script.md) の repertoire / source discussion と、[Unicode 18.0 Change Sources](../topics/unicode-18-change-sources.md) の beta data review の双方に接続する。
