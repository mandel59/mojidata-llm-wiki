# IRG N080

## 要約

1994-02-28/03-04 の Ha Noi 第2回会合決議。registry date は1994-03-16。
Internal Supplementation、Horizontal Supplementation、Vertical Extension の用語と、Vietnam の V-column を定めた。
統合規則・source standards と variant-related matters を別の Annex として準備する方針を置く。
編集体制、入力資料、次会合への提出作業も具体化する。

## 決定・Action Item

- 項目3: 第1 Annex に統合規則と各文字の source standards、第2 Annex に variants の同定・source mapping・分類を置く。前者は T. Koike が担当する。
- 項目4–5: 拡張の3方式と V-column の定義は [canonical event](../events/irg-2-extension-terminology-and-v-column.md)を参照。
- 項目6–9: ZHOU Yongjun を Chief Editor とし、既存統合 repertoire の database 利用、新しい補充用統合規則、BMP 配分は WG2 の責任であることを記す。
- 項目13・16: components の定義を議論し、Vietnam に Chu Nom の辞書を特定・配布するよう求める。
- 項目17–23: internal / horizontal repertoire の提出準備、Editorial Working Group、Akio Kido の新 Rapporteur 受入を記録する。

## 後続決定

[第3回会合](../meetings/irg/irg-meeting-3.md)の Annex・提出 schedule へ続く。
