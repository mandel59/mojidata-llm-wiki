# IRG N2986

## 要約

IRG N2986 は、China / Tao Yang による IRG N2956 への feedback である。
『中国大百科全书』第一版由来の5字の問題指摘を支持し、glyph 修正2件と source reference 修正3件を分けて提示する。
U+2AE99 は青銅器銘文を再検討して原提案とは異なる glyph と15画を示し、U+2B26F は GU ではなく GCESI reference を提案する。
member body の修正案であり、IRG の会合決定や確定 Unihan data ではない。

## フィードバック内容

| 対象 | China の修正案 |
| --- | --- |
| U+2AE99 | glyph を ⿰⿳爫幺又𤰔 へ変更。total strokes は17 → 15、`GBK-3900602` は維持。 |
| U+2B0AF | glyph は維持し、`GBK-5302460` → `GBK-5301480`。 |
| U+2B26F | glyph は維持し、`GBK-4205490` → `GCESI-00562`。『南北史补志』を代替 evidence に示す。 |
| U+2B622 | glyph を ⿰马呇 へ変更。total strokes は10、`GBK-5208925` は維持。 |
| U+2B720 | glyph は維持し、`GBK-2104800` → `GU-2B720`。将来の別 glyph 案は今回の更新表に含めない。 |

文書は百科事典を二次資料と位置づけ、転記や校正の限界から、複数の裏付けがない場合は primary submission evidence ではなく索引として使うべきだと論じる。これは China の資料評価であり、一般的な IRG rule の新設を記録するものではない。

## 後続決定

[IRG N2935](irg-n2935.md) の2026-10-12版は Section 9.1 に掲載する。font appendix を伴う修正案であるが、採否と Unicode / ISO への反映は後続 recommendation / action items で確認する。

## 論点

[IRG N2956](irg-n2956.md) / [IRG N2957](irg-n2957.md) と比べ、glyph correction と evidence replacement の具体的な選択が進んだ。glyph と source reference のどちらを直すかは文字ごとに異なる。PDF 自身の日付は2026-10-10、registry date は2026-10-11。
