# L2/26-251

## 要約

Sridatta A / Srinidhi A が Malayalam の Vedic Double Anusvara 1文字を提案する。
U+0D51 MALAYALAM LETTER VEDIC DOUBLE ANUSVARA を候補とし、Lo / Indic_Syllabic_Category=Bindu を求める。
Taittirīya Kṛṣṇa Yajur Veda の印刷資料で、既存 U+0D04 と対比される用例を示す。
文書日付は 2026-08-22、registry date は 2026-10-13。

## 提案内容

- Devanagari U+A8F4 / Grantha U+1135F に相当する sign を Malayalam へ script-specific に追加する案。
- Grantha U+1135F と別符号化するか統合するかについて feedback を求める。
- U+0D04 の短い stroke と小さい circle は glyph variation として font で処理する。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

既存 Vedic anusvara の glyph variation と、新しい double anusvara の identity を分ける。
