# L2/26-244

## 要約

Kirk Miller が South Slavic の音声・方言表記に使う Cyrillic modifier letters 6文字を提案する。
Cyrillic Extended-D の U+1E06E..U+1E073 を候補とする。
5 superscript letters と subscript soft sign の用例を、1913年から現代の文献に示す。
文書日付は 2026-09-02、registry date は 2026-10-12。

## 提案内容

- LJE / NJE / DJE / TSHE / DZHE と CYRILLIC SUBSCRIPT SMALL LETTER SOFT SIGN が対象。
- 全6字を General_Category=Lm とし、前者には <super>、soft sign には <sub> の compatibility decomposition を提案する。

## 論点

既存 Cyrillic Extended-D の gaps を埋める追加であり、新 script の提案ではない。
