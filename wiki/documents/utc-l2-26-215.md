# L2/26-215 / IRG N2944

## 要約

`L2/26-215` / `IRG N2944` は IRG Meeting \#67 向けの US/Unicode activity report である。文書日付は 2026-09-16、UTC Registry 登録日は 2026-09-17 で、Unicode 18.0 が 2026-09-16 に release されたことを報告する。

Unicode 18.0 の CJK-related highlights、次期 IRG working set への約200 ideographs の見込み、`kTabooVariant` proposal、IVD Moji_Joho collection、WS2024 Version 5.0 review、UTC CJK & Unihan Working Group の予定をまとめる。

## 報告内容

| 区分 | 内容 |
| --- | --- |
| Unicode 18.0 | Small Seal 11,328 characters、CJK additions、CJK Strokes SVSes、Unihan provisional properties、UAX \#60、Unihan tools / UTNs の更新を報告。 |
| next working set | IRG M66.08 に応じ、UTC は次期 IRG working set に約200 ideographs を提出する見込み。 |
| Unihan | [L2/26-216](utc-l2-26-216.md) の provisional `kTabooVariant` と draft UTN \#63 を IRG experts に案内。 |
| IVD | 2026-08-03 の第10版 IVD で Moji_Joho collection に8 sequences が追加された。 |
| WS2024 | UTC-assigned serial 02334〜03503 の Version 5.0 review と submitter responses を報告。 |

## 後続決定

これは activity report であり、IRG Meeting \#67 の recommendation ではない。会合の決定は将来の `IRG N2946` recommendations / action items で確認する。

## 論点

Unicode 18.0 release の成立確認には UTC \#188 minutes と本報告を組み合わせる。前者は authorization、後者は実際の publication を記録しており、時点と文書の役割が異なる。
