# PRI 259

## 要約

`PRI #259` は、Moji_Joho collection とその IVS を同時に登録する public review である。
提出者は ITSCJ / IPSJ、representative は Tetsuji ORITA。review closing date は 2014-03-10。
Moji Jōhō Kiban の行政用途で必要な字形区別を、既存漢字と variation selector の組合せで表す。
archive は 2014-05-16 版 IVD への登録完了を明記する。

## 提案内容

collection identifier は `Moji_Joho`、sequence identifier pattern は `MJ[0-9]{6}`。文字情報基盤整備事業の戸籍・住民基本台帳などで必要な字形を対象とする。未符号化文字の標準化と、符号化済み文字の字形区別を分け、後者を IVS 登録で扱う。

review は、提案字形が base character の glyphic subset であるか、collection の目的に適合するかを確認する。Hanyo-Denshi と同じ glyphic subset を表す場合は既登録の base / VS pair を共有する。

## 後続決定

公式 archive は、2014-05-16 版で Moji_Joho collection と 10,710 IVS が登録され、そのうち 9,685 が Hanyo-Denshi と共有されたと記録する。後続の追加登録は [PRI \#354](pri-354.md) と [PRI \#546](pri-546.md) で追う。

## 論点

同じ base / VS pair が複数 collection に属し得るため、collection ごとの登録件数を合計しても distinct IVS 数にはならない。登録日の履歴は [IVD topic](../topics/ideographic-variation-database.md) を参照。
