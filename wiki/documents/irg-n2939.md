# IRG N2939

## 要約

`IRG N2939` は TCA の Meeting \#67 activity report である。IRG M66.08 が次期 Working Set の各提出を最大 2,500 文字としたことを受け、TCA は約 1,500～2,000 文字を提出する計画を示す。

候補は人名・地名、Minnan / Hakka の文字、歴史文献の文字から集める。これは提出予定の報告であり、候補文字の受理や符号化の決定ではない。

## 報告内容

- 人名・地名資料には Ministry of the Interior の戸政・地政部門や Judicial Yuan の資料を含む。
- Minnan / Hakka の資料として呉守禮《國臺對照活用辭典》を挙げる。
- 歴史文献では Ministry of Education《異體字字典》と、李豐楙らによる《道法會元》を中心とする道教文字の収集を挙げる。

## 後続決定

提出件数は TCA の計画であり、IRG の採択数ではない。実際の submission と review は次期 Working Set の文書で確認する。
