# L2/26-154

## 要約

`L2/26-154` は PAG が UTC Meeting \#188 に提出した、Unicode properties and algorithms に関する55ページの feedback disposition と recommendations である。Core Specification、UCD、Bidi、normalization、line breaking、segmentation、collation、UTS \#39、confusables、emoji を扱う。

Unicode 18.0 に向け、variation selector の非準拠な解釈、`Identifier_Type`、`Hntl` を含む mixed-script detection、ZWNJ 周辺の combining marks などに具体的な変更を勧告する。一部項目は `No Action` または将来版への action item として区別されている。

この文書は working group の勧告であり、UTC の採択結果は [UTC \#188 minutes](utc-l2-26-151.md) の numbered consensus で確認する。

## 決定・Action Item

- Core Specification §3.6.2 に、未割当 variation sequence と misplaced variation selector を規格外の用途で解釈しないという conformance note の追加を勧告する。
- Unicode 18.0 の `Identifier_Type` について、新規文字と Arabic / Hebrew combining marks の値を見直す。UTS \#39 の mixed-script detection に ISO 15924 の `Hntl` を取り込むよう勧告する。
- UTS \#39 の ZWNJ を含む識別子用正規表現では、ZWNJ 後の `Joining_Type=Transparent` を許す部分を除き、Arabic などの combining marks を joiner より前に置く指針を Core Specification に加えるよう勧告する。
- line break、grapheme / word segmentation、UCA、confusables data の個別 feedback にそれぞれ disposition を付ける。すでに data file が更新済みの項目は追加の UTC action を求めていない。

## 後続決定

[L2/26-151](utc-l2-26-151.md) の 188-C19〜C30 は、この PAG report から Unicode 18.0 に取り込む項目を UTC の決定として記録する。report 内の recommendation と、会合で採択された consensus を区別して読む。

## 論点

同じ report に即時の Unicode 18.0 data 修正、将来版への文言検討、`No Action` が並ぶ。実装時には report の提案文だけでなく、minutes と公開された final UCD / UAX / UTS の版を突き合わせる。
