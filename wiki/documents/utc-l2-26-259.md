# L2/26-259

## 要約

Andreas Stötzner が将来追加予定の letterlike symbols の U+1DB00 block 内配置を見直すよう求める。
N5335R3 に対する新規文字追加ではなく、letterlike forms の近接配置の修正案。
DOUBLE SMALL SIGMA / OMICRON UPSILON と FUNCTIO DIFFERENTIATA / DOUBLE X の位置交換を提案する。
文書日付は 2026-09-30、registry date は 2026-10-13。

## 提案内容

- U+1DB20 / U+1DB21 と U+1DB1E / U+1DB1F の位置を入れ替え、lowercase-like symbols を同じ column にまとめる。
- 文書は WG2 N5354 の future addition recommendation を前提として SEWG / UTC へ検討を求める。

## 論点

表題は5 symbols の re-order とするが、本文が明示する swap は4文字。chart 全体の配置意図と正式 disposition は区別する。
