# L2/26-212

## 要約

`L2/26-212` は UTC 162-A2 への報告として、UAX \#29 の `Word_Break` を `Other` から `ALetter` に変更する候補を示す。音声転写、声調記号、Bopomofo、Arabic、Mongolian の用法を検討する。

既存の `Alphabetic` や identifier 関連 property を一括で変える提案ではなく、word segmentation の振る舞いを対象にする。UAX \#29 と Core Specification にある `gc=Sk` と `ALetter` の関係の説明も修正するよう求める。

## 提案内容

- U+02D9、U+0888、U+1807、U+180A、U+2E32、U+2E35..U+2E39、U+A700..U+A707、U+AB6A..U+AB6B、U+10EC9..U+10ECA を `Word_Break=ALetter` に変更する。
- `U+A700..U+A707` は Latin / IPA との音声転写に使われ、`U+02D9` は Bopomofo の neutral tone mark として音節に接することを根拠にする。
- modifier symbols (`gc=Sk`) にも明示的な `ALetter` 例外があることを UAX \#29 と Core Specification の説明に反映する。

## 後続決定

2026-09 時点では提案であり、property value の変更が採択・公開されたことを示す文書ではない。関連する UTC 162-A3 の review notes は [L2/26-214](utc-l2-26-214.md) に分ける。

## 論点

提案者は、文字が単語や転写の一部として隣接する文字と切れないかを `ALetter` の判断基準にする。Unicode 18.0 の final data と、将来版に向けた提案は区別する。
