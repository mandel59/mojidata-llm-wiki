# IRG N2988

## 要約

Suisenn が G-source style に合わない6 glyphs の修正を China NB へ求める。
U+33018 / U+2D447 と、U+3301D / U+3301F / U+33020 / U+33022 の二群を扱う。
後者は他 component に場所を譲る N stroke（捺）を D stroke（点）へ変えるべきとする。
PDF 日付は 2026-09-06、registry date は 2026-10-13。

## 提案内容

- 比較 glyphs として U+30019 / U+4ECE、および U+2CEAD / U+33019 を示す。
- target code points と reference glyphs は画像の表にある。
