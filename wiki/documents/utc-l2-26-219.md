# L2/26-219

## 要約

新しく作られた script の利用を支える application 向け script packages と、実現可能性を調査する ad-hoc group を提案する。
安定性・利用実績の審査に時間を要する間も、community がデジタルで試用・改善できる手段を検討する。
本文日付は2026-10-21、registry date は2026-10-24。
作業部会設置も配布基盤も提案段階である。

## 提案内容

- Open Font License の font、Universal Shaping Engine が必要とする character properties、LDML keyboard layout を package に含める案。
- application が runtime に読み込み、community 内の短い message の交換と実利用データの収集を支える。
- ad-hoc group が goals / non-goals、実装案、vendor と community の要件、Unicode の配布資源を調査して UTC に報告する。
- digital signatures などを含む package の安全性と、符号化後の安定性維持を論点にする。
