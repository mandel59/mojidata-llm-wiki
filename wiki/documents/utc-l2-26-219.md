# L2/26-219

## 要約

L2/26-219 は、Mongolian block を共用する Hudum、Todo、Sibe、Manchu の shaping の曖昧さを整理する。
文字の形、FVS の有効性、default form の三種類の差を取り上げる。
既存 OpenType language system tags では Ali Gali と通常の表記体系を十分に分けられないとして、三つの対応案を示す。
新文字の repertoire 提案ではなく、font と language tagging に関する guidance を求める。

## 提案内容

- Hudum と Sibe / Manchu の U+182E の final form、U+182A と FVS1 の扱いの違いを例示する。
- `MNG`、`TOD`、`SIB`、`MCH` による localized shaping と、Hudum / Todo / Manchu Ali Gali を区別する tag の不足を説明する。
- Ali Gali 専用 language tags、他 writing system の実在形を表示する方式、default で無効の font feature に分ける方式を比較し、適切な guidance を求める。
- 本文の日付は 2026-07-26。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

code point の共用と、writing system ごとの期待する字形・FVS の有効性を分ける必要がある。L2/26-091 の standardized variants deprecation と関連するが、この文書はその採択を記録しない。
