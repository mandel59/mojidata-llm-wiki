# IRG N2963R3

## 要約

`IRG N2963R3` は Roy Wang が41件の GZJW-source representative glyph の修正を求める提案である。IRG N1519 に示された原資料を再照合し、部品の正規化や誤って写された可能性のある glyph を個別に挙げる。

U+2A705、U+2BA08、U+2BCCF などで原資料の筆画・部品との差を論じる。U+2B8BF、U+2B8EE、U+2BA44 の部品の扱いは [IRG N2962R2](irg-n2962r2.md) と見解が異なり、Meeting \#67 の検討対象となる。

## 提案内容

- 41件の glyph について code point、現在の字形、提案理由、原資料の図版を対応付ける。
- IRG N1519 の evidence を参照し、たとえば U+2A705 の筆画、U+2BA08 の `火`、U+2BCCF の `屮` などの形を検討する。
- 一部では China NB が GB 18030 等の字形規約を修正するか、G-source conventions を明確にすることも求める。

## 後続決定

[IRG N2935](irg-n2935.md) は本提案と `IRG N2962R2` の相違を Meeting \#67 agenda Section 9.1 に置く。proposal は IRG の正式な glyph change 決定ではない。

## 論点

原資料の字形、現行 G-source の規約、部品の同一性の判断を区別して review する必要がある。特に3文字の争点は両提案の図版を参照する。
