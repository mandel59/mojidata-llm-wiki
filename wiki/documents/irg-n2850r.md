# IRG N2850R

## 要約

`IRG N2850R` は IRG Principles & Procedures Version 18 Draft 2 である。CJK Unified Ideographs の submission、unification、evidence、working set review、IRG meeting での処理、WG2 への提出までの手順を定める改訂草案である。

原文には draft の変更表示と review notes が含まれる。IRG agenda は 2026-04-17 に Version 18 が公開されたと報告するため、この草案を最終版と同一視しない。

## 提案内容

- 漢字の同定、非同源規則、source evidence、提出 data と font、quality assurance の条件を整理する。
- working set の checking、ORT を使う record-based discussion、WG2 への submission を段階別に記す。
- Annex に IDS matching、UNC、source references、disunification / mapping errors などの指針を置く。

## 後続決定

[IRG N2935](irg-n2935.md) の M66.20 follow-up は、IRG Convenor が Version 18 を 2026-04-17 に公開したと記録する。SC 2/AG 1 の revised Terms of Reference は [IRG N2967](irg-n2967.md) に分ける。
