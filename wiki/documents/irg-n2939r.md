# IRG N2939R

## 要約

IRG N2939R は、TCA の Meeting \#67 activity report の改訂版である。
次期 Working Set に約1,500～2,000字を提出する計画と資料群は初版 IRG N2939 を引き継ぐ。
IRG N2972 の horizontal extension に関し、5字への私的 feedback を受け、審議時に glyph を説明する予定を追加する。
これは source owner の活動報告であり、glyph corrections の承認ではない。

## 報告内容

- 人名・地名、Minnan / Hakka、歴史文献と Daoist characters を次期 submission の主な資料とする。
- IRG N2972 の U+203A6、U+23E25、U+2403D、U+23CFE、U+25337 に experts から suggestions が寄せられたと報告する。
- feedback の具体的な変更案や採否は記載せず、会合で個別の glyph を説明するとする。

## 後続決定

本報告は member body の活動・計画であり、会合の決定や受理件数ではない。後続の submission と会合記録で進捗を確認する。

## 論点

提出予定数は IRG M66.08 の各 submission 最大2,500字という枠内の TCA の計画である。5字の feedback は source-owner の確認事項として、700字の提案全体の採否とは分けて追う。
