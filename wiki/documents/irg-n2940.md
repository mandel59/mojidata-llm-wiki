# IRG N2940

## 要約

`IRG N2940` は、JSC 2（Japan の SC 2 mirror committee）の Shuichi Tashiro による Meeting \#67 activity report である。JSC 2 は IRG 活動への参加再開を決定したと報告する。

当初は mailing list への再登録と IRG 会合への参加から始め、利用可能な資源に応じて貢献を段階的に広げる。Working Set review の全面再開や個別提案の採択までは表明していない。

## 報告内容

- [IRG N2367](irg-n2367.md) で示された、2019 年以降は IRG Working Set review を行わず SC 2 process で review する方針を振り返る。
- [IRG N2721](irg-n2721.md) の 2024 年の復帰要請を受けて JSC 2 が検討した結果、IRG 活動への参加再開を決めたと述べる。
- IRG の漢字研究を尊重しつつ、industrial standard としての backward compatibility と安定した発展の観点から Japan の参加者が討議に貢献すると期待する。

## 後続決定

参加再開は JSC 2 が報告した方針である。具体的な review 担当や Working Set への寄与は後続会合・文書で確認する。
