# L2/26-239

## 要約

SEW が UTC \#189 に提出する script proposals の review と勧告集。
Maya 513、N’ti 47、Ndiko Jonam 69、KORE SEBELI 93文字などの provisional assignment を勧告する。
新文字・Leibniz symbols・Indic properties・注釈変更を扱い、証拠や仕様が不足する提案には追加調査を求める。
SEW-189-C / A 番号は勧告側の番号であり、UTC の採択記録ではない。

## 決定・Action Item

- 新script の勧告と legal clearance の再確認は [SEW \#189 script 勧告](../events/sew-189-script-provisional-assignment-recommendations.md) に集約する。
- §2: Arabic U+0892、Devanagari final anusvara / continuation sign / correction mark、Latin・Cyrillic の追加を勧告。
- §3: Leibniz の letterlike 5文字と miscellaneous 10文字を勧告。balanced ternary と Big5 double arcs は実用・interchange evidence の追加を求める。
- §4: L2/26-255 / 256 の InSC / InPC 更新を勧告。U+0CD5 の property change は影響と canonical equivalence の問題から支持しない。
- §5: Vithkuqi annotations と cedilla guidance の変更を勧告。Mongolian positional variants では未定義位置に別言語の既存字形を使うことを許容し、UTC action は求めない。
- Zou / Kadu / Quikscript / Wagindara には利用・安定性・interchange の証拠等を求め、Wei Rma は encoding model の review と SC 2 feedback を提案する。

## 後続決定

[UTC Meeting \#189](../meetings/utc/utc-meeting-189.md) の審議資料。2026-10-25 時点では会合前であり、採択・承認の結果は後続 minutes で確認する。

## 論点

文書中の勧告・計画と UTC の決定を分けて読む。draft のコード位置・property・日程を確定仕様として扱わない。
