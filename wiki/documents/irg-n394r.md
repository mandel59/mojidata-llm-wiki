# IRG N394R

## 要約

WG2 第31回の結果を受けた Rapporteur の改訂 action plan 案。
1996-08-27 の文書を09-16に改訂し、09-20までの確認を求める。
IS/HS の誤り修正・font、Extension A の BMP 照会、composition の質問への回答作業を提案する。
取消表示や無回答を支持とみなす確認手順を含むが、最終承認された action items とは断定しない。

## 提案内容

- IS/HS: Annex の review、2回の errata review、source-owner の font 修正・固定、印刷用 chart の提出を提案する。
- Extension A: 追加 evidence、font、印刷などの一部項目は Cancelled。残る支持要請と区別する。
- Composition: N392 に基づく radicals / components の整理、選択規則、N310 改訂、各 body の回答を提案する。comments 文書は N392 であり N393 ではないと明記する。
- 表紙の status は To be finalized。registry date は1996-08-27、本文の revised date は09-16。

## 後続決定

正式な WG2 決議は [N391](irg-n391.md)を優先する。N394R の確認が最終的に完了したかは、この提出案だけでは確定しない。

## 論点

本文は M31.11 の引用で6,865字と記すが、一次決議 N391 は6,585字。文書番号対応にも誤記があるため、決議と正式文書の同定には N391 と catalog を使う。
