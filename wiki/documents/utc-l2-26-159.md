# L2/26-159

## 要約

`L2/26-159` は Charts Working Group が UTC Meeting \#188 に提出した report である。Unicode 18.0 code charts の公開方式、versioned URLs、補助 charts、ISO/IEC 10646 charts と beta feedback を扱う。

chart PDFs の permissions password は beta charts で既に撤去済みと報告し、collation / casing charts の近代化を予定する。将来の chart URL 移行案は報告時点の plan であり、実際の公開先は release artifact で確認する。

## 報告内容

- `unicode.org/charts/` の一部を `/Public/<version>/charts/` に移し、旧 URL を latest version に redirect する計画を示す。delta charts と Unihan の一部資料は別扱いにする。
- WG2 M73.03 と SC2 approval を受け、ISO/IEC 10646 第7版の code charts を Unicode site 上の外部ファイルとして提供する予定を説明する。
- PRI \#548 とその他の chart / names list feedback を整理する。

## 後続決定

[UTC \#188 minutes](utc-l2-26-151.md) と Unicode 18.0 の公開 charts で採択・実装された内容を確認する。
