# L2/26-254

## 要約

Sridatta A / Srinidhi A が Sinhala の nukta 使用を提示する preliminary document。
Tamil の ṟa / ḻa と、Hindi / Perso-Arabic consonants の Sinhala transliteration を例示する。
専用 nukta の encoding・表現について SEWG / experts の review を求め、確定 repertoire は置かない。
文書日付は 2026-09-21、registry date は 2026-10-13。

## 報告内容

- Sri Lanka の bilingual primers と学習書にある RAYANNA / LLA、Hindi / Urdu 用 consonants と下点の組合せを示す。
- Core Specification が Sinhala block に nukta 未符号化と記すことを出発点にする。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

既存 combining dot による表現の可否、専用 Sinhala nukta の必要性、script property / shaping は後続提案で明確化する必要がある。
