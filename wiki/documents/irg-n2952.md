# IRG N2952

## 要約

`IRG N2952` は、IRG への ideograph submission と Working Set に Kangxi Radical Code の primary / secondary radical を割り当てる Version 1 の規則案である。2026-09-25 に公開され、Meeting \#67 agenda は IRG experts の review 対象としている。

形声字、独体字、その他の合体字の順に判断する。形声字では意符を優先し、secondary radical は文字を二通りに分析できる証拠がある場合に限る。単なる理論上の分解は根拠にしない。

## 提案内容

- 形声字では意符が radical ならそれを唯一の radical とし、そうでなければ音符、さらに意符内の radical を順に検討する。
- 独体字では中心を貫く縦画、見た目が最も近い radical、先頭または末尾の画を順に判断材料とする。末画が CJK Stroke N の場合は Kangxi Dictionary に合わせて 丿 に分類する。
- 囲み構造では外側の component、左右または上下の外側が一つの radical を構成する場合はその radical を採る。それ以外の合体字では top-level component の radical のうち画数が最大のものを優先し、該当しない場合は residual strokes が最少の component から選ぶ。

## 後続決定

[IRG N2909](irg-n2909.md) M66.19 が [IRG N2925](irg-n2925.md) に基づく condensed rules 文書の準備を求めた。この Version 1 の採否は Meeting \#67 の recommendations 公開後に確認する。

## 論点

この文書は [IRG Indexing Rules](../topics/irg-indexing-rules.md) の radical assignment を具体的な判断順序へ落とし込む。IRG N2925 の review workload に関する問題提起と、ここに記された割当規則を分けて読む。
