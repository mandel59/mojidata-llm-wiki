# L2/26-140

## 要約

L2/26-140R は miscellaneous mathematical symbols 10文字を求める5th revision。
U+1DB22..U+1DB2B の案を維持し、PROPORTION WITH ONE STROKE と U+22A4 DOWN TACK を分ける根拠を追加した。
math axis 上の横棒と相対的な幅を区別点とし、UTC \#188 の追記要求に対応する。
PDF は 2026-10-08、registry date は旧版と同じ 2026-06-09。改訂日は本文から読む。

## 提案内容

5th revision は repertoire と基本方針を維持し、U+1DB24 の横棒を math axis に置くことと、U+22A4 より幅広い用例を追加する。これは後続 proposal の回答であり、UTC \#188 が10字を採択したことを意味しない。

| 区分 | 内容 |
| --- | --- |
| scope | historical mathematics に現れる miscellaneous symbols。 |
| repertoire | 10 characters。過去 revision で combining characters は別 proposal へ分離された。 |
| project context | Philiumm project、Landesbibliothek Hannover、Leibniz-related source editing。 |
| review history | SEW / UTC feedback に基づき、candidates の削除、glyph-axis clarification、name revision を行った。 |

## 後続決定

[UTC \#188 minutes](utc-l2-26-151.md) は U+22A4 DOWN TACK との disunification rationale を proposal に追記するよう求めたが、文字を provisionally assign する consensus は置いていない。

## 論点

### historic math symbols の分割提案

Leibniz / historic math 系の提案は、ambiguous signs、letterlike symbols、combining overlays、miscellaneous symbols、delta chart correction に分かれている。`L2/26-140` はそのうち small collection の symbol repertoire を扱う。
