# L2/26-145

## 要約

L2/26-145R2 は Dresden / Madrid / Paris codices を対象にする Codical Maya proposal Version 1.5。
PDF 日付は 2026-10-07、registry date は 2026-10-12。Version 1.2 から改訂された。
property tables は477 signs と4 special signs、計481文字、さらに30 format controls を列挙する。
Codical set を base とし、Classic Maya などは extensions で扱う方針を維持する。
WG2 \#73 の review request は過去の Version 1.0 に対するもので、Version 1.5 の採択を記録する後続文書は未確認。

## 提案内容

| 区分 | 内容 |
| --- | --- |
| scope | Postclassic codical subset。Dresden、Madrid、Paris codices の hieroglyphs を対象にする。 |
| corpus size | 210 extant pages、7,122 glyph-blocks、17,147 graphemes という corpus statistics を示す。 |
| encoding model | Maya signs を abstract characters として扱い、glyph blocks / affixation に format controls を用いる。 |
| roadmap | Codical set を base とし、Classic Maya / other periods は extensions として追加する。 |
| script property | existing Maya numerals の Script=Common を Mayan_Hieroglyphs へ再割当てする必要を示す。 |
| properties | Version 1.5 は General_Category、Word_Break、Grapheme_Cluster_Break、Line_Break、Script などの proposed values を追加した。 |

format controls は、horizontal / vertical / ligature / insertion joiners、color・mirror・rotation modifiers、segment delimiters、3 段階の compression controls、15 種の damage modifiers から成る。variation selector は shape variants に用い、rotation / reflection は format controls で扱う。文書は Dresden Codex page 72 の prototype typesetting で、この composition model を例示する。

## 後続決定

[WG2 N5354](wg2-n5354.md) の M73.14 は、`WG2 N5366` と `WG2 N5367` を National Bodies と liaison organizations が WG2 \#74 までに review するよう求めた。これは採択 recommendation ではなく、draft の repertoire、unification、format-control model を次会合まで検討するための review request である。

[UTC \#188 minutes](utc-l2-26-151.md) と `L2/26-158` は両 Maya proposals を reference list に含むが、採択 consensus / action item は置いていない。したがって UTC \#188 で採択されたとは扱わず、WG2 M73.14 の review request と Version 1.5 proposal の review を続ける。Related proposal は [L2/26-146](utc-l2-26-146.md) Maya Hieroglyphs Extended-A である。

## 論点

### codical subset を base encoding にする

Codical Maya は Classic-period full repertoire より狭いが、surviving codices で standardized subset として比較しやすい。proposal は、まず codical set を符号化し、Classic Maya を extension として足す CJK / Egyptian Hieroglyphs に近い model を採る。

### format controls と glyph block composition

Maya hieroglyphs は quadrat / glyph block composition を持つため、単純な linear character sequence だけでは表現できない。format controls を導入する model は、encoded repertoire だけでなく rendering model の review を必要とする。

### draft 内の repertoire 表現

Version 1.5 の Introduction は480 signs、roadmap は481 characters と記し、property tables の U+15500..U+156DC（477）と U+156EC..U+156EF（4）は計481に対応する。format controls は U+15700..U+1571D の30文字である。冒頭の総数は table と一致しないため、確定 repertoire として転記しない。

p.3 の roadmap text は reserved range を U+15720..U+157FF としながら1,024 code points と説明するが、その範囲は224 positions である。p.42 の EastAsianWidth table にも U+1566C..U+156DC の重複 range がある。画像でも照合し、block / future extension の境界と property table は後続 revision で整理する必要がある。
