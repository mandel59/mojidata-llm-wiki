# L2/26-145

## 要約

L2/26-145R4 は Dresden / Madrid / Paris codices を対象にする Codical Maya proposal Version 1.81。
PDF と registry の日付は2026-10-27。Version 1.6 からの改訂でも、481 + 32 = 513文字と2 block の範囲は維持する。
Mayan Hieroglyphs の481文字と、別 block の32 format controls、計513文字を提案する。
Classic Maya などは別の extensions で扱う方針を維持する。
SEW の provisional assignment 勧告は [canonical event](../events/sew-189-script-provisional-assignment-recommendations.md) に集約し、UTC の採択とは分ける。

## 提案内容

| 区分 | 内容 |
| --- | --- |
| scope | Postclassic codical subset。Dresden、Madrid、Paris codices の hieroglyphs。 |
| signs | U+15500..U+156DC の477 signs と U+156EC..U+156EF の EMPTY / LOST / ERASED / BLANK SIGN、計481文字。 |
| blocks | Mayan Hieroglyphs: U+15500..U+156EF。Mayan Hieroglyph Format Controls: U+156F0..U+1570F。 |
| controls | 32文字。joiners、color / rotation / reflection modifiers、segment delimiters、compression controls、damage modifiers。 |
| properties | UnicodeData、Blocks、EastAsianWidth、LineBreak、GraphemeBreak、WordBreak 等の proposed data と names list を示す。 |
| roadmap | Codical set を base とし、Classic Maya / other periods は extensions で追加する。 |

Version 1.6 で、Version 1.5 の30 controls から32へ変更し、controls の開始位置を U+15700 から U+156F0 へ移した。rotation / reflection の組合せを個別の controls として示す。color modifier は直前の sign を赤く表示する用途とする。

## 論点

### repertoire と property ranges の改訂

Version 1.81 は冒頭・block definitions・names list で481 + 32 = 513文字を示す。旧 Version 1.5 の冒頭480 / tables 481という不一致や、EastAsianWidth の重複 range を現在の提案の説明として持ち越さない。最新版の EastAsianWidth は signs と各 controls を分けた範囲を列挙している。

### format controls と rendering

glyph blocks と affixation を表す model は code point の一覧だけで完結しない。位置関係・ligature・segment・damage・color の rendering behavior と、別 proposal である Extended-A との関係を確認する必要がある。

### 既存 Mayan Numerals の Script 値

Version 1.81 の本文 p.8 は U+1D2E0..U+1D2F3 の `Script=Common` から `Mayan_Hieroglyphs` への変更を今回は提案せず、別提案で扱い得るとする。一方、Properties の Scripts.txt 案 p.69 には同範囲を `Mayan_Hieroglyphs` とする行が残る。本文とデータ案が一致していないため、20文字の Script 変更が今回の提案・採択に含まれるとは断定できない。513文字は新規 repertoire の数である。
