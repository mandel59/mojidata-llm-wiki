# IRG N2972

## 要約

IRG N2972 は、TCA が700件の T-source horizontal extensions を提案する文書である。
対象は Ministry of the Interior の household registration に使われる人名文字と CNS 11643 Web から集めた TA-source characters である。
提案は既符号化の CJK Unified Ideographs Extension B に source references と glyphs を対応付ける。
2026-10-08版の IRG N2935 は Section 8.5 に本提案を掲載し、Meeting \#67 の審議入力とする。

## 提案内容

- 700文字の T-source references と T-glyphs を Extension B code points に対応付ける。
- 根拠資料は Ministry of the Interior の人名用文字資料と CNS 11643 Web（全字庫）。
- 文書は TCA の member contribution で、IRG による審議・承認を記録しない。

## 後続決定

[IRG N2935](irg-n2935.md) の2026-10-08版は Section 8.5 に本提案を掲載する。[IRG N2939R](irg-n2939r.md) は5字の glyph を審議時に説明すると報告する。agenda 掲載と source-owner の説明予定を採択と区別し、採否は会合後の recommendation と action items で確認する。

## 論点

本提案は新しい code point を求めず、既存 Extension B ideographs に T-source data を追加する horizontal extension である。source owner の資料と proposed glyphs の review が必要となる。
