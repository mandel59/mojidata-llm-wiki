# L2/26-243

## 要約

Karl Pentzlin が Kingsley Read の Quikscript を Shavian から独立した script として符号化する案を提出する。
U+16080..U+160AF の48 slots に44 letters と2 punctuation marks、計46文字を置く。
Junior / Senior Quikscript の形を別文字にせず、接続表示の違いを font / rendering で扱う。
本文は Draft 2026-08-24、registry date は 2026-10-12。

## 提案内容

- letters は U+16080..U+160AB、LEFT / RIGHT ANGLED PARENTHESIS は U+160AC / U+160AD を候補とする。
- Shavian との相違として文字 identity、alphabetic order、両 script を混ぜた文書、fallback legibility、Senior の接続表示を挙げる。
- Script、BidiBrackets、BidiMirroring、LineBreak、NamesList、collation と Core Specification text の案を含む。
