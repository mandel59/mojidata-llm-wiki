# L2/26-258

## 要約

Dr. T Marvin Zou が Zou / Zoulai script と numerals の符号化を提案する。
M. Siehzathang の alphabet、community publications、Keyman layout、PUA font mapping を提示する。
文字 inventory と UnicodeData 案は対応に不一致があり、正式な位置・総数を確定できる段階ではない。
文書日付は 2026-08-04、registry date は 2026-10-13。

## 提案内容

- Section 7 は U+E040..U+E049 を digits、U+E020..U+E03A を vowel signs / marks とする。
- Section 8 の UnicodeData sample は U+E040..U+E049 を small letters、U+E020..U+E029 を digits とする。末尾注記は再び E040..E049 を numerals とする。
- Section 5 の27字表と uppercase / lowercase、combining signs、property sample の対応は整理が必要。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

PUA values は font の暫定 mapping であり、Unicode の正式割当ではない。p.15–16 を画像でも照合し、内部矛盾を補正せずそのまま review issue として残す。
