# L2/26-252

## 要約

Francesco Catoni が North / South Turkestan Brāhmī を既存 Brahmi block 内で扱う preliminary proposal を提出する。
Khotanese、Tocharian、Tumshukese、Uigur などの不足文字・結合機能を整理する。
別 script blocks の追加より、共通文字と font による style 差を軸にする案。
文書日付は 2026-09-11、registry date は 2026-10-13。

## 提案内容

- AE vowel、特殊 consonants、Sonderzeichen selector、bar virama、conjunct joiner などの候補と manuscript sequences を示す。
- CONJUNCT JOINER は vowel の後にも conjunct が続く場合を表し、既存 VIRAMA の拡張で扱うか別 code point とするかを未決とする。
- Rouran-specific code points は今回求めず、必要に応じて比較用例だけを挙げる。

## 論点

script identity と block 方針、既存 Brahmi shaping の拡張、新しい control の semantics が中心。preliminary 案の encoding sequences を確定仕様として扱わない。
