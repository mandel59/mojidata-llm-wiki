# IRG N2987

## 要約

IRG N2987 は、Wang Xieyang が IRG N2984 の15字への指摘に回答した feedback である。
U+217B2 と U+28545 は修正すべきだとし、他の文字では実際の使用、historical evidence、関連字との glyph style の一貫性を維持理由に挙げる。
一律に特定の normalization standard へ合わせる方針には同意せず、具体的な標準のない字では使用実態を優先する考えを説明する。
回答者の修正意向であり、IRG の承認や IRG N2929R / 正式 data の更新完了を示す文書ではない。

## フィードバック内容

| 対象 | 回答 |
| --- | --- |
| U+217B2 | 丂 component を feedback に従って修正する。 |
| U+28545 | ⿺辶垔 へ修正する。Founder Song – Population Information の U+EEDB は本来この形であり、database の font configuration error が原因だったと説明する。 |
| U+23F40 | U+EBDA の人名用 font glyph と合わせるため維持する、と理由を訂正する。 |
| U+28908 | Tao Yang と検討し、学術的な隶定字の説明に役立つとして中央の曰を支持する。 |
| U+31286 / U+9D75 | URO の鵵を変えず glyph style をそろえるため、U+31286 も維持する意向を示す。 |
| U+3297F | 『查姓字拼音、四角号码对照簿』の形に合わせたと説明する。 |

文書は『古籍印刷通用字规范字形表』の番号を `GB/Z 40637-2021` と訂正し、guidance standard の性格を挙げて、兔の避让は glyph choice の問題だと論じる。
