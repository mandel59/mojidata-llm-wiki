# IRG N2983

## 要約

IRG N2983 は、CheonHyeong Sim が U+2EA07 に統合された source glyphs の同一性を再検討した調査報告である。
IRG N2929R の新 G-source glyph が J / SAT-source と同様に一点多い形であることから、T / KP-source との統合が安全かを問う。
点のある形が顧だけでなく䫃の異体にもなり得るとし、SAT に Extension F 提出時の evidence の確認を求める。
具体的な処理案を強く支持せず、member bodies の討議を求める。過去の disunification を取り消す決定ではない。

## 報告内容

- [IRG N2786](irg-n2786.md) の U+FACB / U+2F9FF の分離と、[IRG N2834](irg-n2834.md) による U+2EA07 への統合案を背景に置く。
- [IRG N2929R](irg-n2929r.md) の `GCW-86725` は J / SAT-source 型の glyph で、T / KP-source より一点多い。14画形、15画形、避让のない16画形を区別して検討する。
- 著者は14画形を顧の異体、15 / 16画形を顧または䫃の異体になり得るものと読む。『教育部異體字字典』などを evidence にする。
- JMJ-059024 の『新大字典』evidence は顧を示すと確認する一方、SAT-source の判断材料は得られなかったとして、SAT に原資料の確認を求める。

## 後続決定

[IRG N2935](irg-n2935.md) の2026-10-12版は Section 7 に掲載する。具体的な再分離・source migration の採否は後続 recommendation で確認する。

## 論点

glyph の点の差、異体関係、source owner の意図を同じ根拠で決めないことが論点である。[IRG N2984](irg-n2984.md) の U+2EA07 feedback はこの報告へ参照を分ける。PDF 自身の日付は2026-10-10、registry date は2026-10-11。
