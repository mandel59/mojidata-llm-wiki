# L2/26-214

## 要約

`L2/26-214` は UTC 162-A3 に応じ、UAX \#29 Revision 36 の `Word_Break` review notes を再検討した報告である。U+058A ARMENIAN HYPHEN を `ALetter` から `Other`、U+FF0C FULLWIDTH COMMA と U+FF1B FULLWIDTH SEMICOLON を `MidNum` から `Other` に変えるよう提案する。

fullwidth punctuation の変更は、CJK 文中で数字の前後を誤って1語に結合する問題を扱う。文書は既存の annotated corpora と Wikimedia corpus の用例を検討するが、提案段階であり Unicode 18.0 の確定値ではない。

## 提案内容

- U+058A は行末で単語を分ける Armenian hyphen の用法から、一般の hyphen と同じ `Other` を提案する。Armenian の他の punctuation と Hebrew geresh の `ALetter` は維持する。
- U+FF0C / U+FF1B は通常の CJK punctuation として数字の間にも現れるため `Other` を提案する。文書内の SIGHAN 2005 corpus 調査では、影響される comma 24例中20例、semicolon 3例中3例が `Other` に合うと報告する。
- U+055F ARMENIAN ABBREVIATION MARK は別途調査とし、U+FE10 / U+FE14 の既存 `Other` は維持する。

## 後続決定

この文書は proposal で、UTC consensus や final data の変更を記録していない。modifier symbols を `ALetter` に追加する別の提案は [L2/26-212](utc-l2-26-212.md) を参照する。

## 論点

`MidNum` の価値は数字の区切り方に依存する。文書は fullwidth comma に例外的な数字用法があることも示すため、将来の disposition では改善と回帰を分けて評価する必要がある。
