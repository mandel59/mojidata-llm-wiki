# IRG N2945

## 要約

`IRG N2945` は Vietnam の Meeting \#67 activity report である。WS2024 に割り当てられた review を完了し、ORT の comments に回答していると報告する。

[IRG N2970](irg-n2970.md) の V-source horizontal extension 9,263 文字を提出し、資料が得られれば追加提案もあり得るとする。U+268A1 / U+268A2 については将来の glyph normalization proposal に変更案を含める予定であり、現時点の決定ではない。

## 報告内容

- V-source 9,263 件は Vietnamese documents における使用と読みを資料化しやすい文字群を選んだ。NomNaTong-Regular font の数百 glyph を修正し、既存 V-source glyph の形と揃えた。
- [IRG N2928](irg-n2928.md) / [IRG N2953](irg-n2953.md) の U+268A1 / U+268A2 では二つの component forms を有効と認めつつ、既存の他文字との一貫性から一方へ正規化する案を将来提出すると述べる。
- Nôm 辞典と主要文学作品に見える約 5,000 文字を、将来の符号化候補と見積もる。これは次期 Working Set への確定提出数ではない。

## 後続決定

glyph normalization と追加 horizontal extension は今後の提案予定である。Meeting \#67 の採否と Unihan / code chart の変更は後続文書で確認する。
