# L2/26-228

## 要約

Adam Victor が balanced ternary の負の単位桁 −1 を表す TURNED DIGIT ONE 1文字を提案する。
Number Forms の U+218C または空き位置を候補とし、Numeric_Value=-1 を求める。
Setun 関連文献を根拠に挙げる一方、その書籍の画像は入手できていないと本文に明記する。
文書日付は 2026-08-14、registry date は 2026-10-12。

## 提案内容

- General_Category=No、Bidi_Class=EN、ccc=0 とし、1桁の数値文字として扱う案。
- 文字 T、minus sign、1 + combining overbar による代用を、数値処理・表示・交換の観点から不十分とする。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

Numeric Type の記載は「Nu」であり、正式な Numeric_Type property value として転記しない。根拠として挙げる1963年書籍の図版不足も審議時の確認対象。
