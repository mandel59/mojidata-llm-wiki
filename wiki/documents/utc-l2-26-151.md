# L2/26-151

## 要約

`L2/26-151` は 2026-07-28/30 の UTC Meeting \#188 minutes である。Unicode 18.0 の repertoire / property / data / specification changes を最終化し、188-C47 で Unicode 18.0 と同期 UTS の release を 2026-09-16 target で authorize した。

会合は Chisoi の Unicode 18.0 からの延期、Small Seal algorithmic name、new character provisional assignments、PAG recommendations、CJK / Unihan data changes、Unicode 19.0 向け CJKV Components と `kIRG_SGSource` を含む48件の consensusを記録する。proposal の提出と UTC decision を区別するための一次ソースである。

## 決定・Action Item

### Unicode 18.0 release

- 188-C2 は Chisoi 40 code points の Unicode 18.0 承認を取り消し、provisionally assigned に戻した。
- 188-C3 は Small Seal 11,328 characters の algorithmic name を `SMALL SEAL CHARACTER-XXXXX` に変更した。
- 188-C19〜C30 は variation selectors、Joining_Type data、Bidi_Class、Line_Break、Indic_Conjunct_Break、UCA、UTS \#39 などの Unicode 18.0 changes を承認した。
- 188-C47 は会合の decisions / actions を取り込んだ Unicode 18.0、UTS \#10、UTS \#39、UTS \#46、UTS \#51、UTS \#58 の release を 2026-09-16 target で authorizeした。

### Script / character pipeline

188-C4〜C18 は Kannada、Tulu-Tigalari、Newa、Brahmi、Arabic、Latin、Leibnizian Ambiguous Signs、musical symbol などを provisional assignment / Unicode 19.0 targetへ進めた。Koré Sébèli、Ndiko Jonam、N’ti は追加確認が必要とされ、Codical Maya / Maya Extended-A には consensus が置かれていない。

### CJK / Unihan

188-C35〜C46 は `kRSUnicode`、`kIRG_GSource`、T-source glyphs、`RSIndex.txt`、458件の `kTotalStrokes`、U+16FE6 DOUBLE IDEOGRAPHIC FULL STOP、U+16FE5 WHITE IDEOGRAPHIC COMMA、CJK Unified Ideographs Components-A/B、`kIRG_SGSource`、Unikemet data changes を扱った。Components-A/B と `kIRG_SGSource` は Unicode 19.0 target である。

## 後続決定

[L2/26-215 / IRG N2944](utc-l2-26-215.md) は Unicode 18.0 が 2026-09-16 に release されたことを報告する。UTC \#188 の release authorization と実際の publication は [UTC \#188 Unicode 18.0 release authorization](../events/utc-188-unicode-18-release-authorization.md) に集約する。

## 論点

minutes の consensus は、working group report の recommendation をそのまま自動採択したものではない。採択、修正、保留を確認する際は、この minutes の numbered consensus / action item を優先する。特に Maya proposals は `L2/26-158` の reference list には現れるが、UTC \#188 の decision set には入っていない。
