# L2/26-161

## 要約

`L2/26-161` は UC Berkeley の Script Encoding Initiative (SEI) が UTC Meeting \#188 に提出した liaison report である。SEI が支援した提出済みの script proposals と、現在開発中の proposal を分けて示す。

Ndiko Jonam、N’ti、Codical Maya、Maya Extended-A、Lampungic、Vatteluttu などの作業状況を報告する。提出・資金支援・SEW review・UTC 承認はそれぞれ異なる段階である。

## 報告内容

- SEI-funded proposals の提出状況と、Kulitan、Linear Elamite、Masaba、Persian Siyaq、Proto-Sinaitic、Zou などの開発予定を列挙する。
- Codical Maya と Maya Extended-A は proposal が存在するが、この report 自体は符号化を決定しない。

## 後続決定

UTC \#188 での各 script の扱いは [minutes](utc-l2-26-151.md) と [SEW recommendations](utc-l2-26-158.md) で確認する。
