# L2/26-260

## 要約

Joint CLDR/UTC Orthographic Sequences WG（SEQ）の活動・設計状況を報告する。
CLDR-TC を主担当、UTC を partner として、orthographic sequences の機械可読な記述を検討する。
well-formedness validation、display normalization、reading normalization の三層を区別する。
本文日付は2026-10-20、registry date は2026-10-21。

## 報告内容

- LDML XML と portable regular-expression subset を検討し、ICU Transliterator / Pynini FST への変換を目指す。
- script-wide の und grammar と language-specific locale tailorings を分ける。
- 言語固有の制約を keyboard / application の層で処理し、font shaping による過度の排除を避ける方向を報告する。
- NFC の変更ではなく、その外側に更新可能な equivalence layer を置く案。
- MeitY / C-DAC、ICANN LGR、CLDR keyboard reordering との接続を review 中。
