# IRG N2892

## 要約

`IRG N2892` は、IRG Meeting \#45 から \#65 までに扱われた CJK ideograph disunification cases を集約した report である。各行に meeting number、source reference、glyph、historical / new code point、文書作成時点の status、reference document、source migration note を置く。

Meeting \#45-\#63 の多くは `done` または標準・CD への反映済みとして記録される。一方、Meeting \#64 の 17 件は WG2 \#72、Meeting \#65 の U+2EA07 / U+2B81E 関連 3 source references は WG2 \#73 の確認待ちという snapshot である。

この文書は個々の disunification を決定する recommendation ではなく、複数会合と WG2 文書に分散した decision trail を一つの表にまとめた参照資料である。

## 報告内容

### 一覧の構造

表は source reference を単位とするため、一つの disunification が複数行になる場合がある。たとえば Meeting \#58 の V1-5454 / UTC-01005 はともに U+5F50 から U+2B739 へ移り、Meeting \#62 の T4-2634 / JMJ-010468 / TF-2662 は U+5CC0 周辺の source disposition を別々に記録する。

| 範囲 | 文書上の状態 | 読み方 |
| --- | --- | --- |
| Meeting \#45-\#58 | 主に `done` | 新 code point への移動と、historical code point に残す `TU` / `VN` source reference を追える。 |
| Meeting \#62-\#63 | ISO/IEC 10646 Ed.7 CD または Unicode Standard へ反映 | U+5CC0 と U+2F980 周辺の source disposition を記録する。 |
| Meeting \#64 | WG2 \#72 confirmation 待ち | KP1-439A と 16 T-source references の移動候補をまとめる。 |
| Meeting \#65 | WG2 \#73 confirmation 待ち | U+2EA07 への KP1-869A / T6-6430 移動と、U+6B25 から U+2B81E への GCESI-00550 移動を記録する。 |

### historical code point に残る source reference

disunification 後も historical code point 自体は消えない。文書は、移動元に `TU-...`、`VN-...`、`HU-...`、`KPU-...` などの internal / historical source reference を加える case を note 欄に残し、既存 code point と新 code point の source identity を分けて追跡する。

### Meeting \#65 の追加

最終更新では、[IRG N2834](irg-n2834.md) などの検討を受け、U+980B 頋の compatibility ideographs に付いていた KP1-869A と T6-6430 を U+2EA07 へ移し、U+FACB / U+2F9FF 側を `KPU-0FACB` / `TU-2F9FF` に更新する案を収録した。また GCESI-00550 を U+6B25 から U+2B81E へ移す案も載せる。いずれもこの文書では WG2 \#73 confirmation 待ちである。

## 後続決定

[IRG N2909](irg-n2909.md) の M66.05 は、後継の [IRG Disunified Ideographs](https://www.unicode.org/irg/disunified.html) web page を旧 `IWDS Series 4` の replacement として accept した。したがって `IRG N2892` は Meeting \#65 までの dated snapshot として使い、現在の pending / implemented status は web page と後続 UTC / WG2 / IRG records で確認する。

## 論点

### status は文書時点のもの

`To be confirmed by WG2#72` / `WG2#73` は 2025 年の表に記録された状態であり、現在状態として転載してはならない。body と時点を保ったまま、後続 recommendation や Unicode release data へ接続する必要がある。

### disunification と source migration

この一覧が追うのは code point の追加だけではない。既存 source reference の移動、historical code point 用 source reference の追加、compatibility mapping の維持、representative glyph の扱いが一体になっているため、[IRG Source Data and Representative Glyphs](../topics/irg-source-data-and-representative-glyphs.md) と併読する必要がある。
