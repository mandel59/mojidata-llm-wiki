# L2/26-220

## 要約

L2/26-220 は、Big5 ETen extension の 0xF9FA–0xF9FD にある double arc quadrant の罫線4字を提案する。
CP950 の light arc への多対一 mapping と、Big5-2003 の double corner への mapping では元の区別を保持できないとする。
Symbols for Legacy Computing の U+1FBFB–U+1FBFE を提案し、round-trip conversion の例を示す。
本文の日付は 2026-07-31、registry date は 2026-10-09。

## 提案内容

- `BOX DRAWINGS DOUBLE ARC DOWN AND RIGHT`、`DOWN AND LEFT`、`UP AND RIGHT`、`UP AND LEFT` の4字。
- 提案 UnicodeData は `General_Category=So`、`Bidi_Class=ON`。
- original Big5 の single arc、ETen の double arc、straight double corner を資料と glyph 比較で区別する。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

既存 mapping が異なる legacy characters を同じ Unicode character に寄せる点が中心である。文書の推定による mapping 履歴と、資料から確認できる glyph の違いを分け、mapping の修正決定として扱わない。
