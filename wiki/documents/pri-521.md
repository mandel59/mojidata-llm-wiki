# PRI 521

## 要約

`PRI #521` は、CAAPH collection とその IVS を同時に登録する public review である。
提出者は Culture and Art Publishing House Co., Ltd. (文化艺术出版社)、representative は Eiso Chan。
review closing date は 2025-07-11。95 base characters に対して 198 IVS を提案する。
中国の文化・芸術と非物質文化遺産資料のデジタル化で必要な字形を対象とする。
登録完了は [IVD 2025-07-14 event](../events/ivd-2025-07-14-caaph-registration.md) を参照。

## 提案内容

collection identifier は `CAAPH`、sequence identifier pattern は `[A-Z]\d{4}`。identifier の prefixes は資料分野や基本字形を区別し、`B`、`G`、`J`、`K` は Chinese Library Classification に、`M` は基本字形に対応する。

登録対象は 95 base characters に対する 198 IVS。文書は通用规范汉字表と GB/T 22321.1-2025 の字形との関係や、IRG に提出した glyph charts を示す。review では各字形の base character への適合性と collection scope を確認する。

## 後続決定

公式 archive は 2025-07-14 版 IVD への登録完了を明記する。結果と影響は [CAAPH 登録 event](../events/ivd-2025-07-14-caaph-registration.md) に集約する。

## 論点

[IRG N2767](irg-n2767.md) は CAAPH collection への objection がないとして endorse したと報告する。IRG editorial report と、IVD Registrar による public review・登録は異なる段階の記録として扱う。
