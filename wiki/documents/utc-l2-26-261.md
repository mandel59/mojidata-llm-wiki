# L2/26-261

## 要約

Unicode 4.0.0〜8.0.0 の StandardizedVariants.html が使う旧 CGI glyph service を data URL に置き換える提案。
CGI が返していた画像をそのまま HTML に埋め込み、各版を standalone にする。
旧版の表示資源を保守する案であり、variation sequence の追加・変更ではない。

## 提案内容

- refglyph CGI URL を同じ GIF 内容の data:image/gif;base64 URL に置換する。
- StandardizedVariants.html 自体が存在するのは Unicode 3.2.0〜9.0.0、今回の置換対象は4.0.0〜8.0.0。
- CGI service を廃止できるようにすることが目的。

## 論点

過去版の画像資源の保存と、文字・variation sequence の規範データ変更を混同しない。
