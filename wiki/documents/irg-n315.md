# IRG N315

## 要約

1996-02-08、Cupertino の IRG 第6回会合決議。
components は既存規格・Vertical Extension Level I・N302 との重複を避け、小さくする条件を定める。
composition の structure symbols を新しい control characters として扱う方針を決議し、WG2 への要求を進める。
Vertical Extension の工程・優先順位の判断基準と、Annex 改訂作業も記録する。

## 決定・Action Item

- 項目1: N312 の editorial result を受け、期限内の正しい data で VE V4.0 を作成し、遅れた data は Level III に回す。
- 項目2: ISO/IEC 10646-1:1993、VE3.0 Level I（N263）、N302 に存在しない component を選び、集合を最小化する。
- 項目3–5: structure symbols を control characters として受け入れる方針とし、component repertoire の整備と WG2 提出を進める。現在の Unicode General_Category を定めたものではない。
- 項目6: Annex への comments と改訂提出日を設定する。
- 項目9–10: Level I に category A / 統合可能な候補、Annex source、複数 body の要求、単独 source の場合の国の規格・公的資料・辞書・IT vendor 使用などの根拠を置く。Level II は低頻度、Level III は文学・研究・教育などの必要性を説明する。

## 後続決定

[N321](irg-n321.md)が WG2 への進捗報告として束ね、[N360](irg-n360.md)項目10が具体的な4提案の送付を決めた。
