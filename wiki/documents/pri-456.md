# PRI 456

## 要約

`PRI #456` は、Adobe-Japan1 collection への 1 IVS 追加登録の public review である。
提出者は Adobe、representative は Masataka Hattori。review closing date は 2022-08-26。
Adobe-Japan1-7 に含まれる Extension H ideograph の字形を登録対象とする。
archive は 2022-09-13 版 IVD への登録完了を記録する。

## 提案内容

Adobe-Japan1-7 の ideograph を、CJK Unified Ideographs Extension H の base character と結び付ける sequence を追加する。提出時点では Extension H が Unicode 15.0 に入る予定として説明されている。

collection identifier は `Adobe-Japan1`。sequence identifier は `CID+` に digits を続ける形式であり、Adobe の glyph identifier と IVS の対応を表す。

## 後続決定

公式 archive は、2022-09-13 版 IVD に 1 IVS が追加登録されたと明記する。collection の最新更新日と登録件数は [IVD topic](../topics/ideographic-variation-database.md) から確認できる。

## 論点

Adobe-Japan1 の glyph collection の版と、IVD の日付付き release は別の版管理である。Unicode の Extension H 符号化と IVS の登録も区別して追う。
