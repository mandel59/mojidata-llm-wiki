# IRG N200

## 要約

Zhang Zhoucai が IRG 内外の experts に components / composition の討議参加を呼びかけた案内。
IRG 第4回会合の C1 / C2 を引用し、component の定義と composition scheme の目標・方式を説明する。
Internet と FAX で意見を集め、China による英訳、feedback、summary report の schedule を示す。
この文書自体は components repertoire の符号化決定ではない。

## 報告内容

引用する C1 は ideographic components を ideographs の表現に用いる basic units とし、ideographs proper と dependent ideographs を含める。Ideographic composition は、規則で順序づけた component の列で単一 ideograph を表現する scheme と定義する。

引用する C2 は Zhang Zhoucai 主導で IRG 外にも開いた討議を続け、composition scheme の目標と方式を論じる方針である。英訳を1995-03-10、feedback を05-01、summary を06-17 とする計画を載せる。registry date は1995-04-03、表紙には `95/03/14;04/03` の日付表記がある。

## 後続決定

現代の [CJKV Components](../topics/cjkv-components.md)へ問題設定を比較できる。ただし1995年の scheme と2026年の494文字案が同一 repertoire である根拠にはしない。

引用する C1 / C2 は、原決議 [N189](irg-n189.md)と [定義採用 event](../events/irg-4-components-composition-definitions.md)で確認できる。後続の scheme は [N310](irg-n310.md)へ。
