# PRI 418

## 要約

`PRI #418` は、MSARG collection への追加 IVS 登録の public review である。
提出者は Macao SAR の Public Administration and Civil Service Bureau (SAFP)。review closing date は 2020-09-11。
MSCS-2020 の未登録 variants 68 件と対応する base characters 65 件、計 133 sequences を提案する。
archive は 2020-11-06 版 IVD への登録と、review 後の代表字形調整を記録する。

## 提案内容

MSCS-2020 は Macao の行政情報交換で使う文字集合であり、文書は vertical extension、horizontal extension、IVS による字形区別を分けて説明する。初回登録済みの variants 11 件を除く 68 件と、対応する base characters 65 件を今回の登録対象とした。

source reference の `ME-hhhh[h]-nnn` に対し、sequence identifier では hyphen を underscore に置き換える。文字符号化の source reference と IVD identifier は同一表記ではない。

## 後続決定

公式 archive は 2020-11-06 版に 133 IVS が追加登録されたと明記する。review comments を検討した結果、4 sequence identifiers の representative glyphs を調整した。登録後の collection 全体は [IVD topic](../topics/ideographic-variation-database.md) で追う。

## 論点

提案時の glyph charts と登録後の代表字形には差があるため、実装時は正式データと collection の登録後資料を確認する。MSCS の文字追加、source reference 追加、IVS 登録はそれぞれ別の操作である。
