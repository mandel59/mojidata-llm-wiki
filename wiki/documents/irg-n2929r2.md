# IRG N2929R2

## 要約

China の GCW-source horizontal extension proposal の R2 revision。
対象は R と同じ9,178文字で、URO と Extensions A–H / J の既存文字へ source references を追加する。
改訂 PDF の表紙日付は 2026-10-12、registry date も同日。
IRG \#67 の2026-10-14版 agenda Section 8.1 は、この R2 を討議完了として掲載する。

## 提案内容

- 件数は URO 21、A 168、B 3,061、C 421、D 27、E 377、F 2,795、G 1,537、H 366、J 405。
- 地名・人名・学術文献などの evidence、code chart 比較と GCW-source references を束ねる。新しい code points の追加ではない。

## 後続決定

後続の勧告と継続 review は [IRG \#67 horizontal extension disposition](../events/irg-67-horizontal-extension-dispositions.md)に集約する。


## 論点

R→R2 で総数は変わらない。各字形の revision は N2984 / N2987 の feedback と対照して読む。agenda の完了印だけでは全9,178件の正式承認を示さない。
