# PRI \#559

## 要約

`PRI #559` は Proposed Update UAX \#45, U-source Ideographs の open review である。closing date は 2026-10-05。

## 提案内容

draft は IRG restructuring、optional fields の明確化、Components-B 用 `CmptB` status、duplicate entries、`DYC` / `TUS` source-tag regex、`UNKN` source tag、IRG submissions の first residual stroke requirement removal を扱う。

## 後続決定

2026-09-18 時点で open。UTC \#189 の disposition と最終 UAX \#45 data format を確認する。

## 論点

Components-B を UAX \#45 workflow で扱うための status と、submission / duplicate record syntax の更新が同じ draft に含まれる。既存 data producer は field optionality と source-tag validation の両方を確認する必要がある。
