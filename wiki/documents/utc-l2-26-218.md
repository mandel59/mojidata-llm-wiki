# L2/26-218

## 要約

L2/26-218 は、Unicode 18.0.0 の SealSources.txt で重複 glyph を避けるため省略された source references を補足する kSEAL_AdditionalSrc property を提案する。
対象は THX、CCZ、QJZ、DYC の計79件の source glyph names と、それらをひも付ける30 code point records。
既存の source properties の構文を変えず、新 property を provisional として追加する案である。
これは UTC の審議を求める proposal であり、採択済みの Unicode 18.0 data change ではない。

## 提案内容

- kSEAL_AdditionalSrc は省略された kSEAL_THXSrc、kSEAL_CCZSrc、kSEAL_QJZSrc、kSEAL_DYCSrc の値を並べ、対応する code point を特定する。
- 文書は Unicode 18.0.0 の既存 SealSources.txt を基準に30件の追加 records を示す。値の並びは code chart 上の source 順にする。
- 提案者は、既存 property を複数値に変える案や、値を連結する案より、新 property の追加が chart production workflow への影響を抑えやすいと説明する。

## 後続決定

この文書は CJK Experts による discussion を求めている。確認できる後続 recommendation または UTC decision はまだないため、property は提案段階として扱う。

## 論点

SealSources.txt では各 source の重複 glyph を一つにまとめているため、現在の code chart と data file だけでは省略された字名と表示先 code point の対応を追いにくい。本提案は source glyph の列挙を保ちながら、その対応情報を追加 property で公開する。
