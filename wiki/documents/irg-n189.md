# IRG N189

## 要約

1995-03-03、Taipei の第4回会合結論。
components / composition の定義を採用し、IRG 外にも開く討議を継続する。
既存合意の変更手順、役職兼任制限の撤回、補充作業の条件変更も記録する。
Internal / Horizontal Supplementation と Vertical Extension は別の編集・review schedule を持つ。

## 決定・Action Item

- H1: Vietnam の N164 による V-column horizontal extensions と China の N170 による G-column internal extensions を受理し、N080 項目14を置き換える。
- H2–H3 / V1–V3: repertoire と MRF の準備、defect reports、統合・review、高品質印刷の工程を定める。TCA の第5～7面を source list へ加える。
- C1–C2: 定義と継続討議は [canonical event](../events/irg-4-components-composition-definitions.md)へ。
- W1–W2: 既存合意の変更・撤回を plenary 承認によるものとし、[三役兼任禁止の撤回](../events/irg-4-officer-role-restriction-withdrawal.md)を記録する。
- W3: Internal / Horizontal Supplementation に対する source code separation rule の禁止を撤回する。source code separation rule 自体の廃止という意味ではない。
- M1 / A1–A2: Annex 修正を継続し、Mao Yong-Gang を Chief Editor として受理。Zhang Zhoucai の次期 Rapporteur 推薦は WG2 confirmation を条件とする。

## 後続決定

[N200](irg-n200.md)の討議案内、[N250](irg-n250.md)の components 作業方針へ続く。
