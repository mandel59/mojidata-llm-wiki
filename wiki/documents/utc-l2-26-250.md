# L2/26-250

## 要約

Sridatta A / Srinidhi A が U+0CD5 KANNADA LENGTH MARK の独立使用と property を検討する。
pluta vowels、音楽表記、Tulu の用例を根拠に General_Category=Mc→Lo、Line_Break=CM→AL を提案する。
code chart の dotted circle を外すことと、two-part vowels への影響について feedback を求める。
文書日付は 2026-09-27、registry date は 2026-10-13。

## 提案内容

- 既存の vowel sign II / EE / OO の構成要素だけでなく、space・danda 後や行頭で単独・反復して現れる用例を示す。
- 既存文字の property と chart 表示を変更する案であり、新文字追加ではない。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

General_Category の変更は既存の vowel sequence と shaping に影響するため、独立使用の証拠と処理上の帰結を合わせて審議する。
