# IRG N2936

## 要約

IRG N2936 は China の IRG Meeting \#67 向け activity report である。
China は未符号化候補が7,000字を超え、WS2027 では2,500–3,000字以上の quota を申請する見込みと報告する。
地名・人名資料の調査では6,169字を特定し、IRG N2929 の G-source horizontal extension 改訂版も提出した。
これらは計画・活動状況の報告であり、IRG による受理や quota 決定を記録するものではない。

## 報告内容

- Sichuan International Studies University は IRG N2929 に対する feedback を受けて IRG N2929R を提出し、次回会合では主に dialect characters から1,000–2,000字の horizontal extension を提案する計画を示した。
- 同センターは公式地名・人名資料から未符号化文字6,169字を特定し、自然村級以上の公式地名と大半の公式人名の調査をほぼ完了したと報告した。
- Culture and Art Publishing House は GCA / GWY sources 約200字、Guangxi University は約6,000字の Zhuang characters を次期 working set 候補として準備している。
- 報告は MetaHan font tooling、Chinese Character Six Scripts Database、《字海》の出版など他の活動も記録する。

## 後続決定

IRG N2935 は WS2024 Version 5.0 review と各 source issue を Meeting \#67 の agenda に置く。IRG N2936 に記された次期 working set の候補数は、正式提出・割当済みの数ではない。

## 論点

China の activity report は、現在の WS2024 review と、次の WS2027 へ向けた新規候補準備を分けて説明する。G-source horizontal extension の内容は [IRG N2929R](irg-n2929r.md) を一次文書として参照する。
