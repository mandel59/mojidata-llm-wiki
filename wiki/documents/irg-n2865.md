# IRG N2865

## 要約

`IRG N2865` は、[IRG N2834](irg-n2834.md) が示した U+980B / U+FACB / U+2F9FF disunification の Solution 2 に TCA が同意した一頁の feedback である。TCA は、T6-6430 を U+2F9FF から除き、既存 U+2EA07 へ horizontal extension として対応付けることを支持した。

同時に、U+2F9FF の T-source を `T6-6430` から historical / internal reference `TU-2F9FF` へ更新するよう求める。新規 code point を設ける案ではなく、既存 code point 間の source migration を具体化する member body contribution である。

## フィードバック内容

TCA の同意内容は次の3点に集約される。

1. T6-6430 を U+2F9FF から除く。
2. T6-6430 を U+2EA07 へ horizontal extension として対応付ける。
3. U+2F9FF に残る T-source reference を `TU-2F9FF` に更新する。

文書は Unicode 17.0 code chart excerpts で U+980B、U+2F9FF、U+2EA07 の glyph columns を比較し、U+2F9FF / U+2EA07 が 顧 variants であるという `IRG N2834` の整理を member body として支持する。

## 後続決定

[IRG N2826](irg-n2826.md) の M65.05 は、`IRG N2834` と `IRG N2865` の提案を unanimously accept し、KP1-869A と T6-6430 を既存 U+2EA07 に置くよう WG2 へ勧告した。[IRG N2892](irg-n2892.md) はこの結果を、U+2F9FF から U+2EA07 への T-source migration として記録する。

## 論点

### horizontal extension と historical reference

U+2EA07 への `T6-6430` 追加と、U+2F9FF への `TU-2F9FF` 追加は対になる。前者だけを反映すると移動元 code point の chart / source history が失われ、後者だけでは active T-source glyph の対応先が更新されない。

### TCA feedback の範囲

この文書は T-source disposition に限定され、KP1-869A の representative glyph や U+980B の reading properties 全体を再論証しない。それらの根拠は `IRG N2834` と後続文書を参照する必要がある。
