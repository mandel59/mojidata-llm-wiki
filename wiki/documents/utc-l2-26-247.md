# L2/26-247

## 要約

Roozbeh Pournader が UTC 159-A81 に対応し、Core Specification の cedilla / comma rendering 説明を修正するよう報告する。
Table 7-1 の T/t を cedilla group へ戻し、Latvian G/g の大小文字別 placement を明示する。
新文字・normalization 変更ではなく、既存 U+0327 とその canonical equivalents の default rendering guidance の修正案。
文書日付は 2026-09-02、registry date は 2026-10-12。

## 報告内容

- Cedilla below: C/c、E/e、H/h、S/s、T/t。Comma below: D/d、G、K/k、L/l、N/n、R/r。Turned comma above: g。
- Latvian の説明に L/l と historical R/r を補い、D/d は Livonian の用例として区別する。
- Romanian の T/t with comma below に U+0326 を使う選択と、U+0327 の font rendering defaults を分ける。
