# L2/26-253

## 要約

Sridatta A / Srinidhi A が Kannada の repha と他の marks の表示順を報告し、SEWG へ feedback を求める。
RA + VIRAMA + RA は repha + RA より subjoined second RA で表す実例を示す。
repha と U+0CD5 LENGTH MARK には両方の visual orders があり、font / shaping と encoding の扱いを問う。
文書日付は 2026-08-17、registry date は 2026-10-13。

## 報告内容

- U+0CB0 U+0CCD U+0CB0 の例外表示を Core Specification に記述し、未 attested の repha form 用 ZWJ sequence は求めない。
- anusvara / visarga は repha の後へ置き、他の nonspacing marks は second consonant を基準に置く実例を示す。
