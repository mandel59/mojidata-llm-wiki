# IRG N2968

## 要約

`IRG N2968` は CheonHyeong Sim が IRG Meeting \#67 に情報提供として提出した MetaHan の進捗報告である。200種以上の stroke library と glyph skeleton data から、補間で CJK glyph outlines を生成する個人 project を紹介する。

Serif / Kǎi 用の skeleton sets、font 出力、stroke order や weight data などの設計を説明する。IRG に採択や規格変更を求める proposal ではない。

## 報告内容

- GlyphWiki と異なる stroke library、skeleton editing、font generation の設計を比較する。
- 文書作成時点では visual editor がなく、skeleton data を手で編集すると記す。
- 英語・中国語・日本語・韓国語の説明を含む。

## 後続決定

以前の agenda は本書を activity report として載せていたが、2026-10-16に再取得した Registry では N2968 が `(unused)` / URLなしへ変更され、2026-10-15版 [N2935](irg-n2935.md) にも本書の掲載はない。このページの要約、date、source、resource は以前に取得した文書と旧 catalog に基づく履歴として保持する。Registry の変更理由はこの資料から確定しない。

IRG の working set や code chart の glyph が MetaHan により変更されたという記録ではない。
