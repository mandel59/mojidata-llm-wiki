# L2/26-240

## 要約

Charts WG の18.0公開後の振り返りと19.0準備の報告。
block charts の version 別 archive、representative glyphs を用いる auxiliary charts、URL redirect の構成を説明する。
19.0 の chart sources は現在対象となる repertoire 向けに準備され、新たな採択には font の早期提出が必要とする。
旧版 archive の公開拡大や Unibook 代替検証は計画として区別する。

## 報告内容

- 18.0 と17.0の block-by-block charts を version 別に保存し、従来の /charts/ URL を /Public/latest/charts/ 経由で誘導する。
- names list auxiliary charts に permalink と clickable cross-reference を導入した。
- 18.0 French charts は翻訳待ちで17.0へ誘導されると報告する。
- 16.0〜5.0 の archive を順次公開する計画。Unibook は引き続き chart production に使用する。
- L2/26-211 に基づく NamesList.txt の変更を勧告し、U+031C cross-reference と U+024B annotation は19.0向けに修正済みと報告する。

[UTC Meeting \#189](../meetings/utc/utc-meeting-189.md) の審議資料。2026-10-25 時点では会合前であり、採択・承認の結果は後続 minutes で確認する。
