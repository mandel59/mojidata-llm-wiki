# L2/26-229

## 要約

Rikza F. Sh. が特殊な Indo-Pak mushaf の tajwīd・waqf・補助注記に使う Arabic characters 26文字を提案する。
Arabic Extended-D に2 letters と24 combining marks を追加する案である。
通常版全般の必須文字ではなく、特定出版社の recitation guides を増補した版の用例を提示する。
本文は 2025-11-05、改訂 2026-08-25、registry date は 2026-10-12。

## 提案内容

- U+10D93 REH WITH TAIL は right-joining、U+10D94 LAM WITH HOOK は dual-joining を提案する。
- U+10E48..U+10E5F は sukūn / shadda variants、DUA / IHTIYAAT、small low letters / words、WAQF LAAZIM など。ccc は用途により 230 / 220 / 33 / 28 を提案する。
- LAM WITH HOOK の確認用例は medial form だが、提案は全 positional forms を扱う dual-joining とする。
- 既存文字の stylistic variant とされた DAMMA WITH INVERTED DAMMA ABOVE について、異なる recitation function の用例を提示する。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

異なる機能を持つ mark、位置だけの variant、marginalia の表現を区別し、各候補を一括で採択済みと扱わない。
