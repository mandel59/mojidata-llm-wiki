# L2/26-270

## 要約

装飾された glass bottle を fragrance / potion / elixir などに使う emoji として追加する提案。
ESR の [L2/26-237](utc-l2-26-237.md) が Unicode 19.0 向けの5候補に含めている。
本文タイトルは ORNATE GLASS BOTTLE。ESR は ORNATE BOTTLE として勧告する。
2026-10-25 時点では UTC の採択前である。

## 提案内容

美容・香水・gifting と fantasy / gaming の複数用途を示す。
flowers や test tube では表しにくい、人が作る香りの製品・容器の表現を求める。
