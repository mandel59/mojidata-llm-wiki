# L2/26-135

## 要約

`L2/26-135` は UAX \#14 の line breaking と UAX \#29 の segmentation に、deterministic finite automata (DFA) の実装記述と対応する data files を追加する提案である。現行の rule 記述を保ちながら、効率的で更新しやすい実装方法を提供する。

`LineBreakSymbols.txt`、`LineBreakStates.txt`、`LineBreakTransitions.txt` などの data と、lookahead、tailoring の仕組みを説明する。PRI \#555 の review 対象であり、文書自体は規範的な採択を示さない。

## 提案内容

- UAX \#14 に DFA の構造、擬似コード、complex context、CLDR / CSS tailoring を加える。
- UAX \#29 に state machine の説明と data publication を加える。tailoring は state machine の再生成ではなく input symbol の再割当てで扱う。
- Unicode 17.0 / 18.0 用の試験 data を PRI \#555 に公開し、採用後は versioned UCD auxiliary files として提供する案を示す。

## 後続決定

[PRI \#555](pri-555.md) の review と後続 UTC decision を確認する。提案された DFA files を Unicode 18.0 の必須実装と断定しない。
