# IRG N2943

## 要約

IRG N2943 は、John Knightley による UK の IRG Meeting \#67 activity report である。
現行 Working Set の作業に加え、IRG N2960 の horizontal extension と次期 Working Set の準備を報告する。
次期候補は561字を暫定的に受け入れ、さらに216字を shortlist に置いた段階で、最終提出規模は従来と同程度の約1,000字を見込む。
これは UK 内の準備状況であり、IRG が受理・符号化した件数ではない。

## 報告内容

- [IRG N2960](irg-n2960.md) に至る horizontal extension 作業を実施した。
- 次期 Working Set に向けて561字を暫定的に受け入れ、216字を shortlist に置いた。約1,000字という見込みは最終提出規模で、確定数ではない。
- CDG の貢献に謝意を示す。文書は略称の展開を記していない。

## 後続決定

[IRG N2935](irg-n2935.md) は Section 3.8 に本報告を掲載する。次期 Working Set の正式な提出・受理は後続文書で確認する。
