# L2/26-153

## 要約

`L2/26-153` は 2026-04-01 から 2026-07-07 まで public feedback の対象だった PRI と、各 issue の feedback 文書への一覧である。UTR \#59、UAX \#60、UTS \#61、Unicode 18.0 beta、UCD / annex 改訂などを束ねる。

これは review の入口と期間を示す registry 文書で、feedback の採否を自ら決定しない。個別の issue と UTC \#188 minutes を合わせて読む。

## 報告内容

- PRI \#510、\#520、\#523、\#533〜\#555 の対象 issue と feedback link を掲げる。
- `PRI #555` は finite automata for line breaking and segmentation の review へ接続する。

## 後続決定

各 issue の disposition は [UTC \#188 minutes](utc-l2-26-151.md) と該当 WG report に分かれる。
