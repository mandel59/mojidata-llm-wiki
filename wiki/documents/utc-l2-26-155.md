# L2/26-155

## 要約

`L2/26-155` は Editorial Working Group が UTC Meeting \#188 に提出した report である。Unicode 18.0 Core Specification の編集計画、technical reports の出版方式、public feedback の処理をまとめる。

Chisoi の延期と Small Seal の名称変更に伴う本文調整、Egyptian Hieroglyphs の `kEH_AltSeq` の順序問題、Unicode 18.0 beta feedback を扱う。report の recommendation と UTC 決定は区別する。

## 報告内容

- Unicode 18.0 の新規 content の締切を 2026-08-16 とし、その後は showstopper を中心に扱う計画を示す。
- Core Specification と technical reports の出版基盤の統合を検討し、PRI \#548 / \#550 と proposal feedback への対応を示す。
- Egyptian Hieroglyphs `kEH_AltSeq` について UTC \#188 で ad hoc discussion を求める。

## 後続決定

[L2/26-151](utc-l2-26-151.md) と Unicode 18.0 の最終本文で実際の編集結果を確認する。
