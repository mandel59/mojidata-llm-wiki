# IRG N321

## 要約

1996-04-17 の Rapporteur による IRG 進捗・要求の WG2 向け報告。
Vertical Extension Draft 4.1 と IS/HS Draft 5.0 の段階、components / composition の作業をまとめる。
component・radical・structure symbols の必要 code space は見積もりとして示される。
会合決議の再掲と、Rapporteur の見込み・要求を分けて読む。

## 報告内容

- pp.1–2: VE Draft 1.0 から4.1までの版を列挙し、3.1 は dropped、4.0 は electronic only とする。4.1 は1996-04-18 release と記し、文書日付の翌日に当たる。Level I は6,608字。
- pp.2–3: IS/HS Draft 5.0 は G/T/K の internal extension と V-column 追加を含むと報告する。高品質印刷への WG2 回答は、この報告時点では未着とする。
- pp.3–4: N315 の component 選択と構造記号の決議を再掲。未符号化 radicals は10未満、追加 components は512未満、structure symbols は12～13という Rapporteur の見積もりを示す。
- 次回会合、Rapporteur 推薦、CUHK の FTP site 準備も報告する。

## 後続決定

[第7回の提出案送付](../events/irg-7-ideographic-description-proposals-forwarding.md)と [Extension A の WG2 処理](../events/wg2-31-extension-a-repertoire-and-bmp-consultation.md)へ続く。

## 論点

p.2 は6,608字の Level I に続く301字（K & S）の行も Level I と印刷する。見出しの整合性に問題があり、N315 の3段階分類と照合し、印刷値を黙って Level II に改めない。
