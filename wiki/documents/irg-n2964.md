# IRG N2964

## 要約

`IRG N2964` は Unicode 18.0 の CJK Unified Ideographs と CJK Compatibility Ideographs を code point 範囲、block、初出 Unicode version ごとに示す集計資料である。PDF 本体には 2026-09-16 版と記されており、registry 掲載日 2026-07-19 とは区別する。

統合漢字は 101,997 文字、互換漢字は 1,002 文字と集計する。前者には Compatibility block 内に置かれた統合漢字 12 文字を含む。Unicode 18.0 で追加された Extension D の U+2B81E と、各 block 内または周辺の未割当範囲も明示する。文書は repertoire の参照表であり、個別文字の採否を決める会合記録ではない。

## データ内容

最初の表は BMP、SIP、TIP にわたり、URO と各 Extension の範囲を Unicode version 別に分ける。Extension D は 223 文字で、そのうち U+2B81E が Unicode 18.0 追加分である。表末尾には統合漢字 101,997 文字と未割当 44,795 code points を載せる。

次の表は BMP の CJK Compatibility Ideographs と SIP の Compatibility Ideographs Supplement をまとめ、互換漢字 1,002 文字、未割当 42 code points とする。registry には対応する [data file](https://www.unicode.org/irg/docs/n2964-CJKUIv18.txt) も掲示されている。

## 論点

この集計は [Unicode 18.0 Change Sources](../topics/unicode-18-change-sources.md) の CJK repertoire を確認する入口になる。source reference、glyph、Unihan property の変更理由を追う場合は、個別の IRG / UTC 文書と final UCD を併読する。
