# L2/26-237R

## 要約

2026-10-27 の改訂 ESR report は、Unicode 19.0 向けに新文字4件と RGI ZWJ sequence 1件を勧告する。
初版で独立文字案だった EYES LOOKING RIGHT を、既存文字による directional sequence へ変更した。
ORNATE BOTTLE、ORCHID、VULTURE、INUKSHUK は新文字案として残る。
CLDR short name の変更と Emoji 20.0 の受付期間も提案・報告する。
表のコード位置と [189-C] は報告書中の勧告・文案であり、UTC の採択番号ではない。

## 報告内容

| 候補 | 改訂版の表現案 | 提案 |
| --- | --- | --- |
| EYES LOOKING RIGHT | `1F440 200D 27A1 FE0F`、RGI_Emoji_ZWJ_Sequence | [L2/26-269](utc-l2-26-269.md) |
| ORNATE BOTTLE | U+1FA7F、新文字 | [L2/26-270](utc-l2-26-270.md) |
| ORCHID | U+1FACB、新文字 | [L2/26-271](utc-l2-26-271.md) |
| VULTURE | U+1FACA、新文字 | [L2/26-272](utc-l2-26-272.md) |
| INUKSHUK | U+1F6DA、新文字 | [L2/26-273](utc-l2-26-273.md) |

初版の EYES LOOKING RIGHT は U+1FAEC の新文字案だった。改訂版の勧告対象は5 emoji だが、新規コードポイントは4文字である。

- 👀 の CLDR short name を EYES LOOKING LEFT に変更するよう依頼する案。
- 2026年の提案受付は終了し、前年より50%多い提案を review したと報告する。
- Emoji 20.0 の受付は2027-02-02〜05-31とし、Q3 勧告・Q4 確定に合わせる予定。
