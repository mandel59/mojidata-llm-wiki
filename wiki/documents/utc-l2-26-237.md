# L2/26-237

## 要約

ESR が Unicode 19.0 向けに新しい emoji 5文字を勧告する。
EYES LOOKING RIGHT、ORNATE BOTTLE、ORCHID、VULTURE、INUKSHUK が対象。
既存 EYES の CLDR short name の変更と、Emoji 20.0 の受付期間の変更も提案・報告する。
表内のコード位置と consensus 文案は会合前の勧告である。

## 報告内容

| 候補 | コード位置案 | 提案 |
| --- | --- | --- |
| EYES LOOKING RIGHT | U+1FAEC | [L2/26-269](utc-l2-26-269.md) |
| ORNATE BOTTLE | U+1FA7F | [L2/26-270](utc-l2-26-270.md) |
| ORCHID | U+1FACB | [L2/26-271](utc-l2-26-271.md) |
| VULTURE | U+1FACA | [L2/26-272](utc-l2-26-272.md) |
| INUKSHUK | U+1F6DA | [L2/26-273](utc-l2-26-273.md) |

- 👀 の CLDR short name を EYES LOOKING LEFT に変更するよう依頼する案。
- 2026年の提案受付は終了し、前年より50%多い提案を review したと報告する。
- Emoji 20.0 の受付は2027-02-02〜05-31とし、Q3 勧告・Q4 確定に合わせる予定。
