# PRI \#560

## 要約

`PRI #560` は Proposed Update UAX \#50, Unicode Vertical Text Layout の open review である。UTC \#188 で provisionally assigned された U+16FE5 WHITE IDEOGRAPHIC COMMA と U+16FE6 DOUBLE IDEOGRAPHIC FULL STOP の glyphs を Table 3 に追加し、closing date は2026-12-30。

## 提案内容

draft は U+16FE5 / U+16FE6 の vertical layout guidance を追加し、Acknowledgments の historical details も改善する。

## 後続決定

2026-11-03のpageもOpen。両 character は Unicode 19.0 target であり、この PRI は vertical presentation の review を行う。

## 論点

character の provisional assignment は UTC \#188 minutes、glyph redesign / UAX \#50 update は action items、この PRI は公開 review という別段階である。

### 2026-10-26付のDraft 2

Revision 36のDraft 2は3.2.5 Emojiを追加し、emojiとして表示する文字は `Vertical_Orientation=U` のように表示すべきとする。`Emoji_Presentation=No` の文字でも、定義済みemoji variation sequenceのselectorが続く場合を含む。Table 3はU+16FE5 / U+16FE6を加え、U+1F201を除く。後者は表からの削除であり、文字の符号化が取り消されることを意味しない。
