# PRI \#560

## 要約

`PRI #560` は Proposed Update UAX \#50, Unicode Vertical Text Layout の open review である。UTC \#188 で provisionally assigned された U+16FE5 WHITE IDEOGRAPHIC COMMA と U+16FE6 DOUBLE IDEOGRAPHIC FULL STOP の glyphs を Table 3 に追加し、closing date は 2026-10-05。

## 提案内容

draft は U+16FE5 / U+16FE6 の vertical layout guidance を追加し、Acknowledgments の historical details も改善する。

## 後続決定

2026-09-18 時点で open。両 character は Unicode 19.0 target であり、この PRI は vertical presentation の review を行う。

## 論点

character の provisional assignment は UTC \#188 minutes、glyph redesign / UAX \#50 update は action items、この PRI は公開 review という別段階である。
