# IRG N2965

## 要約

`IRG N2965` は Unicode 18.0 の Han ideograph blocks の配置を示す 3 ページの図である。BMP、SIP、TIP をそれぞれ 1 ページに分け、block ごとの領域を凡例で区別する。

BMP では Extension A、URO、Compatibility、SIP では Extensions B–F と I、Compatibility、TIP では Extensions G、H、J を凡例に示す。文字数や未割当数の確認には [IRG N2964](irg-n2964.md) の表を使う。

## データ内容

各 plane に置かれた Han ideograph blocks の位置関係を視覚的に確認する資料である。個別の code point の source reference や glyph 修正を記録する文書ではない。

## 論点

[Unicode 18.0 Change Sources](../topics/unicode-18-change-sources.md) では repertoire の範囲を見渡す図として参照し、正確な範囲と文字数は [IRG N2964](irg-n2964.md) と final Unicode data で確認する。
