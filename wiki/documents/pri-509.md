# PRI \#509

## 要約

`PRI #509` は Proposed Draft UTS \#58 の public review issue で、2026-02-03 に close した。平文に埋め込まれた URL、とくに非 ASCII 文字を含む URL の境界検出と、path / query / fragment の必要最小限の escaping を扱う。

email address の検出と escaping も対象である。review page の resolution は feedback を本文へ反映し、UTS を公開すると述べる。個別の feedback と final UTS の内容は別途確認する。

## 報告内容

- linkifier が平文中の URL span を判定する際の共通の規則を提案する。
- URL 自体の構文規格だけでは flowing text 中の境界検出を定めないという問題を示す。

## 後続決定

PRI page は closed と resolution を記録する。実装に使う規定は公開された UTS \#58 の版を参照する。
