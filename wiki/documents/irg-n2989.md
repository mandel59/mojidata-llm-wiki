# IRG N2989

## 要約

UK が IRG N2918 の U+3062B / U+30C68 reference glyph changes へ条件付きで異議なしと回答する。
source references を維持し、変更前後の whole characters が unifiable と合意されることを条件とする。
whole-character unification から component 同士の unifiability は導けないと明記する。
PDF は John Knightley、2026-10-13。registry source は UK、date は 2026-10-14。

## フィードバック内容

- UK-02988 / UK-02901 は提出時に single evidence に基づく representative glyph とした経緯を説明する。
- 日 / 耳、晴 / 聙、正 / 止、および後者を含む larger components の一般的統合を、この2文字の判断は意味しない。
- whole-character unification を確認すれば他 member bodies の horizontal extension を妨げないとする。

## 会合との関係

会合結果は [IRG Meeting \#67](../meetings/irg/irg-meeting-67.md) と [IRG N2946](irg-n2946.md) を参照する。

## 論点

UK の条件付き回答であり、無条件の glyph correction approval ではない。agenda の討議完了と正式 recommendation を分ける。
