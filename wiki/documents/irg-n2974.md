# IRG N2974

## 要約

`IRG N2974` は、U+3097C（T13-2F35）の T-source representative glyph の変更を IRG と TCA に求める Roy Wang の提案である。原提案の IRG Working Set 2015 が挙げた《龍龕手鑑》と《中華字海》について、別版に ⿱敉目 の形が見えるとする。

提案は U+3097C の T-source glyph を ⿱敉目 に更新するもの。文書自体は TCA の同意や IRG の決定を記録しない。

## 提案内容

- U+3097C の現行 T-source は T13-2F35。
- 《龍龕手鑑》卷四 p.60 と《中華字海》p.1059 の版を証拠に、別の glyph 形 ⿱敉目 を示す。
- ⿱敉目 は GHZR-52684.18 の glyph と同じ形だと述べ、T-source glyph の変更を求める。

## 後続決定

Meeting \#67 agenda は Section 9.1 にこの案件を置き、TCA feedback を当初 TBD としていた。公開された [IRG N2975](irg-n2975.md) で TCA は変更案に同意し、更新 glyph を反映した font を IRG と WG2 に提出した。これは TCA の回答であり、IRG / UTC / WG2 による正式採択はまだ確認できない。

## 論点

[T-source Representative Glyph Issues](../topics/t-source-representative-glyph-issues.md) の U+2976E / U+20885 案件とは別の文字について、source evidence の版差から representative glyph の変更を求める事例である。
