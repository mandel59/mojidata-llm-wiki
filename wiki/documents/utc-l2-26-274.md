# L2/26-274 / IRG N3001

## 要約

UTC が2026-11-10に提出した、66 encoded CJK Unified Ideographs の U-source horizontal extension 提案。
URO と Extensions A / B / D / E / F の既存文字へ `kIRG_USource` values と U-source representative glyphs を追加する。
Unicode 18.0 の code chart excerpts と提案glyphを対比し、unification の根拠を source-specific notes に示す。
U+5B90 / UTC-00687 については UCV \#277 の適用拡張を提案する。
追加property data は PDF attachment の `data.txt` に収録されている。

## 提案内容

### 対象と添付データ

本文の表は各 code point、Unicode 18.0 の chart excerpt、U-source reference、提案glyphを対応させる。添付 `data.txt` の66行を block 別に集計すると、URO 34字、Extension A 9字、B 9字、D 1字、E 1字、F 12字となる。例として U+3779 に `UTC-02971`、U+5B90 に `UTC-00687`、U+2E17D に `UTC-03132` を追加する案が含まれる。

本文の Action は IRG での検討を求めるもの。各値は提出案のデータであり、採用後の正式 Unihan data は別途追跡する。

### Unification の根拠

Source-specific notes は UCV、ad hoc unification、IRG N1110、Working Set 2021 の既存判断を根拠にする。U+64EA / UTC-00656 は WS2021 \#01545、U+2B756 / UTC-03230 は WS2021 \#01259 を参照する。

U+5B90 / UTC-00687 には、U+3B2A、U+7589、U+24D01 の chart excerpts を先例として UCV \#277 の適用拡張を求める。適用範囲の判断は [IRG Indexing Rules](../topics/irg-indexing-rules.md) と合わせて追う。

## 論点

### 2026年の74文字案との関係

[L2/26-147R3 / IRG N2961R3](utc-l2-26-147.md) の添付74行と本提案の添付66行は、code point の重複がない。74文字案に対する [IRG \#67 の勧告](../events/irg-67-horizontal-extension-dispositions.md)は、その提案を対象とする。66文字案の処理は後続の IRG 文書から追跡する。
