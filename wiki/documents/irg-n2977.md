# IRG N2977

## 要約

IRG N2977 は、Wang Xieyang が U+26842 と U+26866 を重複した文字とみなし、最小限の data changes で区別するよう求めた提案である。
U+26866 の radical を肉から月へ変更し、二つの V-source references を入れ替える案を示す。
China に U+26842 の G-source glyph 修正も求め、U+26866 の horizontal extension と整合させる。
IRG、Vietnam NB、China NB に検討を求める個人提案であり、確定した Unihan / chart change ではない。

## 提案内容

| 対象 | 提案する変更 |
| --- | --- |
| U+26866 | radical を肉 U+8089 から月 U+6708 へ変更する。⿰月董 の evidence を付録に示す。 |
| U+26842 の V-source | `VN-26842` → `V2-8222`。 |
| U+26866 の V-source | `V2-8222` → `VN-26866`。 |
| U+26842 の G-source | 肉 component が明確になる representative glyph へ修正する。 |

付録は『汉语大词典』、1914年の『繁华』、2017年の『明清小说俗字典』、清刊本の『说郛·画鉴』『飞花咏小传』の5点を載せる。最後の evidence は Liu Yikun の提供と記す。

## 後続決定

## 論点

radical、glyph、source reference を連動させる案であり、V-source の reference swap だけを独立した確定更新として扱えない。U+268A1 / U+268A2 の V-source issue とは別件である。PDF 自身の日付は2026-10-10、registry date は2026-10-11。
