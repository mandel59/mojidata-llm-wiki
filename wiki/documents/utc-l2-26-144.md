# L2/26-144

## 要約

`L2/26-144` は、letter I / i から派生した2組4文字を Latin Extended-D に追加する proposal である。`I WITH OBLIQUE STROKE` pair は medieval Latin abbreviation と Tlahuica practical orthography、`I WITH DESCENDER` pair は 1929–1939 年の Latinized Khakas alphabet に用例を持つ。

提案 code points は U+A7DE..U+A7E1。各組を uppercase / lowercase pair とし、Khakas 用小文字は historical sources に従って dotless とする。文書は character identity だけでなく、既存資料の代替表記と、標準 glyph で避けるべき形状も示している。

## 提案内容

| Code point | Proposed name | 用途 |
| --- | --- | --- |
| U+A7DE | `LATIN CAPITAL LETTER I WITH OBLIQUE STROKE` | medievalist usage、Tlahuica |
| U+A7DF | `LATIN SMALL LETTER I WITH OBLIQUE STROKE` | medievalist usage、Tlahuica |
| U+A7E0 | `LATIN CAPITAL LETTER I WITH DESCENDER` | historical Khakas Latin alphabet |
| U+A7E1 | `LATIN SMALL LETTER DOTLESS I WITH DESCENDER` | historical Khakas Latin alphabet |

4文字はいずれも spacing Latin letters で、general category は大文字が `Lu`、小文字が `Ll`、bidi class は `L`。U+A7DE / U+A7DF と U+A7E0 / U+A7E1 をそれぞれ simple case mapping で結ぶ。combining sequence や presentation form ではなく、独立した orthographic characters として提案する。

### I with oblique stroke

Medieval Latin manuscripts では `inter` の abbreviation、Mexico の Tlahuica / Ocuiltec (`pjyɇkakjó`, ISO 639-3 `ocu`) practical orthography では [ɨ] を表す。font support がない Tlahuica 資料では ordinary I / i に slash を重ねた形や U+0268 LATIN SMALL LETTER I WITH STROKE が代用され、slash が stem や dot と衝突して読みにくい例がある。

提案は、Medievalist usage と一部 Tlahuica source に見える短い oblique stroke を標準 glyph の基準とする。annotation は `Medievalist usage, Tlahuica` を推奨する。

### I with descender

Khakas の Latinized alphabet で 1929–1939 年に [ə] を表し、language self-name もこの文字を含む形で綴られた。lowercase は dotless だったため、proposed name に `DOTLESS` を含める。annotation は `Khakassian`。

活字資料には narrow I / dotless i と descender の接続部が foot のように張り出し、L / small capital L の派生に見える例がある。提案はこれを typesetting artifact とみなし、I / dotless i からの派生が明瞭で foot のない形を標準 glyph とする。

## 論点

### 字形の識別性

oblique stroke は slash overlay や U+0268 の glyph と、descender pair は L-derived letters と混同しうる。提案が求めるのは単なる装飾差ではなく、historical orthographies における casing pairs であり、font design では stroke の長さ、dot の有無、descender の foot を区別する必要がある。

### 現用資料と historical corpus

oblique-stroke pair は historical Medievalist usage と contemporary Tlahuica orthography を横断する。一方、descender pair は短期間使われた historical Khakas alphabet の資料再現が中心である。同一 proposal 内でも user community と corpus の性質が異なる。
