# L2/26-248

## 要約

Biswajit Mandal が Jain Nagari などの Sanskrit / Prakrit 写本に使う3 signs を提案する。
U+11B10 JAIN PUSHPIKA、U+11B11 SEPARATOR、U+11B12 CONTINUATION SIGN を候補とする。
Devanagari Extended-A に追加し、全3字を Po / ccc=0 / Bidi_Class=L / Line_Break=AL とする案。
文書日付は 2026-08-22、registry date は 2026-10-13。

## 提案内容

- text / section の終了、連結語の区切り、改行時の続き・省略箇所を示す機能を写本画像で説明する。
- JAIN PUSHPIKA と letter CHA の用例を分け、CONTINUATION SIGN の全 variants を今回追加するとはしない。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

NamesList 案では U+11B11 が CONTINUATION SIGN と記され、冒頭 repertoire / UnicodeData の SEPARATOR と一致しない。割当・名称・annotation の対応を審議で整理する必要がある。
