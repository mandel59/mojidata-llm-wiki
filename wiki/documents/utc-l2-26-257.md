# L2/26-257

## 要約

Kadu Than Naing が Kadu language 用の Asak kyeing を符号化する案を提出する。
2022年に community が採用した独立 alphabet を対象とし、左から右、inherent vowel なしとする。
21 consonants、final consonant 1字、vowels 8字、tone marks 3字、modifiers 2字、digits 10字、計45文字を求める。
文書日付は 2026-08-12、registry date は 2026-10-13。

## 提案内容

- vowels と tone marks、Pali loanwords 用 modifiers、既存 initial letters を再利用する finals を分ける。
- code points は xx00 などの placeholders で、絶対位置の割当を確定していない。

## 後続決定

この文書の変更要求を採択する後続 minutes / recommendation は未確認。提案 code points と property values を確定仕様として扱わない。

## 論点

文書が述べる community adoption と Unicode / ISO の encoding decision を区別する。
