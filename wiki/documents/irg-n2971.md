# IRG N2971

## 要約

`IRG N2971` は W3C Internationalization が IRG Meeting \#67 に提出した1ページの activity report である。CJK ideograph encoding と Web の internationalization requirements の連携を目的に IRG 活動への参加を始めたと述べる。

Chinese text layout、ruby、文字列の照合、言語・方向 metadata、CSS text spacing を最近の関連作業として挙げる。IRG に decision を求める文書ではなく FYI の報告である。

## 報告内容

- 2026-08-04 の Chinese Text Layout Draft Note、2026-06-04 の HTML Ruby Markup Extensions Candidate Recommendation Snapshot を挙げる。
- 2026-07-16 の string matching と language / direction metadata に関する First Public Working Drafts を挙げ、CJK に関する IRG expert feedback を求める。

## 後続決定

[IRG N2973](irg-n2973.md) は China と W3C の会議言語提案であり、本 activity report とは別文書である。Meeting \#67 の対応は会合後に確認する。
