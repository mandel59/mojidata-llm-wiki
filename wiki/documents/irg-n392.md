# IRG N392

## 要約

WG2 第31回で受けた ideographic composition 関連4案への質問集。
構造記号12問、Variation Mark 5問、radical supplement 4問、component supplement 4問を整理する。
scope・入れ子・等価性・不正な構成・類似の意味・独立利用の可否を問い直す。
質問を、既に決まった仕様や禁止事項として読み替えない。

## フィードバック内容

| 対象 | 主な問い |
| --- | --- |
| Structure Characters / WG2 N1430 | operands の範囲と種類、入れ子・grouping・優先順位、符号化済み漢字の別表現と等価性、implementation level、不可能な構成への処理、囲み記号の統合。 |
| Variation Mark / WG2 N1431 | meaning / abstract shape / glyph image のどの類似か、複数の mark が必要か、適用対象、sequence の呼称、sorting / lexical properties。 |
| Radical Supplement / WG2 N1432 | 部分追加と独立した完全部首集合のどちらがよいか、既存統合漢字との区別・統合規則、他記号との組合せ。 |
| Component Supplement / WG2 N1433 | 部分追加か独立した完全集合か、統合原則、構造記号なしに独立利用できるか。 |
