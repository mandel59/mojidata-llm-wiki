# IRG N2934R

## 要約

`IRG N2934R` は、IRG Meeting \#67 を Tokyo, Japan で hybrid 開催する First Call である。文書上の会期は 2026-10-12/16、host は SAT Daizōkyō Text Database Committee、in-person 会場は National Center of Sciences Building 1階の Hitotsubashi Hall とする。

参加登録は in-person / remote とも 2026-09-18、会合文書提出は 2026-09-25 が締切。remote attendees は Zoom を利用し、詳細 logistics は [IRG N2914R](irg-n2914r.md)、更新される schedule / agenda は [IRG N2935](irg-n2935.md) を参照する。

## 後続決定

[IRG N2935](irg-n2935.md) の 2026-07-05 update は、Friday 2026-10-16 を `NO MEETING` とし、実質的な sessions を 10月12–15日に置いている。したがって First Call の meeting range `2026-10-12/16` は event identifier / 当初告知として保ち、current daily schedule は N2935 を優先する。

Meeting \#67 recommendations 用の register row は予約されているが、2026-07-20 の取得では PDF URL が HTTP 404 を返した。First Call と agenda は会合開催や決定を意味せず、recommendations は実体公開後に別途 digest する。

## 論点

### First Call と agenda の役割

本書は開催場所、参加方法、締切を確定する notice で、technical agenda や決定事項の一次ソースではない。WS2024、horizontal extensions、source / glyph issues などの議題は [IRG N2935](irg-n2935.md) と個別 documents、会合結果は会合後の recommendations で追う。

### Japan / SAT との関係

Tokyo 開催と SAT hosting は Japan における IRG activity だが、本書は Japan NB の position paper ではない。host / venue information と member-body technical positions を分離する必要がある。
