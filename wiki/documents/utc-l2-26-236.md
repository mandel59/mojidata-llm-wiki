# L2/26-236

## 要約

Editorial WG の Unicode 18.0 振り返りと19.0編集計画。
block tables と versioned charts の接続、staging、release 直前に集中した AI-assisted feedback を報告する。
19.0 では beta review での PDF 提供、全文検索、script sections の再編、citation instructions の改善を検討する。
構成変更や引用方法の改善は計画・提案準備の段階である。

## 報告内容

- block tables から対応する version の chart にリンクできるようになった。
- 19.0 beta では内容を HTML、production issues を PDF で review する計画。
- Pagefind を全文検索の候補とし、script chapters の再編・accessibility・UAX / UTS の編集基盤を調査する。
- Jim DeLaHunt が citation instructions 改善案を準備する action item を UTC に勧告する。
- PRI \#556 の Seal / Small Seal の名称差は意図した表示と説明し、Myanmar decimal number sets の記述漏れは19.0向けに修正済みと報告する。
