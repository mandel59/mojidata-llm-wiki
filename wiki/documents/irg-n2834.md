# IRG N2834

## 要約

`IRG N2834` は、U+980B 頋、compatibility ideographs U+FACB / U+2F9FF、KP1-869A / T6-6430 の disunification に伴う Unihan reading properties を検討した feedback である。Eiso Chan と Lee Collins は、《廣韻》6 editions の字形を比較し、4 editions が U+2EA07 𮨇系、2 editions が KP1-869A / T6-6430 系であると報告した。

文書は、U+980B に混在する `kCantonese`、`kDefinition`、`kFanqie`、`kSBGY` の古暮切系 data と、`kHanyuPinyin`、`kJapanese`、`kMandarin` の五果切系 data を分離する二案を提示する。authors は、KP1-869A / T6-6430 を既存 U+2EA07 に unify し、新規 U+2B81F を設けない Solution 2 をやや優位とした。

## フィードバック内容

### property values の不整合

文書は U+980B の readings を二系統に分ける。`kCantonese=gu3`、`kDefinition`、`kFanqie=古暮` は 顧 / 顾 系を指す一方、`kHanyuPinyin`、`kJapanese`、`kMandarin` は 五果切の 頋 に対応すると分析する。`kSBGY=368.26` も古暮切 entry に由来するため、現状では異なる字を指す data が同じ code point に集まっているとする。

### 《廣韻》6版の比較

Figures 1-4 は U+2EA07 の glyph に対応し、JMJ-059024 / SAT-05888 と同じ 顧 variant 系として扱われる。Figures 5-6 は KP1-869A / T6-6430 の glyph に対応する。authors は後二版が宋代より後の刊本であることも判断材料として示す。

### 二つの解決案

| 案 | code point | property migration |
| --- | --- | --- |
| Solution 1 | KP1-869A / T6-6430 を新規 U+2B81F に置く | 古暮切系 values を U+2EA07 と U+2B81F に分け、`kSBGY` を U+2EA07 へ移す。 |
| Solution 2 | KP1-869A / T6-6430 を既存 U+2EA07 に unify | 古暮切系の `kCantonese`、`kDefinition`、`kFanqie`、`kSBGY` を U+2EA07 へ移し、新規 U+2B81F を設けない。 |

両案とも U+980B の `kCantonese` を `ngo5`、`kFanqie` を 五果へ調整する方向を示す。Cantonese reading は後続確認が必要と明記される。

## 後続決定

[IRG N2826](irg-n2826.md) の M65.05 は、`IRG N2834` と [IRG N2865](irg-n2865.md) の提案に基づく disunification を unanimously accept し、KP1-869A と T6-6430 を新規 U+2B81F ではなく既存 U+2EA07 に置くことを WG2 へ勧告した。これは文書が優位とした Solution 2 に対応する。

[IRG N2892](irg-n2892.md) は、Meeting \#65 の結果を U+FACB / U+2F9FF から U+2EA07 への source migration として一覧化し、文書時点では WG2 \#73 confirmation 待ちと記録した。

## 論点

### glyph evidence と reading data を同時に直す

この case は source glyph の移動だけでなく、dictionary-derived properties がどの historical glyph / reading に属するかを再評価する必要がある。code chart、source reference、reading properties を別々に更新すると、U+980B と U+2EA07 の identity が再び不整合になる。

### compatibility mapping は維持される

U+FACB / U+2F9FF の compatibility mapping は U+980B のまま維持される一方、KP / T source references は U+2EA07 へ移る。compatibility equivalence と regional source glyph identity は同一の関係ではない。
