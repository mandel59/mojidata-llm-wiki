# IRG N366

## 要約

「似ているが同じではない」漢字を示す1つの Ideographic Variation Mark の追加案。
N365 の構造記号とは別の提出案とし、summary form は編集時の warning mark と説明する。
表紙は IRG 第7回 Resolution 10b による承認、BMP への収録要求を示す。
現在の variation selector / IVS / IVD と同じ仕組みであるとは扱わない。

## 提案内容

- summary form は1文字、Implementation Level 1 を記す。composite sequences については No とし、editing only の warning mark と説明する。
- 添付 N366A は略号 VAR と、似ているが同一ではないことを示す例を載せる。
- 表紙の1996-07-31と、summary form / 添付の1996-06-27を区別する。
- 余白の手書き意見を IRG / WG2 の採択文として引用しない。

## 後続決定

[WG2 の明確化要求](../events/wg2-31-ideographic-description-refinement.md)と [N392](irg-n392.md)が similarity の軸や sorting / lexical properties を問う。現在との比較は [IVD topic](../topics/ideographic-variation-database.md)へ。
