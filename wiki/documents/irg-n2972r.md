# IRG N2972R

## 要約

TCA が Extension B の700字に対する T-source horizontal extension proposal を改訂する。
2026-10-12 の source-owner response に基づく No.420 の表差替えを記録する。
字形と reference の扱いは [TCA source replacement](../events/irg-67-tca-u2403d-source-replacement.md) に集約する。
PDF / registry date は2026-10-13、総数は700字を維持する。

## 提案内容

- 700字表、IRGN2972R_700_TsrcRef.ttf と mapping text の PDF attachments を指定する。
- No.420 の revision が記録する source-owner の判断は、関連 event に集約する。

## 後続決定

[IRG \#67 TCA U+2403D source replacement](../events/irg-67-tca-u2403d-source-replacement.md) - TCA の source / glyph 差替えの経緯。

[IRG Meeting \#67](../meetings/irg/irg-meeting-67.md) と IRG N2946 の正式 recommendation / action items で採否を確認する。

## 論点

表紙の scope は700 TA-source characters のままだが、改訂表には T9-source の置換を含む。全体をすべて TA-source として数えず、正式 data への反映は後続記録で確認する。
