# IRG N2889R2

## 要約

`IRG N2889R2` は China が IRG N2884、N2838、N2730 に応答した G-source glyph feedback である。多くの glyph revision の妥当性を認めつつ、U+2A790 の字形と元の `⿱罒子` 形の分離、U+2B42D / U+2B5B1 の新旧字形関係などを個別に論じる。

Registry 上の日付は 2026-03-23、PDF の表紙には 2025-10-11 と記されている。両者を区別し、この page の `date` は registry を採る。

## フィードバック内容

- IRG N2884 / N2838 が挙げた57件の G-source glyph correction に賛同する範囲を示す。
- U+2A790 について、現在の glyph を `⿱㓁子` に寄せ、元の `⿱罒子` 形を将来別 code point とする案を提示する。
- 一部の新旧字形の判断は慎重に扱い、字形修正と文字の分離を一律に結び付けない。

## 後続決定

この文書は China の feedback であり、個別字形の IRG 採択を自ら記録しない。関連する後続 status は meeting recommendations を確認する。
