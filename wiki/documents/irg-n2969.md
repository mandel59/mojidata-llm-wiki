# IRG N2969

## 要約

`IRG N2969` は China が IRG Meeting \#67 に提出した、UNC 1文字の符号化提案である。『毛泽东文集』全8巻を調査し、GB/T 2312 にない24文字のうち URO / GBK にもない9文字を確認し、なお未符号化である1文字を対象とする。

対象字には新しい `GHS-00001` source reference、IDS `⿰钅别`、普通話の読み `bì`、客家語の読み、U+289E2 との traditional variant 関係などを提示する。原文資料の証拠を用いて、早期の digitization に必要な UNC と位置付ける。

## 提案内容

- `GHS` を China Revolution and Reform Literature の G-source として導入し、`GHS-\d{5}` 形式の source reference を示す。
- 『毛泽东文集』中の用例と字形、読み、variant 関係を示し、未符号化1文字の UNC 登録を求める。

## 後続決定

[IRG N2935](irg-n2935.md) は本提案を Meeting \#67 agenda Section 6 に載せる。会合は 2026-10 開催予定であり、IRG の採否は未決である。決定の一次ソースは会合後の `IRG N2946` を確認する。

## 論点

これは既存文字への horizontal extension ではなく、新規 UNC の proposal である。文書が示す variant と source evidence を IRG review でどう評価するかが論点となる。
