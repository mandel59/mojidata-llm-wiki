# IRG N2933

## 要約

`IRG N2933` は、IRG Working Set 2024 Version 5.0 に対する consolidated comments の一覧である。174 ページの表は source と serial number ごとに comments を並べ、Attributes、Unification、Glyph Design & Normalization、Other などの区分を付ける。

以前の Version 1.0～4.0 から unresolved として持ち越された指摘と、新しい指摘が併記される。各行は提出者・reviewer の意見であり、会合の採否ではない。Meeting \#67 の WS2024 review に使う入力文書として読む。

## データ内容

- Attributes には radical、residual / total stroke count、first stroke、IDS などの修正提案を集める。冒頭の区分だけで 392 comments と表示される。
- Unification には既存文字との統合・分離についての evidence と reviewer responses、Glyph Design & Normalization には source glyph の形や正規化についての指摘を置く。
- コメントには source owner、IRG Convenor、各 body の reviewer による同意・異論・追加 evidence が含まれ、同一 candidate への複数意見を個別に追える。

## 後続決定

[IRG N2935](irg-n2935.md) は Version 5.0 review を Meeting \#67 の中心議題に置く。`IRG N2933` の個別 comments を決定済みの glyph / attribute changes とみなさず、会合後の editorial report と recommendations で disposition を確認する。

## 論点

[IRG N2932](irg-n2932.md) の Version 5.0 chart / list と突き合わせることで、candidate の現行属性、comment、source owner response を区別できる。集計表全体から一律の採否を導かない。
