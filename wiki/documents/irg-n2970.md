# IRG N2970

## 要約

`IRG N2970` は Vietnam が ISO/IEC 10646 / Unicode の既存 CJK ideographs に9,263件の Vietnamese source references を加える horizontal extension proposal である。Hán-Nôm の伝統的・現代的な文献を扱う複数の辞書・資料に根拠を置く。

提案対象は quốc ngữ の読みが十分に確認できる文字に限り、追加の horizontal extension は今後の研究に委ねる。各行は code point、`kIRG_VSource`、読み、出典とページを対応付ける。

## 提案内容

- 既存文字への V-source reference の追加を求める。新規 code point の符号化提案ではない。
- 出典には『大字典字喃』、『字喃字典』、Taberd の辞典などを含み、資料略号とページ番号を各文字に付ける。
- 414ページの表には既存の `V2` reference を持つ行も含まれるため、review 時には追加・照合する reference の内訳を確認する必要がある。

## 後続決定

[IRG N2935](irg-n2935.md) は Meeting \#67 agenda Section 8 に本提案を載せる。2026-09 時点では提出段階であり、採択済みの source data として扱わない。

## 論点

提案件数が大きいため、既存 V-source reference との重複、各国語の読みと文献証拠、source owner による照合が review の中心となる。[CJK Horizontal Extensions](../topics/cjk-horizontal-extensions.md) に他 body の同型提案をまとめる。
