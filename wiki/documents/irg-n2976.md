# IRG N2976

## 要約

IRG N2976 は、Wang Xieyang が U+21D0A と U+20553 の representative glyph 重複を指摘した提案である。
U+21D0A の現行 glyph は学術的には望ましくても、source reference の『汉语大字典』の字形と合わないとする。
China に U+21D0A の glyph を元の形へ戻すよう求め、両 code points の表示上の重複を避けることを狙う。
新しい文字の符号化や二つの code points の統合を求める文書ではない。

## 提案内容

Unicode 5.1.0、5.2.0、6.0.0 の glyph を比較し、U+21D0A の表示が変化して U+20553 と同じ形になった経緯を示す。『汉语大字典』第一版1022頁・左欄第3字と第二版1095頁・左欄第6字を evidence とし、U+21D0A の representative glyph を original form へ戻すよう提案する。

## 後続決定

[IRG N2935](irg-n2935.md) の2026-10-12版は Section 9.1 に掲載する。IRG / China NB に検討を求めた段階であり、正式な disposition は [IRG Meeting \#67](../meetings/irg/irg-meeting-67.md) と `IRG N2946` の公開後に確認する。

## 論点

既存文字の identity と code chart glyph の重複を分ける必要がある。PDF 自身の日付は2026-10-10、registry date は2026-10-11である。
