# IRG N2938

## 要約

`IRG N2938` は Macao SAR の Meeting \#67 activity report である。MSCS は 443 文字（漢字 427、記号 16）のままで、政府内システム間のデータ交換を主用途とする。

2026 年上半期の文字追加申請は採用基準を満たさず、当面は新しい code point や horizontal extension を提案しない。IRG M66.08 に対しても、次期 Working Set への提出予定はないと明記する。

## 報告内容

- 現行の追加基準のもとでは、今後数年の追加候補は 10～20 文字程度と見込む。基準を緩めた場合の 50～100 文字という数字は条件付き見通しである。
- 七つの system vendor が mobile / desktop 環境で MSCS の表示と入力を段階的に支援している。KylinOS は表示と Cangjie 入力の初期支援を提供した。
- SC 2/AG 1 への移行に合わせ、Category C liaison organization の設立を検討し、2026-11 の政府会議で扱う予定とする。

## 後続決定

この報告は Macao SAR の方針と見通しを示す。IRG Meeting \#67 の決定や liaison 設立済みの状態は記録しない。
