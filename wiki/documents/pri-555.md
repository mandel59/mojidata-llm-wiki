# PRI \#555

## 要約

`PRI #555` は line breaking / segmentation のfinite automata dataをreviewしたPRI。
state machinesをUnicode data filesとして公開する案と、背景・利用方法を示す [L2/26-135](utc-l2-26-135.md) を扱う。
closing dateは2026-10-05。2026-11-03のpageはClosedで、採用や正式データ公開のResolutionは記載されていない。

## 提案内容

review 対象は UAX \#14 / UAX \#29 の規則本文を置き換える新 normative algorithm ではなく、規則に対応する finite automata data とその利用方法である。実装者は data files と `L2/26-135` を合わせて評価する必要がある。

## 後続決定

[review 終了 event](../events/utc-189-pri-523-555-556-review-closures.md) へ。PRI page は Closed だが、採用や正式データ公開を記す Resolution はない。[L2/26-217](utc-l2-26-217.md) は実装経験に基づく賛成意見と仕様明確化の要望を提出している。

review 用には17.0.0 / 18.0.0のdirectoryがあり、18.0.0側に states・symbols・transitions・tailorings の試験データを置く。review 用データの存在だけで正式な UCD の構成要素と断定しない。

## 論点

Unicode 18.0 本体は既に release 済みだが、この PRI は Version 18.0 algorithms の機械実装資料を後続 review している。release authorization と supplementary machine-readable artifacts の review 時点を分けて読む。
