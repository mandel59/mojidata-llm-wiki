# PRI \#558

## 要約

`PRI #558` は Proposed Update UAX \#38, Unicode Han Database (Unihan) の open review である。Unicode 19.0向けの documentation / property syntax を扱い、closing date は2026-12-30。

## 提案内容

draft は IRG の SC 2/AG 1 への restructuring、Singapore references、新 normative `kIRG_SGSource`、`kIRG_GSource` からの `GS` prefix removal、Components-A/B 用 `GCP` / `GCW` / `HCP` / `TCP` prefixes、Section 4.4 の block table 更新を含む。

## 後続決定

2026-11-03のpageもOpen。`kTabooVariant` は [L2/26-216](utc-l2-26-216.md) の別 proposal であり、この draft の採択済み property と混同しない。

## 論点

この PRI は repertoire proposal 自体ではなく、UTC \#188 で進んだ Components-A/B と `kIRG_SGSource` を UAX \#38 の source model に統合する review である。

### 2026-10-26付のDraft 4

Revision 42のDraft 4は、radical / stroke characterの `Equivalent_Unified_Ideograph` が指す漢字の `kTotalStrokes` が元の文字の画数とは限らないと明確化する。`GHS` prefix と U+2B81F のcoverage追加も含み、modificationsは189-A10、189-C7 / 189-A22を参照する。これらは取得したdraftの記載であり、Unicode 19.0正式版の公開を意味しない。
