# PRI \#558

## 要約

`PRI #558` は Proposed Update UAX \#38, Unicode Han Database (Unihan) の open review である。UTC \#188 の Unicode 19.0-target decisions を documentation / property syntax に反映し、closing date は 2026-10-05。

## 提案内容

draft は IRG の SC 2/AG 1 への restructuring、Singapore references、新 normative `kIRG_SGSource`、`kIRG_GSource` からの `GS` prefix removal、Components-A/B 用 `GCP` / `GCW` / `HCP` / `TCP` prefixes、Section 4.4 の block table 更新を含む。

## 後続決定

2026-09-18 時点で open。`kTabooVariant` は [L2/26-216](utc-l2-26-216.md) の別 proposal であり、この draft の採択済み property と混同しない。

## 論点

この PRI は repertoire proposal 自体ではなく、UTC \#188 で進んだ Components-A/B と `kIRG_SGSource` を UAX \#38 の source model に統合する review である。
