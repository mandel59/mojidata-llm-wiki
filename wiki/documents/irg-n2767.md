# IRG N2767

## 要約

`IRG N2767` は、2025-03-17/21 の IRG Meeting \#64 で CJK Editorial Group が扱った miscellaneous issues の審議結果である。16件の T-source migration、U+6138 と U+FACB / U+2F9FF の disunification、G/T/V source updates、UCV/NUCV、IRG PnP、UNC、script-hybrid Han ideographs、CJKV Components を一つの report にまとめる。

この文書は plenary approval 前提の editorial report であり、会合全体の正式な recommendations and action items は [IRG N2765](irg-n2765.md) と併読する。とくに U+FACB / U+2F9FF の移動先は本書の U+2B81F から後続 review の U+2EA07 へ変更されたため、文書時点を保って読む必要がある。

## 報告内容

### disunification と horizontal extension

Meeting \#64 は `IRG N2778` の要求を受け、CJK Compatibility Ideographs Supplement の16文字にある T-source references を対応する unified ideographs へ horizontal extension として移し、移動元には `TU-<code point>` 形式の historical references を置くことを受け入れた。

U+6138 から KP1-439A を新規 U+2B81E へ分離する案も accept した。U+FACB の KP1-869A と U+2F9FF の T6-6430 については、[IRG N2786](irg-n2786.md) などに基づき新規 U+2B81F へ分離すると記録する。U+2A50D は Japan の feedback 待ちとして、この会合では action を取らなかった。

China の2,145件の G-source horizontal extensions と、`IRG N2779R2` ほかにある T-source glyph / reference updates も accept された。

### glyph と property updates

report は、Unicode 17.0 Alpha review に反映された V-source changes、U+2B7C2 の T-glyph と T-source `TB-7C6B` への更新、Vietnam の U+620E phonetic component を含む8 glyphs、3件の V-source normalization を記録する。33件の G-source glyph revision を approve した一方、U+9D56、U+3125D、U+6FF2 など一部は Meeting \#65 へ継続した。

Radical \#194 を一律に common form へ normalize する `IRG N2797R` は glyph change として accept せず、China が U+2D84F への horizontal extension proposal を提出する方向とした。

### UCV/NUCV と IRG PnP

Meeting \#63 までの UCV/NUCV updates を confirm し、Meeting \#64 の新例を次版 `IRG N2813` へ統合することを accept した。PnP については次を合意した。

- `kTotalStrokes` は IRG counting method に従う1値とし、他の counts は provisional `kAlternateTotalStrokes` に置く。
- submission から first residual stroke values を外し、ORT の自動計算と Chief Editor の修正対象にする。
- Annex D の固定 source prefix list を外し、IRG home page と UAX \#38 に同期する一覧を参照する。
- unclear residual stroke value は Annex K で 6 とする。

Working Set の quota と review speed は継続検討とし、現用文字の submission では local reading と official-language reading の両方を可能な限り付す方向に合意した。

### UNC、script-hybrid、components

China が提出した12 ideographs は urgently needed characters として accept し、U+2CEA2..U+2CEAD を推奨 code points とした。US/Unicode の script-hybrid 2文字は扱いの consensus がないため accept しなかった。

script-hybrid Han ideographs は standard stability を理由に性急な判断を避け、対象基準と評価手続をさらに検討するとした。CAAPH IVD collection は objection なしとして endorse し、[IRG N2799](irg-n2799.md) の468 CJKV components は改訂版を Meeting \#65 に出すよう求めた。

## 後続決定

U+FACB / U+2F9FF case は、[IRG N2834](irg-n2834.md) が既存 U+2EA07 を使う Solution 2 を提示し、TCA の [IRG N2865](irg-n2865.md) を経て [IRG N2826](irg-n2826.md) M65.05 が採択した。したがって本書の U+2B81F disposition は Meeting \#64 時点の記録であり、最終案ではない。[IRG N2892](irg-n2892.md) は Meeting \#65 までの更新後の状態を一覧化する。

Script-hybrid Han ideographs は M64 では継続議論だったが、M65.24 で原則として CJKUI extension blocks とは別 block に置く方向へ整理された。CJKV Components も M65.23 と後続改訂を経て WG2 forwarding へ進んだ。

## 論点

### editorial report と plenary recommendation

本書は個別議題の採否と technical details を多く残す一方、正式な recommendation numbering は `IRG N2765` にある。decision trail では本書を詳細な editorial record、`IRG N2765` を plenary recommendation として区別する。

### 会合後に変わった disposition

U+FACB / U+2F9FF のように、Meeting \#64 で accept された新規 code point 案が後続 evidence により既存 code point へ変わる場合がある。古い report の状態を現在状態として転載せず、body・meeting・date と後続文書を併記する必要がある。
