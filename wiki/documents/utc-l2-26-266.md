# L2/26-266

## 要約

UAX \#38 Revision 42, Draft 3 の Proposed Update snapshot。PRI \#558 の review 対象に対応する。
本文日付は2026-09-27、registry date は2026-10-16。
Unicode 19.0 を対象とする draft であり、公開済みの18.0仕様とは分けて読む。
今回のPDF登録は review 解決や最終版公開の記録ではない。

## 提案内容

- normative kIRG_SGSource を追加し、kIRG_GSource の GS prefix を除く。
- CJK components に対応する GCP / GCW / HCP / TCP prefixes と block / indexing の説明を追加する。
- kHangul の記述を更新する。
