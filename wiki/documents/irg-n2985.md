# IRG N2985

## 要約

IRG N2985 は、China / Tao Yang が IRG N2954 と N2955 の U+2CCA3 issue に回答した feedback である。
IRG N891 / N1519 の evidence と glyph の照合に誤りがあったと認め、U+2CCA3 を本来の ⿰钅𣃍 に戻す案を支持する。
glyph に加え、kRSUnicode、kTotalStrokes、traditional form の変更を示す。
source reference を GU に変更して現行 glyph を維持する案は採らず、原 evidence と code point の対応を復元する方向を提案する。

## フィードバック内容

『汉语方言大词典』にある関連4形のうち、⿰金𣃍、⿰飠斯、⿰饣斯はそれぞれ U+28C09、U+2CC9B、U+2B5F2 に符号化済みと説明する。⿰钅𣃍 に対応するはずの U+2CCA3 に ⿰飠𣃍 が入ったとし、次の修正を提案する。

| 項目 | 現行 → 提案 |
| --- | --- |
| G-source glyph | ⿰飠𣃍 → ⿰钅𣃍 |
| `kRSUnicode` | `184.18` → `167'.18` |
| `kTotalStrokes` | `26` → `23` |
| Traditional Form | 対応なし → U+28C09 |
