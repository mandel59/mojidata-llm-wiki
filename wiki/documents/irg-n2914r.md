# IRG N2914R

## 要約

`IRG N2914R` は、Tokyo で hybrid 開催される IRG Meeting \#67 の logistics arrangement である。会期を 2026-10-12/16、会場を National Center of Sciences Building 内の Hitotsubashi Hall、会議室を1階 Special Meeting Rooms とし、SAT Daizōkyō Text Database Committee が host を務める。

参加登録期限は 2026-09-18。visa 用の invitation letter が必要な参加者には 2026年7月末までの登録を推奨し、welcome dinner、会場アクセス、交通、宿泊、日本滞在時の基本情報も案内する。technical agenda や会合決定を記録する文書ではない。

| 項目 | Logistics の内容 |

| date | 2026-10-12/16。10月12日は日本の祝日。 |

| other guidance | welcome dinner、空港・国内・市内交通、宿泊、通貨・電源・決済など |

## 後続決定

[IRG N2934R](irg-n2934r.md) は First Call として参加方法、会合文書提出期限、remote meeting の案内を補い、[IRG N2935](irg-n2935.md) は daily schedule と technical agenda を更新する。N2935 の 2026-07-05 update では 10月16日を `NO MEETING` としているため、実際の session 日程は current agenda を優先する。

本書は開催実務の notice であり、recommendation、action item、technical position を含まない。Meeting \#67 の決定事項は会合後の recommendations 文書で別途追跡する。

## 論点

### First Call / agenda との役割分担

N2914R は registration、visa、venue、travel information の一次ソースである。会合の提出期限と remote participation は N2934R、議題と日別進行は N2935 が一次ソースとなるため、情報の更新時点を混同しない。

### Japan / SAT との関係

会合は日本国内で開催され、SAT Daizōkyō Text Database Committee が host だが、本書は Japan NB の position paper ではない。hosting activity と J-source などに関する technical position は分離して読む必要がある。
