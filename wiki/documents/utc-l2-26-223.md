# L2/26-223

## 要約

L2/26-223 は、Qiang language 用 Wei Rma script の69字を提案する改訂文書である。
L2/22-130、L2/25-129、L2/26-058 を改訂し、過去の SEW comments を取り込む。
従来の Abugida model から alphabet model へ移り、子音に inherent vowel がないことと、base vowels / vowel marks の違いを説明する。
本文の日付は 2026-10-06、registry date は 2026-10-09。

## 提案内容

- 47 consonants と1 vowel carrier、5 vowel letters、3 vowel marks、nasalization / rhotacization indicators 各1字、tone marks 2字、symbol 1字、punctuation 8字を示す。
- 新 repertoire は U+16000 以降の提案表に示される。
- orthographic syllables を C-type、V-type、R-type に分け、linguistic syllable は複数の orthographic syllables で構成できるとする。
- ENN の `Canonical_Combining_Class=204` を提案し、nasalization と後続 vowels / tones の順序を整理する。
- dedicated digits は設けず European digits を使う。

## 後続決定

この文書の採否を記録する後続 recommendation / minutes は未確認。提案された文字・property・注釈を採択済みとして扱わない。

## 論点

Qugu と Taoping 等の音韻の違いを収めながら、letter / mark と syllable boundary の扱いを安定させることが中心となる。Rma という ethnic endonym だけでなく creator の surname を含む Wei Rma を script name とする。
