# L2/26-241

## 要約

RMG が Unicode 18.0 の公開と作業工程を振り返り、19.0 の scope・日程・repertoire を提案する。
19.0 を新文字を含む full release とし、既に承認された494 CJK components に1,596文字を加える案。
alpha / beta review と2027-09-15 release を予定するが、UTC 承認前の計画である。
release 直前の LLM review と staging の課題を踏まえ、QA と自動化の前倒しを求める。

## 報告内容

- repertoire 案は494 + 1,487 + 109 = 2,090文字。新script は Sirmauri 55、Proto-Cuneiform 1,392、Chisoi 40文字。
- 109文字の追加には以前の provisional assignments と、再review後の Leibniz 15文字を含む。
- 7 standardized variation sequences の追加も提案する。
- 日程案: 2027-02-09 alpha 開始、03-23終了、05-25 beta 開始、07-06終了、07-29 UTC \#192 finalization、09-15 release。
- UAX / UTS の staging-compatible links、draft deployment の自動化、早期の内容 review を勧告する。
