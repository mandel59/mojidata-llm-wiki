# L2/26-241R

## 要約

RMG が Unicode 18.0 の公開と工程を振り返り、19.0 の scope・日程・repertoire を提案する。
2026-10-27 の改訂版は、具体的な追加一覧を494 + 1,487 + 94 = 2,075文字と集計する。
初版の2,090文字から変わったが、本文・脚注には旧説明も残り、最終 repertoire 総数ではない。
2027-09-15 release を目標とし、alpha / beta review、早期 QA、staging 自動化を求める。
[189-C] は報告書内の consensus 文案であり、会合の numbered decision と区別する。

## 報告内容

| 集計対象 | 文字数 | 内容 |
| --- | --- | --- |
| 承認済み CJK components | 494 | UTC \#188 の188-C43を参照。 |
| 新script | 1,487 | Sirmauri 55、Proto-Cuneiform 1,392、Chisoi 40。 |
| その他の追加 | 94 | Latin・Indic・Arabic・phonetic・記号など。Leibnizian 54文字を含む。 |
| 上記の合計 | 2,075 | 別途提出される追加文字を含まない。 |

- 188-C17で既に承認された1件とは別に、7 standardized variation sequences の追加を勧告する。
- 日程案: 2026-12-30 PRI feedback snapshot、2027-02-09 alpha 開始、03-23終了、05-25 beta 開始、07-06終了、07-29 UTC \#192 finalization、09-15 release。
- 18.0 の release 直前に LLM review の triage 負荷が生じたことを報告し、内容 QA、staging-compatible links、draft deployment 自動化の前倒しを求める。

## 論点

### 具体的な集計と旧説明の不一致

改訂版 p.5 は「その他」を初版の109から94へ変更し、合計も2,090から2,075へ変更する。一方、p.4 本文には再reviewした Leibniz 15文字を含める勧告が残り、CDAM 1 と比較する脚注も2,090文字のままである。この差だけで15文字の不採択や最終総数を確定してはいけない。

### 日程表の年

UTC \#190 の行は「2026-01-22」と記し、同表の2026年末から2027年への並びと整合しない。原文の年をそのまま確定日程へ転記しない。
