# IRG Meeting \#5

## 概要

1995-08-22、Seoul, Republic of Korea。Vertical Extension の優先順位、IRG の work program、components の扱いを整理した。date は公開決議の日付であり、全会期の開始・終了を補っていない。

## 主要議題

- [Early IRG History (1993–1996)](../../topics/early-irg-history.md)
- [CJKV Components](../../topics/cjkv-components.md)
- [IRG Working Set 2024](../../topics/irg-working-set-2024.md)
- [IRG Working Process and Liaison](../../topics/irg-working-process-and-liaison.md)

### 参照資料の時点

- [IRG N250](../../documents/irg-n250.md) - 会合決議。

## 決定事項

N250 は3 levels の優先順位と source code values の保持を定める。components は Vertical Extension と別集合とし、既存文字と重複せず集合を最小化する方針を置く。

## 後続確認

[第6回](irg-meeting-6.md)が選択条件を具体化する。1995年の Levels I–III を現行 Extensions A/B/C の最終 repertoire と同一視しない。
