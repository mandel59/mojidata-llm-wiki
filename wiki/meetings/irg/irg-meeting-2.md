# IRG Meeting \#2

## 概要

1994-02-28/03-04、Ha Noi, Vietnam。IRG 第2回会合。[N080](../../documents/irg-n080.md) の corrected resolutions が成果文書であり、registry date の1994-03-16を開催日と混同しない。

## 主要議題

- [補充・拡張方式](../../topics/early-irg-history.md)と Vietnam の source column。
- Annex の統合規則・source standards と variants 関連部分。
- components 定義、Chu Nom 辞書、編集者と各 body の提出。

## 決定事項

[拡張の用語と V-column の event](../../events/irg-2-extension-terminology-and-v-column.md)を参照。Annex は2本立てとし、第1 Annex を T. Koike が担当する。Chief Editor と Editorial Working Group、Akio Kido の新 Rapporteur を受け入れた。

## 後続確認

[N100](../../documents/irg-n100.md)の草案と [第3回会合](irg-meeting-3.md)へ進む。N080 の将来会合日程は当時の予定であり、各会合の実際の日程を上書きする根拠にはしない。
