# IRG Meeting \#3

## 概要

1994-08-29/09-02、Beijing, China。IRG 第3回会合。結論 [N131](../../documents/irg-n131.md) と [N100](../../documents/irg-n100.md) の草案を入口にする。開始日は N080 項目10 の会合予定と、N131 の会期末に基づく推定。結論の発行日は1994-09-02。

## 主要議題

- [統合・配列 Annex](../../documents/irg-n100.md)とその適用対象。
- internal / horizontal supplementation の source 条件、V-column の5列 chart。
- vertical extension の候補分類、人名文字、MRF と review schedule。
- components と Y-variants の継続討議。

## 決定事項

[Annex 受理・送付 event](../../events/irg-3-unification-annex-forwarding.md)を参照。N131 H1–H3・V1–V6 は、traditional national standards に基づく補充と、A/H/B 分類・根拠を付ける新規文字の拡張を別工程として扱った。P1 は N095 を operational procedure として採用した。

## 後続確認

N128R は catalog の公開 URL から最終草案を辿れる。components 討議は [N200](../../documents/irg-n200.md)、review cycle の比較は [WS2024 Version 6.0 event](../../events/irg-67-ws2024-version6-review-schedule.md)を参照。
