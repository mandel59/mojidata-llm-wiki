# IRG Meeting \#67

## 概要

IRG Meeting \#67 は [IRG N2934R](../../documents/irg-n2934r.md) の First Call により 2026-10-12/16 に Tokyo, Japan で hybrid 開催すると告知された。[IRG N2914R](../../documents/irg-n2914r.md) は、National Center of Sciences Building 内の会場、2026-09-18 の参加登録期限、visa・交通・宿泊などの logistics を補う。公開 agenda [IRG N2935](../../documents/irg-n2935.md) の registry date と Last Update はともに 2026-10-08。IRG の議事は 2026-10-12/15 に集中し、金曜日 2026-10-16 は BiangBiangCon — East Asia Encoding Meetup が予定されている。

会合の中心は [IRG Working Set 2024](../../topics/irg-working-set-2024.md) Version 5.0 の review で、火曜と水曜の大部分が割り当てられている。月曜には IRG Meeting \#66 の recommendations / action items の follow-up、Horizontal Extension、Representative Glyph / Source Reference Issues が置かれている。

Member body activity reports では [China](../../documents/irg-n2936.md) が未符号化候補6,169字と WS2027 向け準備、[Macao SAR](../../documents/irg-n2938.md) が次期 Working Set への提出予定なし、[TCA 改訂報告](../../documents/irg-n2939r.md) が約 1,500～2,000 字、[Japan](../../documents/irg-n2940.md) が IRG 活動への参加再開、[SAT](../../documents/irg-n2942.md) が次期 Working Set へ約300字、[Vietnam](../../documents/irg-n2945.md) が WS2024 review 完了と V-source 9,263 件の horizontal extension を報告した。[ROK](../../documents/irg-n2941.md) は WS2024 ORT comments への回答と、次期 Working Set へ最大200字を提出する計画を報告した。これらは各 body の報告・計画であり、Meeting \#67 の決定ではない。

## 主要議題

- [IRG Working Set 2024](../../topics/irg-working-set-2024.md) - `IRG N2932` と `IRG N2933` の consolidated comments をもとに Version 5.0 を review する。
- [CJK Horizontal Extensions](../../topics/cjk-horizontal-extensions.md) - 2026-10-08 版 agenda は China [IRG N2929R](../../documents/irg-n2929r.md) 9,178字、[UK 2字](../../documents/irg-n2960.md)、U-source `IRG N2961R2`、V-source `IRG N2970`、[T-source 700字](../../documents/irg-n2972.md) を Section 8 に掲載する。TCA は [IRG N2939R](../../documents/irg-n2939r.md) で5字の glyph について説明する予定を補う。
- [IRG N2973](../../documents/irg-n2973.md) - China と W3C の中国語使用案を Section 9.4 に掲載。Section 9.2 の P&P Participation と合わせて会議運営を討議する予定で、採否は会合後の記録で確認する。
- [UAX \#45 / U-Source Ideographs](../../topics/uax45-u-source-ideographs.md) - `IRG N2961` / `L2/26-147` の U-source horizontal extension と `kIRG_USource` data。
- [IRG Source Data and Representative Glyphs](../../topics/irg-source-data-and-representative-glyphs.md) - `G` / `T` / `K` / `UK` / `V` / `SAT` / `U` source の representative glyph、source reference、Unihan property の修正。V-source では [V-source Representative Glyph Issues](../../topics/v-source-representative-glyph-issues.md) が [IRG N2928](../../documents/irg-n2928.md) / [IRG N2953](../../documents/irg-n2953.md) の U+268A1 / U+268A2 issue を追う。T-source では [IRG N2974](../../documents/irg-n2974.md) の提案に対し、[IRG N2975](../../documents/irg-n2975.md) で TCA が更新 glyph に同意し font を提出した。
- [G-source Glyph and Source Reference Issues](../../topics/g-source-glyph-and-reference-issues.md) - `IRG N2962R2` と `IRG N2963R3` の一部 glyph corrections は conflicting viewpoints として会合で検討する。
- [kIRG_SGSource](../../topics/kirg-sgsource.md) - Singapore characters を `kIRG_GSource` から独立した normative `kIRG_SGSource` へ移す案件の follow-up。
- [CJKV Components](../../topics/cjkv-components.md) - `CJK Unified Ideographs Components-A` / `Components-B` の標準化と WS2024 との重複整理。
- [IRG Indexing Rules](../../topics/irg-indexing-rules.md) - UCV / NUCV、FS / SC guidelines、[IRG N2952](../../documents/irg-n2952.md) の radical assignment rules の review。
- [UCV and NUCV Lists](../../topics/ucv-nucv-lists.md) - `IRG N2931` の UCV / NUCV review と comments due 2026-07-24。

## 決定事項

2026-10-10 時点では Meeting \#67 は未開催であり、決定事項はまだ発生していない。2026-10-08 版 agenda の Section 6 は China UNC proposal、Section 7 は Disunification Proposals `NONE`、Section 8 は5件の horizontal extension proposals を予定する。

成果文書 `IRG N2946` の row と URL は登録されているが、2026-10-10 の取得は HTTP 404 だった。agenda も成果文書を TBD としており、会合後に recommendation 本文を確認してこの節を更新する。
