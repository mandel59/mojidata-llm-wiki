# Michel Suignard

## 概要

Michel Suignard は、Small Seal Script encoding initiative で proposal / feedback 整理を継続的に担った contributor / project editor である。公開文書では、Small Seal の repertoire、code chart、database、WG2 feedback disposition をまとめる作業に関与している。

## 標準化での役割

| 文書 | 役割 |
| --- | --- |
| [L2/26-108 / PRI \#520](../documents/utc-l2-26-108.md) | Draft UAX \#60 の提出者。確定版 Revision 3 の editor としても記載される。 |
| [WG2 N5209](../documents/wg2-n5209.md) | TCA / China proposal と Cook source mapping data を比較し、Small Seal database 整理の進め方を提示。 |
| `WG2 N5294` / `L2/25-049` | Small Seal encoding initiative の considerations と mature repertoire 整理。 |
| `WG2 N5306` / `L2/25-111` | final proposal に向けた unification / disunification issue の整理。 |
| `WG2 N5317` | feedback disposition。 |
| `WG2 N5344R2` | Small Seal WG として revised proposal を提出。 |
| `WG2 N5348R` | Small Seal Script discussion の summary / feedback 整理。 |
| `WG2 N5369` | ISO/IEC 10646 7th edition CD.4 comments disposition を project editor として作成。 |
